# KVM 튜토리얼 01 — 시작하기

**대상:** 초보자 — Openterface KVM 장치의 처음 사용자

---

## 1. KVM-over-USB란 무엇인가?

KVM (Keyboard, Video, Mouse) 장치는 **호스트 컴퓨터** (작업 스테이션)과 **타겟 컴퓨터** (서버, 미니 PC, 삽입 장치) 사이에 있습니다. 이 장치는:

- **타겟의 HDMI 비디오 출력을 잡아** (음성도 있으면)
- **HID 에뮬레이션을 통해 키보드와 마우스 입력을 중계**합니다

모두 단일 USB 케이블을 통해 — 네트워크가 필요하지 않습니다.

이것이 KVM 장치의 특징입니다: 원격 데스크톱 소프트웨어와는 달리, BIOS/UEFI에서, 부팅 중에 또는 시스템이 무너졌을 때까지 타겟을 제어할 수 있습니다.

### Openterface KVM 장치

| 장치 | 형태 | 주요 기능 |
|------|------------|-------------|
| **Mini-KVM** | 컴팩트 USB 동글 | 데스크톱 KVM-over-USB |
| **KVM-Go** | 툴킷 스타일 포ータ블 | 이동식 KVM, 내장 케이블 포함, **iPadOS 지원을 위한 BLE 지원** |
| **uConsole KVM 확장** | 내부 모듈 | ClockworkPi uConsole에 내장된 KVM |

> KeyMod(키보드 및 마우스 에뮬레이터만, 비디오 없음)을 찾으시다면 [KeyMod 튜토리얼](../../keymod/index.md)을 보세요.

## 2. 필요한 것들

### 하드웨어

- **Openterface KVM 장치** — Mini-KVM, KVM-Go 또는 uConsole KVM 확장
- **호스트 컴퓨터** — macOS, Windows, Linux, 또는 Android 운영 체제 실행 중
- **타겟 컴퓨터** — HDMI 출력이 있는 어떤 컴퓨터든
- **HDMI 케이블** — 타겟의 HDMI 출력에서 KVM의 HDMI 입력으로
- **USB 케이블** — KVM에서 호스트 컴퓨터의 USB 포트로 (전원과 데이터를 제공)

### 선택 사항

- **USB 스위치 케이블** — KVM에서 타겟 장치의 USB 포트로 연결(키보드/마우스 에뮬레이션)
- **키보드 및 마우스** — KVM의 USB 스위치 가능한 포트에 연결하여 호스트 또는 타겟을 제어

### 호스트 애플리케이션

| 플랫폼 | 애플리케이션 | 다운로드 |

| **iPadOS** | Openterface for iPadOS | [App Store](/app/ipados/) — **KVM-Go만** |

### Android 요구 사항

Android 앱은 다음을 필요로 합니다:

- **Android 8.0 (API 26)** 이상
- **USB OTG 지원** — 대부분의 현대 스마트폰이 이를 지원합니다 (Samsung, Google Pixel, OnePlus). 연결 USB 플래시 드라이브를 OTG 어댑터로 확인하세요
- **USB OTG 케이블 또는 어댑터** — KVM 장치를 스마트폰에 연결하기 위해

### iPadOS 요구 사항

iPadOS 앱은 다음을 필요로 합니다:

- **iPadOS 17.0** 이상
- **KVM-Go 장치** — iPadOS는 KVM-Go 동글을 BLE(블루투스 높은 에너지)를 통해 키보드/마우스 입력, USB 캡처 카드를 통해 비디오를 연결합니다
- **카메라 및 마이크 권한** — 비디오 미리보기와 캡처 카드에서의 오디오 모니터링을 위해 필요합니다
- **블루투스 권한** — KVM-Go 동글과 HID 입력을 위한 연결을 위해 필요합니다
- **사진 라이브러리 권한**(선택 사항) — 캡처를 저장하기 위해

### macOS 권한

마지막 시작 시, macOS는 다음 권한 요청할 수 있습니다:

| 권한 | 왜? |
|-----------|-----|
| **카메라** | HDMI 캡처 칩에서 비디오를 잡습니다 |
| **마이크** | 타겟에서 오디오를 모니터링합니다 (활성화 시) |
| **접근성** | HID 마우스 제어를 위한 레일 모드 |

### Linux 권한

- 사용자에게 `dialout` 및 `video` 그룹에 추가: `sudo usermod -a -G dialout,video $USER`
- 장치 액세스용 udev 규칙 설치
- **BrlTTY 충돌:** `brltty` 제거 또는 시리얼 칩 검은 목록 — [고장 해결](04-troubleshooting.md#brltty-충돌-linux)

### Windows

- 설치 파일에는 CH340 시리얼 드라이버가 포함되어 있습니다. 포터블 버전은 따로 설치해야 합니다.

## 4. 하드웨어 연결

┌─────────────┐                        ┌──────────────────┐
│   TARGET    │─── HDMI cable ────────▶│  Openterface     │
│  COMPUTER   │                        │  KVM Device      │
└─────────────┘                        │                  │
                                       │  ◄── USB cable ──│── USB switch cable ──▶ Target USB port
                                       └──────────────────┘
                                                │
                                                ▼
                                       ┌──────────────────┐
                                       │   HOST COMPUTER  │
                                       │  (this app)      │
                                       └──────────────────┘
1. 타겟의 **HDMI 출력**을 KVM의 **HDMI 입력**으로 연결하세요
2. KVM의 **USB**를 호스트 컴퓨터의 USB 포트에 연결하세요
3. (선택 사항) KVM에서 USB 스위치 케이블을 타겟의 USB 포트로 연결하세요
4. (선택 사항) 키보드/마우스를 KVM의 USB 스위치 가능한 포트에 연결하세요
5. **타겟 장치**를 켜세요

### 장치 식별

KVM은 여러 USB 장치로 인식됩니다:
- **비디오 캡처** (MS2109/MS2109S/MS2130S) — 웹캠으로 나타납니다
- **시리얼** (CH9329 또는 CH32V208) — `/dev/ttyUSB*` (Linux), `COM*` (Windows), `cu.usbserial-*` (macOS)
- **HID** — 기어 조작을 위한 기어 조작

### Android 장치 연결

Android 앱 사용 시, 연결 체인은 USB OTG를 사용합니다:

┌──────────────┐     HDMI      ┌──────────────────┐
│              │ ────────────▶ │   Openterface     │
│  Target PC   │               │   KVM Device      │
│  (screen)    │ ◀─────────── │                   │
│              │     USB       │                   │
└──────────────┘               └────────┬─────────┘
                                        │
                                   USB OTG
                                        │
                               ┌─────────▼─────────┐
                               │  Android Phone    │
                               │  (Openterface)    │
                               └──────────────────┘
```

Android 연결 순서:

1. **HDMI:** 타겟의 HDMI 출력을 KVM의 HDMI **입력**으로 연결하세요
2. **USB (타겟):** 타겟의 USB 포트를 KVM의 USB 포트에 연결 — 마우스/키보드 신호 전송
3. **USB OTG (폰):** KVM을 Android 폰에 USB OTG 케이블/어댑터를 통해 연결하세요
4. **전원:** KVM 장치(독립적인 전원 공급이 있는 경우)와 타겟 컴퓨터를 켜세요

성공적으로 연결되면, 비디오 미리보기가 임시 화면에서 타겟의 실시간 화면으로 전환되고, 폰 스크린을 터치하면 타겟에 커서가 이동합니다.

### iPadOS 장치 연결

iPadOS 앱은 다른 연결 모델을 사용합니다: **BLE를 위한 입력** 및 **USB 캡처를 위한 비디오**.

```
┌──────────────┐     HDMI      ┌──────────────────┐
│              │ ────────────▶ │   KVM-Go Dongle   │
│  Target PC   │               │                   │
│  (screen)    │ ◀─── USB ──── │                   │
└──────────────┘               └────────┬─────────┘
                                        │
                              ┌─────────┴─────────┐
                              │   USB Capture     │ (비디오)
                              │   BLE (FFF2)      │ (키보드/마우스)
                              └─────────┬─────────┘
                                        │
                              ┌─────────▼─────────┐
                              │     iPad           │
                              │  (Openterface)     │
                              └───────────────────┘
```

iPadOS 연결 순서:

1. **하드웨어:** KVM-Go 동글을 타겟 PC의 USB 포트에 연결하고 HDMI 입력을 연결하세요
2. **타겟 컴퓨터 켜기**
3. **아이패드 앱 열기**와 카메라, 마이크, 블루투스 권한 승인
4. **블루투스 버튼 클릭** — 앱은 `kvm*` 이름을 가진 장치를 스캔합니다
5. **KVM-Go 장치 옆에 있는 연결 버튼 클릭** — 버튼이 RSSI 신호 강도와 함께 녹색으로 변합니다
6. **확인:** 비디오 미리보기가 타겟의 화면을 보이고, 터치하면 클릭이 보내지고, 입력하면 키보드가 전송됩니다

> **참고:** iPadOS 앱은 KVM-Go만 지원합니다. Mini-KVM 및 uConsole KVM 확장에는 BLE 지원이 없습니다.

### 메인 윈도우

```
┌─────────────────────────────────────────────────────────┐
│  메뉴 바 / 툴바                                     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│              비디오 표시 영역                          │

│                                                         │
├─────────────────────────────────────────────────────────┤
│  상태 바 │ 포트 │ 키보드 │ 마우스 │ 해상도 │        │
└─────────────────────────────────────────────────────────┘
```

### Android 권한

첫 시작 시, Android 앱은 다음 권한 요청할 수 있습니다:

| 권한 | 왜? | 거부하면 무엇이 발생하나요 |
|---|---|---|
| **USB 호스트** | Openterface 하드웨어와 통신 | KVM 장치를 감지할 수 없음 |
| **카메라** | HDMI 캡처 칩에서 비디오를 받기 | 미리보기 없음 |
| **스토리지** | 캡처를 저장하기 | 캡처를 저장할 수 없음 |

전체 기능을 위해 모든 권한을 승인하세요. KVM 장치가 감지될 때 시스템 USB 권한 대화상자가 나타납니다 — 허용 버튼을 누릅니다.

### iPadOS 권한

첫 시작 시, iPadOS 앱은 다음 권한 요청할 수 있습니다:

| 권한 | 왜? | 거부하면 무엇이 발생하나요 |
|---|---|---|
| **카메라** | HDMI 캡처 칩에서 비디오를 받기 | 미리보기 없음 |
| **마이크** | 타겟 PC 오디오 모니터링을 iPad 스피커로 | 오디오 모니터링 없음 |
| **블루투스** | KVM-Go와 HID 입력을 위한 연결 및 검색 | 키보드/마우스 입력 전송 불가 |
| **사진 라이브러리** | 캡처를 저장하기 | 캡처를 앱 문서 폴더에 저장 |

권한이 거부되었을 경우, **설정 > 사생활 & 보안**로 돌아가서 재활성화하세요.

### 연결 확인

- **HDMI 표시:** 녹색 = 신호 감지, 오렌지 = 신호 없음, 회색 = 미지
- **키보드 표시:** 녹색 = 연결됨, 오렌지 = 찾기 실패, 회색 = 미지
- **마우스 표시:** 녹색 = 연결됨, 오렌지 = 찾기 실패, 회색 = 미지
- **시리얼 포트:** 이름과 baud rate(9600 또는 115200)가 표시되어야 합니다

표시가 오렌지나 회색일 경우, [고장 해결](04-troubleshooting.md)를 참조하세요.

## 6. 기본 KVM 제어

### 마우스 모드

| 모드 | 설명 | 가장 적합한 |
|------|-------------|----------|
| **절대** (기본값) | 호스트 커서가 타겟 화면에 직접 매핑됩니다 | 일반 사용, GUI 이동 |
| **상대적 (HID)** | HID를 통해 마우스 움직임을 델타로 전송합니다 | 게임, 빠른 상호작용 |

툴바 토글 또는 **Control > 마우스 모드**를 통해 전환하세요.

### 키보드 입력

모든 키 입력은 애플리케이션 창이 초점일 때마다 타겟으로 전송됩니다:
- 표준 키, 기능 키, 모디피케이터
- 특수 키: Ctrl+Alt+Del, Print Screen
- **붙여넣기:** 클립보드 텍스트를 에뮬레이션 키보드 입력으로 전송합니다

### USB 스위치

USB 스위치 가능한 포트를 다음과 같이 전환하세요:
- **호스트** — 키보드/마우스는 호스트 컴퓨터를 제어합니다
- **타겟** — 키보드/마우스는 타겟 컴퓨터를 제어합니다
