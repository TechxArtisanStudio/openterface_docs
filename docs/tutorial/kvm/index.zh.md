# KVM 软件教程

> 全面的KVM-over-USB：在同一个设备上控制目标的键盘、视频和鼠标。

本教程涵盖Openterface KVM系列——这些设备可以捕捉目标的HDMI视频输出，并通过HID模拟将键盘/鼠标输入传递过去：

- **Mini-KVM** — 紧凑型USB KVM适配器
- **KVM-Go** — 工具箱形式的便携式KVM
- **uConsole KVM扩展** — uConsole内置的KVM

> **平台：**macOS、Windows、Linux（桌面应用程序）、Android（移动应用）和iPadOS（平板电脑应用）。Android特定和iPadOS特定的注释在整个教程中都有标记。
> **注意：**仅在KVM-Go上支持iPadOS——iPadOS应用通过蓝牙LE连接到KVM-Go适配器。

> 寻找KeyMod（仅键盘与鼠标模拟器）？参见[KeyMod教程](../keymod/index.md)。
