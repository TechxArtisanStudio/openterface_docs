# Tutorial pentru Software KVM

> Controlul tastaturii, video și mouse-ului prin un singur dispozitiv.

Această tutoriale abordează seria **Openterface KVM** — dispozitive care capturează output-ul HDMI al țintei și retransmitem intrarea de tastatură/mouse prin emulare HID:

- **Mini-KVM** — Adaptor USB compact KVM
- **KVM-Go** — KVM portabil într-un format de cutie de instrumente
- **uConsole KVM Extension** — KVM incorporat pentru uConsole

> **Platforme:** macOS, Windows, Linux (aplicații desktop), **Android** (aplicație mobilă) și **iPadOS** (aplicație tableta). Notițe specifice pentru Android și iPadOS sunt menționate pe parcurs.
> **Observație:** iPadOS este doar suportat pe KVM-Go — aplicația iPadOS se conectează prin Bluetooth LE la dongle-ul KVM-Go.

> Căutând **KeyMod** (doar emulator pentru tastatură și mouse)? Vezi [tutoriale KeyMod](../keymod/index.md).
