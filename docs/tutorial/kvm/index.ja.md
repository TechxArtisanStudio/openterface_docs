# KVMソフトウェアチュートリアル

> USB経由のフルKVM：キーボード、ビデオ、マウスを1つのデバイスで制御。

このチュートリアルでは **Openterface KVMシリーズ** をカバーします。これらのデバイスはターゲットのHDMIビデオ出力をキャプチャし、キーボード/マウス入力を通じてHIDエミュレーションを介してリレーします：

- **Mini-KVM** — コンパクトなUSB KVMアダプター
- **KVM-Go** — ツールキット形式のポータブルKVM
- **uConsole KVM拡張** — uConsoleに内蔵されたKVM

> **プラットフォーム:** macOS、Windows、Linux（デスクトップアプリ）、Android（モバイルアプリ）およびiPadOS（タブレットアプリ）。Android向けとiPadOS向けの注釈は随所に記載されています。
> **注意:** iPadOSは**KVM-Goのみでサポートされます** — iPadOSアプリはKVM-GoドングルをBluetooth LE経由で接続します。

> KeyMod（キーボード&マウスエミュレータのみ）を探している？ [KeyModチュートリアル](../keymod/index.md) を参照してください。
