# KVM Tutorial 01 — Начало работы

**Аудитория:** Начинающие — пользователи, впервые работающие с устройствами KVM Openterface

---

## 1. Что такое KVM-over-USB?

Устройство KVM (Keyboard, Video, Mouse) располагается между **хост-компьютером** (вашей рабочей станцией) и **целевым компьютером** (сервер, мини-ПК, встроенное устройство). Оно:

- **Захватывает** HDMI-видеовыход целевого устройства (и аудио, если доступно)
- **Передаёт** ввод с клавиатуры и мыши через эмуляцию HID
- Всё через один USB-кабель — сеть не требуется

Именно это отличает KVM-устройства от программ удалённого рабочего стола: вы можете управлять целевым устройством даже в **BIOS/UEFI**, при загрузке или когда ОС зависла.

### Устройства KVM Openterface

| Устройство | Форм-фактор | Ключевая особенность |
|--------|------------|-------------|
| **Mini-KVM** | Компактный USB-донгл | Настольный KVM-over-USB |
| **KVM-Go** | Портативный, в стиле набора инструментов | Мобильный KVM со встроенными кабелями, **поддержка iPadOS через BLE** |
| **uConsole KVM Extension** | Внутренний модуль | Встроенный KVM для ClockworkPi uConsole |

> Ищете **KeyMod** (только эмулятор клавиатуры и мыши, без видео)? См. [Tutorial KeyMod](../../keymod/index.md).

## 2. Что вам понадобится

### Оборудование

- **Устройство KVM Openterface** — Mini-KVM, KVM-Go или uConsole KVM Extension
- **Хост-компьютер** — С macOS, Windows, Linux или Android
- **Целевой компьютер** — Любой компьютер с HDMI-выходом
- **HDMI-кабель** — От HDMI-выхода целевого устройства к HDMI-входу KVM
- **USB-кабель** — От KVM к хост-компьютеру (питание и данные)

### Дополнительно

- **USB-кабель переключения** — От KVM к USB-порту целевого устройства (для эмуляции клавиатуры/мыши)
- **Клавиатура и мышь** — Подключите к переключаемому USB-порту KVM для управления хостом или целевым устройством

## 3. Установка

### Хост-приложение

| Платформа | Приложение | Загрузка |
|----------|------------|----------|
| **macOS** | Openterface for macOS | [App Store](/appstore) или [DMG](app/mmacos/dmg-installation.md) |
| **Windows** | Openterface QT | [GitHub Releases](https://github.com/TechxArtisanStudio/Openterface_QT/releases) |
| **Linux** | Openterface QT | [Flatpak](https://flathub.org/apps/com.openterface.openterfaceQT), .deb, .rpm, AppImage |
| **Android** | Openterface for Android | [Google Play](https://play.google.com/store/apps/details?id=com.openterface.AOS) или [GitHub Releases](https://github.com/TechxArtisanStudio/Openterface_Android/releases) |
| **iPadOS** | Openterface for iPadOS | [App Store](/app/ipados/) — **только KVM-Go** |

### Требования Android

Приложение Android требует:

- **Android 8.0 (API 26)** или новее
- **Поддержку USB OTG** — большинство современных телефонов её поддерживают (Samsung, Google Pixel, OnePlus). Проверьте, подключив USB-накопитель через OTG-адаптер
- **USB OTG-кабель или адаптер** для подключения KVM-устройства к телефону

### Требования iPadOS

Приложение iPadOS требует:

- **iPadOS 17.0** или новее
- **Устройство KVM-Go** — iPadOS подключается к донглу KVM-Go через **Bluetooth Low Energy (BLE)** для ввода с клавиатуры/мыши и к USB-карте захвата для видео
- **Разрешения камеры и микрофона** — необходимы для предпросмотра видео и мониторинга аудио с карты захвата
- **Разрешение Bluetooth** — необходимо для обнаружения и подключения донгла KVM-Go для HID-ввода
- **Разрешение медиатеки** (необязательно) — для сохранения скриншотов и записей в приложение «Фото»

### Разрешения macOS

При первом запуске macOS запросит:

| Разрешение | Зачем |
|-----------|-----|
| **Камера** | Захват видео с HDMI-чипа захвата |
| **Микрофон** | Захват аудио с целевого устройства (если включено) |
| **Универсальный доступ** | Необходимо для HID-управления мышью в относительном режиме |

### Разрешения Linux

- Добавьте пользователя в группы `dialout` и `video`: `sudo usermod -a -G dialout,video $USER`
- Установите правила udev для доступа к устройству
- **Конфликт BrlTTY:** удалите `brltty` или добавьте serial-чип в чёрный список — см. [Устранение неполадок](04-troubleshooting.md#brltty-conflict-linux)

### Windows

- Установщик включает serial-драйвер CH340. Для portable-сборок установите его отдельно.

## 4. Подключение оборудования

┌─────────────┐                        ┌──────────────────┐
│   ЦЕЛЕВОЙ   │─── HDMI-кабель ───────▶│  Openterface     │
│  КОМПЬЮТЕР  │                        │  KVM-устройство  │
└─────────────┘                        │                  │
                                       │  ◄── USB-кабель │── USB-кабель переключения ──▶ USB-порт цели
                                       └──────────────────┘
                                                │
                                                ▼
                                       ┌──────────────────┐
                                       │  ХОСТ-КОМПЬЮТЕР  │
                                       │  (это приложение)│
                                       └──────────────────┘
1. Подключите **HDMI-выход** целевого устройства к **HDMI-входу** KVM
2. Подключите **USB** KVM к **USB-порту хост-компьютера**
3. (Необязательно) Подключите USB-кабель переключения от KVM к USB-порту целевого устройства
4. (Необязательно) Подключите клавиатуру/мышь к переключаемому USB-порту KVM
5. **Включите** целевое устройство

### Обнаружение устройства

KVM определяется как несколько USB-устройств:
- **Захват видео** (MS2109/MS2109S/MS2130S) — отображается как веб-камера
- **Serial** (CH9329 или CH32V208) — `/dev/ttyUSB*` (Linux), `COM*` (Windows), `cu.usbserial-*` (macOS)
- **HID** — используется для операций с прошивкой

### Подключение через телефон Android

При использовании приложения Android цепочка подключения использует USB OTG:

┌──────────────┐     HDMI      ┌──────────────────┐
│              │ ────────────▶ │   Openterface     │
│  Целевой ПК  │               │   KVM-устройство  │
│  (экран)     │ ◀─────────── │                   │
│              │     USB       │                   │
└──────────────┘               └────────┬─────────┘
                                        │
                                   USB OTG
                                        │
                               ┌────────▼─────────┐
                               │  Телефон Android  │
                               │  (Openterface)    │
                               └──────────────────┘
```

Порядок подключения для Android:

1. **HDMI:** подключите HDMI-выход целевого устройства к HDMI-**входу** KVM
2. **USB (цель):** подключите USB-порт целевого устройства к USB-порту KVM — передаёт сигналы мыши/клавиатуры
3. **USB OTG (телефон):** подключите KVM к телефону Android через USB OTG-кабель/адаптер
4. **Питание:** включите KVM-устройство (если есть отдельный вход питания) и целевой компьютер

При успешном подключении предпросмотр видео переключается с заглушки на живой экран целевого устройства, а касание экрана телефона перемещает курсор на целевом устройстве.

### Подключение через iPadOS

Приложение iPadOS использует другую модель подключения: **BLE для ввода** и **USB-захват для видео**.

```
┌──────────────┐     HDMI      ┌──────────────────┐
│              │ ────────────▶ │   KVM-Go Dongle   │
│  Целевой ПК  │               │                   │
│  (экран)     │ ◀─── USB ──── │                   │
└──────────────┘               └────────┬─────────┘
                                        │
                              ┌─────────┴─────────┐
                              │   USB Capture     │ (видео)
                              │   BLE (FFF2)      │ (клавиатура/мышь)
                              └─────────┬─────────┘
                                        │
                              ┌─────────▼─────────┐
                              │     iPad           │
                              │  (Openterface)     │
                              └───────────────────┘
```

Порядок подключения для iPadOS:

1. **Оборудование:** подключите донгл KVM-Go к USB-порту целевого ПК и подключите HDMI-вход
2. **Включите** целевой компьютер
3. **Откройте приложение** на iPad и предоставьте разрешения камеры, микрофона и Bluetooth
4. **Нажмите кнопку BLE** на панели инструментов — приложение сканирует устройства с именами `kvm*`
5. **Нажмите Подключить** рядом с вашим устройством KVM-Go — кнопка становится зелёной с уровнем сигнала RSSI
6. **Проверьте:** предпросмотр видео показывает экран целевого устройства, касание отправляет клики, ввод отправляет нажатия клавиш

> **Примечание:** Приложение iPadOS работает только с **KVM-Go**. Mini-KVM и uConsole KVM Extension не поддерживают BLE.

### Главное окно

```
┌─────────────────────────────────────────────────────────┐
│  Строка меню / Панель инструментов                      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│              ОБЛАСТЬ ОТОБРАЖЕНИЯ ВИДЕО                  │
│         (показывает экран целевого устройства)          │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  Строка состояния │ Порт │ Клавиши │ Мышь │ Разрешение │
└─────────────────────────────────────────────────────────┘
```

### Разрешения Android

При первом запуске приложение Android запрашивает:

| Разрешение | Зачем | Что произойдёт при отказе |
|---|---|---|
| **USB Host** | Связь с оборудованием Openterface | Приложение не обнаружит KVM-устройство |
| **Камера** | Получение видео с HDMI-чипа захвата | Нет предпросмотра видео |
| **Хранилище** | Сохранение скриншотов и записей | Невозможно сохранить захваты |

Предоставьте все разрешения для полной функциональности. При обнаружении KVM-устройства также появляется системный диалог разрешения USB — нажмите **Разрешить**.

### Разрешения iPadOS

При первом запуске приложение iPadOS запрашивает:

| Разрешение | Зачем | Что произойдёт при отказе |
|---|---|---|
| **Камера** | Получение видео с HDMI-карты захвата | Нет предпросмотра видео |
| **Микрофон** | Мониторинг аудио целевого ПК через динамики iPad | Нет мониторинга аудио |
| **Bluetooth** | Обнаружение и подключение KVM-Go для HID-ввода | Невозможно отправить ввод с клавиатуры/мыши |
| **Медиатека** | Сохранение скриншотов и записей | Захваты всё равно сохраняются в папку Documents приложения |

Если вы случайно отклонили разрешение, перейдите в **Настройки > Конфиденциальность и безопасность**, чтобы включить его снова.

### Проверка подключения

- **Индикатор HDMI:** зелёный = сигнал обнаружен, оранжевый = нет сигнала, серый = неизвестно
- **Индикатор клавиатуры:** зелёный = подключено, оранжевый = не найдено, серый = неизвестно
- **Индикатор мыши:** зелёный = подключено, оранжевый = не найдено, серый = неизвестно
- **Serial-порт:** должен показывать имя порта и скорость (9600 или 115200)

Если индикаторы показывают оранжевый или серый, см. [Устранение неполадок](04-troubleshooting.md).

## 6. Базовое управление KVM

### Режимы мыши

| Режим | Описание | Лучше всего для |
|------|-------------|----------|
| **Абсолютный** (по умолчанию) | Курсор хоста напрямую сопоставляется с экраном цели | Общее использование, навигация GUI |
| **Относительный (HID)** | Движения мыши отправляются как дельты через HID | Игры, быстрое взаимодействие |

Переключайте через переключатель на панели инструментов или **Управление > Режим мыши**.

### Ввод с клавиатуры

Все нажатия клавиш передаются на целевое устройство, пока окно приложения в фокусе:
- Стандартные клавиши, функциональные клавиши, модификаторы
- Специальные клавиши: Ctrl+Alt+Del, Print Screen
- **Вставить в цель:** отправляет текст из буфера обмена как эмулированные нажатия клавиш

### Переключение USB

Переключайте переключаемый USB-порт между:
- **Хост** — клавиатура/мышь управляют хост-компьютером
- **Цель** — клавиатура/мышь управляют целевым компьютером
