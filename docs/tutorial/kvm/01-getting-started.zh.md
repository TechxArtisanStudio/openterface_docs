# KVM教程 01 — 开始使用

**受众：** 初学者 — 第一次使用 Openterface KVM 设备的用户

---

## 1. 什么是KVM-over-USB？

一个KVM（键盘、视频、鼠标）设备位于您的 **主机计算机** 和目标计算机之间。它：

- **捕获** 目标设备的HDMI视频输出（如果有音频，也会捕获）
- **转发** 您的键盘和鼠标输入通过 HID仿真
- 所有这些都通过一根USB线完成 — 不需要网络

这就是KVM设备与其他远程桌面软件的不同之处：即使在BIOS/UEFI模式下、启动时或操作系统崩溃后，您仍然可以控制目标计算机。

### Openterface KVM设备

| 设备 | 形状 | 关键特性 |
|------|-----|---------|
| **Mini-KVM** | 紧凑型USB便携式 | 桌面KVM-over-USB |
| **KVM-Go** | 工具箱风格便携式 | 随身携带的KVM，带有内置线缆，通过BLE支持iPadOS |
| **uConsole KVM扩展** | 内置模块 | ClockworkPi uConsole集成的内置KVM |

> 想要KeyMod（仅键盘和鼠标仿真器）？请参阅[KeyMod教程](../../keymod/index.md)。

---

## 2. 需要什么

### 硬件

- **Openterface KVM设备** — Mini-KVM、KVM-Go或uConsole KVM扩展
- **主机计算机** — 运行macOS、Windows、Linux或Android的电脑
- **目标计算机** — 任何具有HDMI输出的电脑
- **HDMI线缆** — 从目标的HDMI输出到KVM的HDMI输入
- **USB线缆** — 从KVM到您的主机计算机（提供电源和数据）

### 可选

- **USB切换线缆** — 从KVM到目标设备的USB端口（用于键盘/鼠标仿真）
- **键盘和鼠标** — 插入KVM的USB可切换端口以控制主机或目标

## 3. 安装

### 主机应用程序

| 平台 | 应用程序 | 下载 |
|-----|--------|----|
| **macOS** | Openterface for macOS | [App Store](/appstore) 或 [DMG](app/mmacos/dmg-installation.md) |
| **Windows** | Openterface QT | [GitHub发布](https://github.com/TechxArtisanStudio/Openterface_QT/releases) |
| **Linux** | Openterface QT | [Flatpak](https://flathub.org/apps/com.openterface.openterfaceQT)，.deb，.rpm，AppImage |
| **Android** | Openterface for Android | [Google Play](https://play.google.com/store/apps/details?id=com.openterface.AOS) 或 [GitHub发布](https://github.com/TechxArtisanStudio/Openterface_Android/releases) |
| **iPadOS** | Openterface for iPadOS | [App Store](/app/ipados/) — 只支持KVM-Go |

### Android要求

Android应用程序需要：

- **Android 8.0 (API 26)** 或更高版本
- **USB OTG支持** — 大多数现代手机都支持（三星、谷歌Pixel、一加）。验证方法：连接一个USB闪存驱动器到OTG适配器
- **USB OTG线缆或适配器**，用于将KVM设备连接到您的手机

### iPadOS要求

iPadOS应用程序需要：

- **iPadOS 17.0** 或更高版本
- **KVM-Go设备** — iPadOS通过Bluetooth Low Energy (BLE)与KVM-Godongle进行键盘/鼠标输入，通过USB捕获卡获取视频
- **相机和麦克风权限** — 需要用于视频预览和捕获卡音频监控
- **蓝牙权限** — 必须发现并连接到KVM-Godongle以发送HID输入
- **相册权限**（可选）— 保存截图和录制到照片应用

### macOS权限

首次启动时，macOS将请求：

| 权限 | 原因 |
|----|-----|
| **相机** | 捕获来自HDMI捕获芯片的视频 |
| **麦克风** | 捕获目标设备的音频（如果启用） |
| **辅助功能** | 必要用于相对模式下的HID鼠标控制 |

### Linux权限

- 将用户添加到`dialout`和`video`组：`sudo usermod -a -G dialout,video $USER`
- 安装udev规则以访问设备
- **BrlTTY冲突**：移除`brltty`或黑名单串行芯片 — 参见[故障排除](04-troubleshooting.md#brltty-conflict-linux)

### Windows

- 安装程序捆绑了CH340串行驱动。对于便携式构建，单独安装。

## 4. 连接硬件

┌─────────────┐                        ┌──────────────────┐
│   目标      │─── HDMI线缆 ────────▶│ Openterface     │
│ 计算机      │                        │ KVM设备        │
└─────────────┘                        │                  │
                                       │ ◄── USB线缆 ──│── USB切换线缆 ──▶ 目标USB端口
                                       └──────────────────┘
                                                │
                                                ▼
                                       ┌──────────────────┐
                                       │   主机计算机     │
                                       │ (此应用程序)    │
                                       └──────────────────┘
1. 将目标的 **HDMI输出** 连接到KVM的 **HDMI输入**
2. 将KVM的 **USB端口** 连接到主机计算机上的一个USB端口
3. （可选）将USB切换线缆从KVM连接到目标的USB端口
4. （可选）将键盘/鼠标插入KVM的USB可切换端口
5. **开启** 目标设备

### 设备检测

KVM枚举为多个USB设备：
- **视频捕获**（MS2109/MS2109S/MS2130S）— 出现为摄像头
- **串行**（CH9329或CH32V208）— `/dev/ttyUSB*` (Linux)， `COM*` (Windows)， `cu.usbserial-*` (macOS)
- **HID** — 用于固件操作

### 使用Android手机连接

使用Android应用程序时，连接链路通过USB OTG：

┌──────────────┐     HDMI      ┌──────────────────┐
│              │ ────────────▶ │   Openterface     │
│ 目标PC (屏幕) │               │   KVM设备        │
└──────────────┘               └────────┬─────────┘
                                        │
                                   USB OTG
                                        │
                               ┌─────────▼─────────┐
                               │  Android手机      │
                               │  (Openterface)    │
                               └───────────────────┘
```

Android连接顺序：

1. **HDMI**：将目标的HDMI输出连接到KVM的HDMI输入
2. **USB（目标）**：将目标的USB端口连接到KVM的USB端口 — 传输鼠标/键盘信号
3. **USB OTG（手机）**：通过USB OTG线缆/适配器将KVM连接到您的Android手机
4. **电源**：开启KVM设备（如果需要单独电源输入）和目标计算机

成功连接后，视频预览会从占位符切换到目标的实时屏幕，并且点击手机屏幕会在目标上移动光标。

### 使用iPadOS连接

iPadOS应用程序使用不同的连接模型：**BLE用于输入** 和 **USB捕获用于视频**。

```
┌──────────────┐     HDMI      ┌──────────────────┐
│              │ ────────────▶ │ KVM-Godongle    │
│ 目标PC (屏幕) │               │                   │
└──────────────┘               └────────┬─────────┘
                                        │
                              ┌─────────▼─────────┐
                              │   USB捕获         │ (视频)
                              │   BLE (FFF2)      │ (键盘/鼠标)
                              └─────────┬─────────┘
                                        │
                              ┌─────────▼─────────┐
                              │     iPad           │
                              │  (Openterface)     │
                              └───────────────────┘
```

iPadOS连接顺序：

1. **硬件**：将KVM-Godongle插入目标PC的USB端口并连接HDMI输入
2. **开启电源** 目标计算机
3. **打开应用程序** 并授予相机、麦克风和蓝牙权限
4. **点击BLE按钮** 在工具栏中 — 应用程序扫描名为`kvm*`的设备
5. **点击KVM-Go设备旁边的连接** — 按钮变为绿色并显示RSSI信号强度
6. **验证**：视频预览显示目标屏幕，点击发送点击，输入发送按键

> **注意**：iPadOS应用程序仅支持KVM-Go。Mini-KVM和uConsole KVM扩展不支持BLE。

## 5. 第一次启动

### 主要窗口

```
┌─────────────────────────────────────────────────────────┐
│ Menu Bar / 工具栏                                     │
├─────────────────────────────────────────────────────────┤
│                                                         │
│              视频显示区域                              │
│         (显示目标设备屏幕)                           │
│                                                         │
├─────────────────────────────────────────────────────────┤
│ 状态栏 │ 口径 │ 键盘 │ 鼠标 │ 分辨率 │        │
└─────────────────────────────────────────────────────────┘
```

### Android权限

首次启动时，Android应用程序请求：

| 权限 | 原因 | 拒绝后会发生什么 |
|---|---|---|
| **USB主机** | 与Openterface硬件通信 | 应用程序无法检测到您的KVM设备 |
| **相机** | 接收来自HDMI捕获芯片的视频 | 无视频预览 |
| **存储** | 保存截图和录制内容 | 无法保存捕获 |

授予所有权限以获得完整功能。当检测到KVM设备时，还会出现系统USB权限对话框 — 点击**允许**。

### iPadOS权限

首次启动时，iPadOS应用程序请求：

| 权限 | 原因 | 拒绝后会发生什么 |
|---|---|---|
| **相机** | 接收来自HDMI捕获卡的视频 | 无视频预览 |
| **麦克风** | 监听目标PC音频通过iPad扬声器 | 无法监听音频 |
| **蓝牙** | 发现并连接到KVM-Go以发送HID输入 | 无法发送键盘/鼠标输入 |
| **相册库** | 保存截图和录制内容 | 捕获的图像仍保存在应用程序文档文件夹中 |

如果您不小心拒绝了权限，请前往**设置 > 隐私与安全**重新启用。

### 验证连接

- **HDMI指示器**：绿色 = 接收到信号，橙色 = 无信号，灰色 = 不明
- **键盘指示器**：绿色 = 连接，橙色 = 未找到，灰色 = 不明
- **鼠标指示器**：绿色 = 连接，橙色 = 未找到，灰色 = 不明
- **串行端口**：应显示一个端口号和波特率（9600或115200）

如果指示器显示橙色或灰色，请参阅[故障排除](04-troubleshooting.md)。

## 6. 基本KVM控制

### 鼠标模式

| 模式 | 描述 | 最佳用途 |
|------|-------------|----------|
| **绝对**（默认） | 主机光标直接映射到目标屏幕 | 广泛使用，GUI导航 |
| **相对 (HID)** | 鼠标的移动通过HID以增量形式发送 | 游戏，快速交互 |

通过工具栏切换或**控制 > 鼠标模式**进行切换。

### 键盘输入

所有按键在应用程序窗口聚焦时转发到目标设备：
- 标准键、功能键、修饰符
- 特殊键：Ctrl+Alt+Del, Print Screen
- **粘贴到目标**：将剪贴板文本作为仿真按键发送

### USB切换

在USB可切换端口之间进行切换：
- **主机** — 您的键盘/鼠标控制主机计算机
- **目标** — 您的键盘/鼠标控制目标计算机
