# Tutorial de Software KVM

> Controle completo do KVM por USB: controle do teclado, vídeo e mouse em um único dispositivo.

Este tutorial abrange a **série Openterface KVM** — dispositivos que capturam a saída de vídeo HDMI da alvo e reenviam o input de teclado/mouse através da emulação HID:

- **Mini-KVM** — Adaptador USB compacto KVM
- **KVM-Go** — KVM portátil no formato de ferramenta
- **Extensão KVM uConsole** — KVM embutido para o uConsole

> **Plataformas:** macOS, Windows, Linux (aplicativos desktop), **Android** (aplicativo mobile) e **iPadOS** (aplicativo tablet). Notas específicas para Android e iPadOS estão marcadas ao longo do texto.
> **Nota:** O iPadOS é **suportado apenas no KVM-Go** — o aplicativo iPadOS se conecta via Bluetooth LE ao dongle KVM-Go.

> Buscando **KeyMod** (apenas emulador de teclado e mouse)? Veja o [tutorial do KeyMod](../keymod/index.md).
