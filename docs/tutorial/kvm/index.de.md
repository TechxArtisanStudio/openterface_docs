# KVM-Software-Tutorial

> Vollständige KVM über USB: Tastatur, Bildschirm und Maussteuerung in einem Gerät.

Diese Anleitung umfasst die **Openterface KVM-Serie** — Geräte, die das Zielbildschirmausgang auf HDMI aufnehmen und die Tastatureingaben/Maussteuerung über HID-Emulation weiterleiten:

- **Mini-KVM** — kompakter USB-KVM-Adapter
- **KVM-Go** — tragbarer KVM im Werkzeugkastenformat
- **uConsole KVM-Erweiterung** — integrierter KVM für die uConsole

> **Plattformen:** macOS, Windows, Linux (Desktop-Anwendungen), **Android** (Mobile-Anwendung) und **iPadOS** (Tablet-Anwendung).
> Android-spezifische und iPadOS-spezifische Hinweise sind im gesamten Text markiert.
> **Hinweis:** iPadOS wird nur von KVM-Go unterstützt — die iPadOS-App verbindet sich über Bluetooth LE zum KVM-Go-Dongle.

> Suchen Sie nach **KeyMod** (nur Tastatur & Mausemulator)? Siehe den [KeyMod-Tutorial](../keymod/index.md).
