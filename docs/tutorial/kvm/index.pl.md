# KVM Software Tutorial

> Full KVM-over-USB: kontrola klawiatury, ekranu i myszki w jednym urządzeniu.

Tutaj znajdziesz szczegółowy przewodnik po serii **Openterface KVM** — urządzeniach, które zapisują wyjście HDMI urządzenia docelowego i przekazują wejścia klawiatury/myszki poprzez emulację HID:

- **Mini-KVM** — kompaktowy adapter USB KVM
- **KVM-Go** — przenośny KVM w formacie narzędziowym
- **uConsole KVM Extension** — wbudowany KVM dla uConsole

> **Platformy:** macOS, Windows, Linux (aplikacje stacjonarne), **Android** (aplikacja mobilna) i **iPadOS** (aplikacja tabletkowa).
> Uwagi dotyczące Androida i iPadOS są podkreślone w całym przewodniku.
> **Uwaga:** iPadOS jest obsługiwany tylko przez KVM-Go — aplikacja iPadOS połącza się z urządzeniem poprzez Bluetooth LE.

> Szukasz **KeyMod** (tylko emulator klawiatury i myszy)? Zobacz przewodnik [KeyMod](../keymod/index.md).
