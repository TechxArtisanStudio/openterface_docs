# KVM 軟件教程

> 全面的KVM-over-USB：在同一個設備上控制目標的鍵盤、視頻和鼠標。

本教程涵蓋Openterface KVM系列——這些設備可以捕捉目標的HDMI視頻輸出，並通過HID模擬將鍵盤/鼠標輸入傳遞過去：

- **Mini-KVM** — 緊湊型USB KVM適配器
- **KVM-Go** — 工具箱形式的便攜式KVM
- **uConsole KVM擴展** — uConsole內置的KVM

> **平台：**macOS、Windows、Linux（桌面應用程序）、Android（移動應用）和iPadOS（平板電腦應用）。Android特定和iPadOS特定的註釋在整個教程中都有標記。
> **注意：**僅在KVM-Go上支持iPadOS——iPadOS應用通過藍牙LE連接到KVM-Go適配器。

> 尋找KeyMod（僅鍵盤與鼠標模擬器）？參見[KeyMod教程](../keymod/index.md)。
