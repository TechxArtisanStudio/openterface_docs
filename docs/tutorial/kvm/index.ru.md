# КВМ-ПО: Учебник по использованию

> Полное управление KVM через USB: управление клавиатурой, видеосигналом и мышью в одном устройстве.

Этот учебник покрывает серию **Openterface KVM** — устройства, которые захватывают видеоизображение с HDMI целевого устройства и передают ввод с клавиатуры/мышью через эмуляцию HID:

- **Mini-KVM** — компактный USB адаптер KVM
- **KVM-Go** — переносимый KVM в формфакторе набора инструментов
- **uConsole KVM Extension** — встроенный KVM для uConsole

> **Платформы:** macOS, Windows, Linux (приложения на рабочем столе), **Android** (мобильное приложение) и **iPadOS** (приложение для планшета).
> Заметки по Android-специфическим и iPadOS-специфическим функциям приведены в тексте.
> **Примечание:** iPadOS поддерживается только на KVM-Go — приложение для iPadOS подключается к KVM-Go через Bluetooth LE.

> Ищете **KeyMod** (только эмулятор клавиатуры и мыши)? См. [Учебник по KeyMod](../keymod/index.md).
