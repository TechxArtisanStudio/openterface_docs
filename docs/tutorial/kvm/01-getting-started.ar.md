# درس KVM 01 — البدء

**الجمهور:** المبتدئون — مستخدمو أجهزة Openterface KVM لأول مرة

---

## 1. ما هو KVM-over-USB؟

يجلس جهاز KVM (لوحة المفاتيح، الفيديو، الماوس) بين **الكمبيوتر المضيف** (محطة عملك) و**الكمبيوتر الهدف** (خادم، كمبيوتر صغير، جهاز مدمج). يقوم بـ:

- **التقاط** مخرجات فيديو HDMI للهدف (والصوت، إن وُجد)
- **إعادة توجيه** إدخالات لوحة المفاتيح والفأرة عبر محاكاة HID
- كل ذلك عبر كابل USB واحد — دون الحاجة إلى شبكة

هذا ما يميز أجهزة KVM عن برامج سطح المكتب البعيد: يمكنك التحكم في الهدف حتى في **BIOS/UEFI**، أثناء الإقلاع، أو عند تعطل نظام التشغيل.

### أجهزة Openterface KVM

| الجهاز | الشكل | الميزة الرئيسية |
|--------|------------|-------------|
| **Mini-KVM** | محول USB مدمج | KVM-over-USB لسطح المكتب |
| **KVM-Go** | محمول بأسلوب صندوق أدوات | KVM متنقل مع كابلات مدمجة، **دعم iPadOS عبر BLE** |
| **uConsole KVM Extension** | وحدة داخلية | KVM مدمج لـ ClockworkPi uConsole |

> تبحث عن **KeyMod** (محاكي لوحة مفاتيح وماus فقط، بدون فيديو)؟ راجع [درس KeyMod](../../keymod/index.md).

---

## 2. ما تحتاجه

### الأجهزة

- **جهاز Openterface KVM** — Mini-KVM أو KVM-Go أو uConsole KVM Extension
- **كمبيوتر مضيف** — يعمل بنظام macOS أو Windows أو Linux أو Android
- **كمبيوتر هدف** — أي كمبيوتر بمخرج HDMI
- **كابل HDMI** — من مخرج HDMI للهدف إلى مدخل HDMI لجهاز KVM
- **كابل USB** — من KVM إلى الكمبيوتر المضيف (يوفر الطاقة والبيانات)

### اختياري

- **كابل تبديل USB** — من KVM إلى منفذ USB لجهاز الهدف (للمحاكاة لوحة المفاتيح/الفأرة)
- **لوحة مفاتيح وماus** — توصيلهما بمنفذ USB القابل للتبديل في KVM للتحكم في المضيف أو الهدف

## 3. التثبيت

### تطبيق المضيف

| المنصة | التطبيق | التحميل |
|----------|------------|----------|
| **macOS** | Openterface for macOS | [App Store](/appstore) أو [DMG](app/mmacos/dmg-installation.md) |
| **Windows** | Openterface QT | [GitHub Releases](https://github.com/TechxArtisanStudio/Openterface_QT/releases) |
| **Linux** | Openterface QT | [Flatpak](https://flathub.org/apps/com.openterface.openterfaceQT)، .deb، .rpm، AppImage |
| **Android** | Openterface for Android | [Google Play](https://play.google.com/store/apps/details?id=com.openterface.AOS) أو [GitHub Releases](https://github.com/TechxArtisanStudio/Openterface_Android/releases) |
| **iPadOS** | Openterface for iPadOS | [App Store](/app/ipados/) — **KVM-Go فقط** |

### متطلبات Android

يتطلب تطبيق Android:

- **Android 8.0 (API 26)** أو أحدث
- **دعم USB OTG** — معظم الهواتف الحديثة تدعمه (Samsung، Google Pixel، OnePlus). تحقق بتوصيل محرك أقراص USB فلاش بمحول OTG
- **كابل أو محول USB OTG** لتوصيل جهاز KVM بهاتفك

### متطلبات iPadOS

يتطلب تطبيق iPadOS:

- **iPadOS 17.0** أو أحدث
- **جهاز KVM-Go** — يتصل iPadOS بمحول KVM-Go عبر **Bluetooth Low Energy (BLE)** لإدخال لوحة المفاتيح/الفأرة، وببطاقة التقاط USB للفيديو
- **أذونات الكاميرا والميكروفون** — مطلوبة لمعاينة الفيديو ومراقبة الصوت من بطاقة التقاط
- **إذن Bluetooth** — مطلوب لاكتشاف محول KVM-Go والاتصال به لإدخال HID
- **إذن مكتبة الصور** (اختياري) — لحفظ لقطات الشاشة والتسجيلات في تطبيق الصور

### أذونات macOS

عند أول تشغيل، سيطلب macOS:

| الإذن | السبب |
|-----------|-----|
| **الكاميرا** | يلتقط الفيديو من شريحة التقاط HDMI |
| **الميكروفون** | يلتقط الصوت من الهدف (إن كان مفعّلاً) |
| **إمكانية الوصول** | مطلوب للتحكم بالفأرة HID في الوضع النسبي |

### أذونات Linux

- أضف مستخدمك إلى مجموعتي `dialout` و`video`: `sudo usermod -a -G dialout,video $USER`
- ثبّت قواعد udev للوصول إلى الجهاز
- **تعارض BrlTTY:** أزل `brltty` أو ضع شريحة Serial في القائمة السوداء — راجع [حل المشكلات](04-troubleshooting.md#brltty-conflict-linux)

### Windows

- يتضمن المثبّت برنامج تشغيل CH340 التسلسلي. للإصدارات المحمولة، ثبّته بشكل منفصل.

## 4. توصيل الأجهزة

┌─────────────┐                        ┌──────────────────┐
│   الهدف     │─── كابل HDMI ────────▶│  Openterface     │
│  الكمبيوتر  │                        │  جهاز KVM        │
└─────────────┘                        │                  │
                                       │  ◄── كابل USB ──│── كابل تبديل USB ──▶ منفذ USB للهدف
                                       └──────────────────┘
                                                │
                                                ▼
                                       ┌──────────────────┐
                                       │  الكمبيوتر المضيف│
                                       │  (هذا التطبيق)   │
                                       └──────────────────┘
1. وصّل **مخرج HDMI** للهدف بـ **مدخل HDMI** لجهاز KVM
2. وصّل **USB** لجهاز KVM بـ **منفذ USB على الكمبيوتر المضيف**
3. (اختياري) وصّل كابل تبديل USB من KVM إلى منفذ USB للهدف
4. (اختياري) وصّل لوحة المفاتيح/الفأرة بمنفذ USB القابل للتبديل في KVM
5. **شغّل** جهاز الهدف

### اكتشاف الجهاز

يُعرَف KVM كأجهزة USB متعددة:
- **التقاط فيديو** (MS2109/MS2109S/MS2130S) — يظهر ككاميرا ويب
- **Serial** (CH9329 أو CH32V208) — `/dev/ttyUSB*` (Linux)، `COM*` (Windows)، `cu.usbserial-*` (macOS)
- **HID** — يُستخدم لعمليات البرامج الثابتة

### الاتصال عبر هاتف Android

عند استخدام تطبيق Android، تستخدم سلسلة الاتصال USB OTG:

┌──────────────┐     HDMI      ┌──────────────────┐
│              │ ────────────▶ │   Openterface     │
│  كمبيوتر     │               │   جهاز KVM        │
│  الهدف       │ ◀─────────── │                   │
│  (الشاشة)    │     USB       │                   │
└──────────────┘               └────────┬─────────┘
                                        │
                                   USB OTG
                                        │
                               ┌────────▼─────────┐
                               │  هاتف Android    │
                               │  (Openterface)   │
                               └──────────────────┘
```

ترتيب الاتصال لـ Android:

1. **HDMI:** وصّل مخرج HDMI للهدف بـ **مدخل** HDMI لجهاز KVM
2. **USB (الهدف):** وصّل منفذ USB للهدف بمنفذ USB لجهاز KVM — ينقل إشارات الفأرة/لوحة المفاتيح
3. **USB OTG (الهاتف):** وصّل KVM بهاتف Android عبر كابل/محول USB OTG
4. **الطاقة:** شغّل جهاز KVM (إن كان له مدخل طاقة منفصل) والكمبيوتر الهدف

عند الاتصال بنجاح، تنتقل معاينة الفيديو من العنصر النائب إلى شاشة الهدف المباشرة، والنقر على شاشة الهاتف يحرّك المؤشر على الهدف.

### الاتصال عبر iPadOS

يستخدم تطبيق iPadOS نموذج اتصال مختلف: **BLE للإدخال** و**التقاط USB للفيديو**.

```
┌──────────────┐     HDMI      ┌──────────────────┐
│              │ ────────────▶ │   KVM-Go Dongle   │
│  كمبيوتر     │               │                   │
│  الهدف       │ ◀─── USB ──── │                   │
│  (الشاشة)    │               │                   │
└──────────────┘               └────────┬─────────┘
                                        │
                              ┌─────────┴─────────┐
                              │   USB Capture     │ (فيديو)
                              │   BLE (FFF2)      │ (لوحة مفاتيح/ماus)
                              └─────────┬─────────┘
                                        │
                              ┌─────────▼─────────┐
                              │     iPad           │
                              │  (Openterface)     │
                              └───────────────────┘
```

ترتيب الاتصال لـ iPadOS:

1. **الأجهزة:** أدخل محول KVM-Go في منفذ USB لكمبيوتر الهدف ووصّل مدخل HDMI
2. **شغّل** الكمبيوتر الهدف
3. **افتح التطبيق** على iPad وامنح أذونات الكاميرا والميكروفون وBluetooth
4. **اضغط زر BLE** في شريط الأدوات — يبحث التطبيق عن أجهزة باسم `kvm*`
5. **اضغط Connect** بجانب جهاز KVM-Go — يتحول الزر إلى الأخضر مع قوة إشارة RSSI
6. **تحقق:** تعرض معاينة الفيديو شاشة الهدف، النقر يرسل نقرات، الكتابة ترسل ضغطات مفاتيح

> **ملاحظة:** تطبيق iPadOS يعمل فقط مع **KVM-Go**. Mini-KVM وuConsole KVM Extension لا يدعمان BLE.

## 5. أول تشغيل

### النافذة الرئيسية

```
┌─────────────────────────────────────────────────────────┐
│  شريط القوائم / شريط الأدوات                          │
├─────────────────────────────────────────────────────────┤
│                                                         │
│              منطقة عرض الفيديو                          │
│         (تعرض شاشة جهاز الهدف)                         │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  شريط الحالة │ المنفذ │ المفاتيح │ الفأرة │ الدقة │   │
└─────────────────────────────────────────────────────────┘
```

### أذونات Android

عند أول تشغيل، يطلب تطبيق Android:

| الإذن | السبب | ماذا يحدث عند الرفض |
|---|---|---|
| **USB Host** | التواصل مع أجهزة Openterface | التطبيق لا يكتشف جهاز KVM |
| **الكاميرا** | استقبال الفيديو من شريحة التقاط HDMI | لا معاينة فيديو |
| **التخزين** | حفظ لقطات الشاشة والتسجيلات | لا يمكن حفظ اللقطات |

امنح جميع الأذونات للوظائف الكاملة. يظهر أيضاً مربع حوار إذن USB للنظام عند اكتشاف جهاز KVM — اضغط **Allow**.

### أذونات iPadOS

عند أول تشغيل، يطلب تطبيق iPadOS:

| الإذن | السبب | ماذا يحدث عند الرفض |
|---|---|---|
| **الكاميرا** | استقبال الفيديو من بطاقة التقاط HDMI | لا معاينة فيديو |
| **الميكروفون** | مراقبة صوت كمبيوتر الهدف عبر مكبرات iPad | لا مراقبة صوت |
| **Bluetooth** | اكتشاف KVM-Go والاتصال به لإدخال HID | لا إدخال لوحة مفاتيح/ماus |
| **مكتبة الصور** | حفظ لقطات الشاشة والتسجيلات | تُحفظ اللقطات في مجلد مستندات التطبيق |

إذا رفضت إذناً بالخطأ، انتقل إلى **Settings > Privacy & Security** لإعادة تفعيله.

### التحقق من الاتصال

- **مؤشر HDMI:** أخضر = إشارة مكتشفة، برتقالي = لا إشارة، رمادي = غير معروف
- **مؤشر لوحة المفاتيح:** أخضر = متصل، برتقالي = غير موجود، رمادي = غير معروف
- **مؤشر الفأرة:** أخضر = متصل، برتقالي = غير موجود، رمادي = غير معروف
- **منفذ Serial:** يجب أن يعرض اسم المنفذ ومعدل الإرسال (9600 أو 115200)

إذا ظهرت المؤشرات بالبرتقالي أو الرمادي، راجع [حل المشكلات](04-troubleshooting.md).

## 6. التحكم الأساسي في KVM

### أوضاع الفأرة

| الوضع | الوصف | الأفضل لـ |
|------|-------------|----------|
| **Absolute** (افتراضي) | مؤشر المضيف يُعيَّن مباشرة لشاشة الهدف | الاستخدام العام، التنقل في الواجهة |
| **Relative (HID)** | حركات الفأرة تُرسل كفروق عبر HID | الألعاب، التفاعل السريع |

بدّل عبر مفتاح التبديل في شريط الأدوات أو **Control > Mouse Mode**.

### إدخال لوحة المفاتيح

تُوجَّه جميع ضغطات المفاتيح إلى الهدف عندما تكون نافذة التطبيق في التركيز:
- المفاتيح القياسية، مفاتيح الوظائف، المعدّلات
- مفاتيح خاصة: Ctrl+Alt+Del، Print Screen
- **Paste to Target:** يرسل نص الحافظة كضغطات مفاتيح محاكاة

### تبديل USB

بدّل منفذ USB القابل للتبديل بين:
- **Host** — لوحة المفاتيح/الفأرة تتحكم في الكمبيوتر المضيف
- **Target** — لوحة المفاتيح/الفأرة تتحكم في الكمبيوتر الهدف
