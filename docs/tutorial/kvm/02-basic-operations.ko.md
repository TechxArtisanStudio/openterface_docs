# KVM 튜토리얼 02 — 기본 작업

**대상:** 초보자~중급 — 일상 사용 기능

---

## 1. 마우스 제어

### 절대 모드 (기본값)

호스트 마우스 커서가 타겟 화면에 직접 매핑됩니다. 두 커서 모두 표시됩니다.

- **가장 적합한:** 일반 사용, 서버 관리, BIOS 탐색
- **커서 동작:** 자동 숨김 또는 비디오 영역 위에 호스트 커서 항상 표시

### 상대 (HID) 모드

마우스 움직임이 HID 인터페이스를 통해 상대 델타로 전송됩니다. 호스트 커서는 숨겨집니다.

- **가장 적합한:** 게임, 원시 마우스 입력이 필요한 애플리케이션
- **요구 사항:** macOS에서 접근성 권한
- **종료:** 전역 키보드 단축키 (macOS) 또는 Esc 길게 누르기 (Qt)

### Android 마우스 모드

Android 앱은 설정 패널에서 전환 가능한 타겟 마우스 제어 방법 세 가지를 제공합니다:

| 모드 | 동작 방식 | 가장 적합한 |
|---|---|---|
| **절대 (기본값)** | 아무 곳이나 탭하면 커서가 그곳으로 점프하고 왼쪽 클릭. 위치는 비례 매핑. | 대부분의 작업 |
| **상대** | 손가락을 드래그하면 커서가 드래그에 상대적으로 이동, 노트북 트랙패드처럼. 손가락을 떼면 커서는 그대로. | 정밀 커서 배치 |
| **절대 드래그** | 탭하고 길게 누르기; 커서가 점프하여 손가락을 따라감. "Drag" 레이블 표시. 놓으면 드롭. | 파일 드래그, 텍스트 선택 |

**Android 마우스 버튼:** 한 번 탭 = 왼쪽 클릭, 길게 누르기 = 오른쪽 클릭, 두 번 탭 = 더블 클릭.

### iPadOS 마우스 모드

iPadOS 앱은 두 가지 마우스 모드를 제공하며, 툴바의 마우스 모드 버튼으로 전환할 수 있습니다:

| 모드 | 아이콘 | 동작 방식 | 가장 적합한 |
|---|---|---|---|
| **Pan Mode** (상대) | 손 아이콘 | 손가락이 노트북 트랙패드처럼 — 드래그로 커서 이동, 탭으로 클릭 | 일반 데스크톱 사용, 평평한 표면 |
| **iPencil Mode** (절대) | 연필 아이콘 | 터치 위치가 타겟 화면 좌표에 직접 매핑, 그래픽 태블릿처럼 | 정밀 포인팅, Apple Pencil 사용 |

**두 모드의 제스처:**

| 제스처 | Pan Mode | iPencil Mode |
|---|---|---|
| **한 번 탭** | 왼쪽 클릭 | 커서를 해당 지점으로 이동 + 왼쪽 클릭 |
| **탭 & 드래그** | 커서 이동 (상대) | 왼쪽 버튼 누른 채 드래그 |
| **두 번 탭** | 더블 클릭 | 해당 지점에서 더블 클릭 |
| **길게 누르기** | 오른쪽 클릭 | 해당 지점에서 오른쪽 클릭 |
| **두 손가락 탭** | 오른쪽 클릭 | 오른쪽 클릭 |
| **두 손가락 드래그** | 스크롤 휠 | 스크롤 휠 |

**빠른 메뉴:** 비디오 미리보기를 길게 누르면 Left Click, Right Click, Drag 옵션이 있는 메뉴가 열립니다.

**드래그 모드:** 두 번 탭 & 길게 누르기 또는 빠른 메뉴에서 Drag 선택 — 왼쪽 버튼이 눌린 상태로 유지되며 "Dragging Mode Active" 레이블이 표시됩니다.

### 성능 프리셋 (macOS)

**Control > Mouse Mode > Performance Presets** 아래:

| 프리셋 | 스로틀 | 보드레이트 | 사용 사례 |
|--------|----------|----------|----------|
| Low Performance Target | 30 Hz | 9600 | 느린 타겟 장치 |
| Casual Use | 80 Hz | 9600 | 일상적인 서버 관리 |
| Gaming | 250 Hz | 115200 | 반응성 좋은 게임 |
| Max Performance | 1000 Hz | 115200 | 최대 반응성 |

스로틀이 높을수록 = 더 반응적. 보드레이트가 높을수록 = 더 빠른 직렬 통신.

## 2. 키보드 입력

### 표준 입력

앱 창에 포커스가 있는 동안 입력된 모든 키 입력이 타겟으로 전달됩니다.

### 특수 키

툴바 키 패널 또는 **Control > Special Keys**를 통해 키 조합 전송:

- **F1–F12:** 기능 키
- **Ctrl+Alt+Del:** Windows 세 손가락 경례
- **Print Screen:** 스크린샷 키
- **Ctrl+Alt+F2:** Linux VT 전환

### 키보드 레이아웃

타겟 OS 레이아웃을 타겟 컴퓨터에 맞게 설정:

| 레이아웃 | 동작 |
|--------|----------|
| **Windows** | 호스트 키를 Windows 관례에 매핑 |
| **Mac** | 호스트 키를 Mac 관례에 매핑 |
| **Linux** | 호스트 키를 Linux 관례에 매핑 |

지역 레이아웃 (QWERTY UK, 덴마크어, QWERTZ 독일어, AZERTY 프랑스어, 일본어 등)도 Qt 애플리케이션에서 사용 가능합니다.

### 타겟에 붙여넣기

앱은 클립보드 텍스트를 에뮬레이션 키 입력으로 타겟에 전송합니다. 사용자 이름, 명령, URL에 유용합니다.

> **참고:** ASCII 문자만 지원됩니다. 오래되거나 바쁜 시스템에서는 긴 텍스트의 서식이 손실되거나 문자가 누락될 수 있습니다.

**붙여넣기 동작 구성 (macOS):**
- **Ask Every Time:** 매번 호스트 또는 타겟을 묻는 프롬프트
- **Host Paste:** 항상 타겟으로 전송
- **Local Paste:** 항상 호스트에 붙여넣기

### Android 화면 키보드

Android 앱은 메인 화면 오른쪽 하단의 키보드 버튼 (⌨)을 통해 접근할 수 있는 전체 화면 키보드를 제공합니다:

| 컨트롤 | 기능 |
|---|---|
| **ShortCut** | 미리 만들어진 단축키: Ctrl+C/V, Win+L, Ctrl+Alt+Del, Alt+F4 등 |
| **Function** | F1–F12, PrtSc, ScrLk, 탐색 키 (Ins, Home, PgUp 등), 방향키 |
| **System** | 문자, 숫자, 구두점, Backspace, Enter가 포함된 QWERTY 레이아웃 |
| **Modifier keys** | Ctrl, Shift, Alt, Win — 다음 키 전송 후 자동 리셋되는 토글 버튼 |

**Ctrl+Alt+Del** 같은 조합 전송: Ctrl 탭 (강조), Alt 탭 (둘 다 강조), Del 탭. 키 전송 후 모든 수정자가 자동으로 리셋됩니다.

키보드는 **다양한 지역 레이아웃** (US, 일본어 JIS, 독일어 QWERTZ 등)도 지원하며 설정 패널에서 선택할 수 있습니다. 확대/축소 버튼으로 키 크기를 조정할 수 있습니다.

### iPadOS 키보드 입력

iPadOS 앱은 두 가지 키보드 입력 방법을 지원합니다:

**플로팅 화면 키보드:** 툴바의 **Keyboard** 버튼을 탭하면 Mac 스타일의 드래그 가능한 플로팅 키보드가 표시됩니다:

| 행 | 키 |
|---|---|
| **Top** | Esc, F1–F12, Del |
| **Number** | `, 1–0, -, =, Backspace |
| **QWERTY** | Tab, q–p, [, ], \, Enter |
| **Home row** | Caps, a–l, ;, ', Enter |
| **Bottom** | Shift, z–m, ,, ., /, Shift |
| **Modifiers** | Ctrl, Alt, Cmd, Space, Cmd, Alt, Ctrl |

- **수정자 토글:** Ctrl, Shift, Alt, Cmd 또는 Caps를 탭하여 켜기/끄기 (파란색으로 강조)
- **키보드 모드:** Normal (표준 입력) 및 Game (게임 입력에 최적화된 HID 패킷 헤더)
- **드래그:** 헤더의 드래그 핸들을 잡아 키보드를 화면 어디든 재배치

**외부 iPad 키보드:** iPad에 연결된 물리 키보드 (Bluetooth, Smart Connector, USB)는 타겟 PC로 직접 패스스루됩니다. 수정자 키는 누름/해제 이벤트로 전송되므로 `Ctrl+C` 또는 `Alt+Tab` 같은 조합이 자연스럽게 작동합니다.

**복합 키 단축키:** 앱에는 툴바에서 카테고리별로 접근할 수 있는 일반적인 단축키 라이브러리가 포함되어 있습니다:

| 카테고리 | 예시 |
|---|---|
| **Navigation** | Ctrl+C/V/X/A/F, Ctrl+Home/End, Page Up/Down |
| **Editing** | Ctrl+Z/Y, Ctrl+B/I/U, Ctrl+D |
| **System** | Ctrl+S/O/P/R, F11, Alt+F4 |
| **Application** | Alt+Tab, Cmd+M, Cmd+Shift+3/4 (macOS 스크린샷) |

## 3. 비디오 설정

### 해상도 표시

툴바에 타겟의 현재 입력 해상도와 FPS가 표시됩니다. 해상도는 타겟이 HDMI를 통해 출력하는 내용에 따라 결정됩니다.

### 지원 해상도

| 해상도 | 프레임 레이트 범위 |
|------------|-----------------|
| 640x480 | 5–60 Hz |
| 720x480 | 5–60 Hz |
| 800x600 | 5–60 Hz |
| 1024x768 | 10–60 Hz |
| 1280x720 | 10–60 Hz |
| 1280x1024 | 5–30 Hz |
| 1600x1200 | 5–30 Hz |
| 1920x1080 | 5–30 Hz |

### 해상도 변경

1. 비디오 설정에서 원하는 해상도 구성

### 종횡비 & 스케일링

| 모드 | 동작 |
|------|----------|
| **Active Resolution** | 활성 비디오 영역 자동 감지 |
| **HID Resolution** | 캡처 카드 하드웨어의 해상도 사용 |
| **Custom** | 비율 수동 설정 (16:9, 4:3, 21:9 등) |

**스케일링:** Stretch (창을 채움, 왜곡 가능), Fit (레터박스), Fill (잘릴 수 있음).

### 확대/축소

확대/축소, 맞춤으로 재설정, 확대 시 스크롤로 패닝.

### 비디오 백엔드 (Qt)

| 백엔드 | 플랫폼 | 참고 |
|---------|----------|-------|
| **FFmpeg** | All | 권장, 하드웨어 가속 |
| **GStreamer** | Linux | 파이프라인 유연성 |
| **Qt Multimedia** | Windows | 간단한 대체 |

**Preferences > Video > Media Backend**를 통해 전환. 변경 후 재시작 필요.

### Android 비디오 컨트롤

Android 앱에서 비디오 설정은 설정 패널 (Menu 버튼 ☰)을 통해 접근:

- **Video Format** — 해상도 (1920×1080, 1280×720, 640×480) 및 프레임 레이트 (30fps, 60fps) 선택. 비디오가 끊기면 해상도/프레임 레이트를 낮추세요.
- **Controls** — **brightness**, **contrast**, **hue** 실시간 슬라이더
- **Rotate/Flip** — 90° CW/CCW 회전, 수평/수직 뒤집기. KVM 장치가 거꾸로 또는 옆으로 장착된 경우 유용

설정은 세션 간 유지됩니다 — 한 번만 구성하면 됩니다.

### iPadOS 비디오 컨트롤

iPadOS에서 비디오 컨트롤은 하단 툴바에서 접근:

- **Resolution Switching** — **Video** 버튼 (현재 해상도 표시)을 탭하여 선택: 2160p (4K), 1080p (기본값), 720p 또는 480p. 느린 연결에서는 해상도를 낮춰 성능 향상.
- **Zoom Mode** — **Zoom**을 탭하여 확대 모드 진입, 두 손가락 핀치로 확대. 확대 표시기에 현재 수준 표시 (예: `2.5x`). 확대 시 한 손가락 드래그로 뷰포트 패닝. **Zoom**을 다시 탭하여 종료.
- **Fullscreen** — **Fullscreen**을 탭하여 툴바를 숨기고 비디오를 전체 화면으로 확장. 왼쪽 상단 화살표 버튼으로 종료.
- **Screen Rotation** — **Rotate**를 탭하여 방향 보정 모드 순환 (Normal, 90° CW, 180°, 90° CCW). KVM-Go 동글이 옆으로 또는 거꾸로 장착된 경우 유용. 회전은 라이브 미리보기와 저장된 캡처 모두에 적용.

카메라 시작 중 "Starting Camera..." 로딩 표시기가 나타납니다. 카메라가 연결되지 않았지만 권한이 부여된 경우 안내 이미지가 표시됩니다.

## 4. 타겟 오디오

HDMI 캡처 칩이 HDMI 신호에서 오디오를 추출하여 호스트에 USB 오디오 입력으로 제공합니다.

### 오디오 활성화

1. 오디오 아이콘 클릭 또는 오디오 설정 열기
2. 오디오 캡처 활성화
3. 올바른 입력 장치 선택 (예: "OpenterfaceA")
4. 호스트 출력 장치 선택

대부분의 플랫폼에서 오디오는 기본적으로 비활성화되어 있습니다.

### 볼륨 제어

- **타겟 측:** 타겟 컴퓨터에서 조정
- **호스트 측:** 캡처 장치용 호스트 OS 오디오 믹서 사용

### iPadOS 오디오 모니터링

iPadOS 앱을 통해 iPad 스피커 또는 헤드폰으로 타겟 PC 오디오를 들을 수 있습니다:

- 툴바의 **Audio** 버튼 (스피커 아이콘)을 탭하여 모니터링 전환
- **아이콘 상태:** 회색 사선 스피커 = 미승인, 빨간 사선 스피커 = 꺼짐, 녹색 파형 스피커 = 켜짐
- 첫 사용 시 앱이 마이크 권한 요청
- 오디오는 iPad 스피커 또는 연결된 헤드폰/Bluetooth 오디오로 재생
- **녹화 중:** 피드백 방지를 위해 모니터링 오디오가 일시적으로 음소거되지만, 오디오는 녹화 파일에 캡처됩니다

## 5. 화면 캡처 & 녹화

### 스크린샷

툴바의 카메라 아이콘 클릭. 이미지는 OS 기본 미디어 폴더에 저장됩니다:
- **Linux:** `~/Pictures`
- **Windows:** `C:\Users\<name>\Pictures`
- **macOS:** Camera captures 폴더 (Camera 메뉴 경유)

### 녹화

녹화 버튼을 클릭하여 타겟의 비디오 및 오디오 스트림 녹화 시작/중지. 녹화 중 타이머가 표시됩니다.

**녹화 설정:**
- 출력 형식 (MP4, AVI, MOV, MKV)
- 비디오 비트레이트, 오디오 코덱
- 출력 디렉터리

### Android 화면 캡처 & 녹화

Android에서 설정 패널을 통해 접근:

- **Screen Capture** — 탭하여 현재 비디오 프레임 스냅샷을 장치 기본 미디어 폴더에 저장. **Storage permission** 필요.
- **Record Video** — 탭하여 녹화 시작/중지. 상단에 타이머가 있는 빨간 녹화 표시기 표시. 비디오는 장치 기본 미디어 폴더에 저장.

**사용 사례:** 타겟 부팅 과정 녹화, 오류 메시지 캡처, 구성 단계 문서화.

### iPadOS 화면 캡처 & 녹화

**스크린샷:** 툴바의 **Screenshot** 버튼 (카메라 아이콘) 탭. 앱이 고해상도 프레임을 캡처하고 방향을 보정하여 JPEG로 저장.

**비디오 녹화:** **Record** 버튼을 탭하여 시작/중지. 중지 후 앱이 녹화 세부 정보 (시간 및 파일 크기) 표시.

| 설정 | 값 |
|---|---|
| **Video codec** | H.264 at 30 fps |
| **Resolution** | 캡처 장치와 일치 (일반적으로 1920×1080) |
| **Audio codec** | AAC at 128 kbps, 48 kHz, stereo |
| **Container** | MOV |

**파일 위치:**
- **App Documents:** `Documents/Recordings/` — Files 앱 > On My iPad > Openterface KVM > Recordings에서 탐색
- **Photos App:** Photo Library 권한이 부여되고 설정에서 활성화된 경우
- **파일 이름:** `Openterface_YYYY-MM-DD_HH-mm-ss.jpg` (스크린샷) 또는 `.mov` (녹화)

**사용 사례:** 타겟 부팅 과정 녹화, 오류 메시지 캡처, 구성 단계 문서화.
