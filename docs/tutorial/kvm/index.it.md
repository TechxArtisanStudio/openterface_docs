
# Tutorial sul software KVM

> Controllo del tastierino, video e mouse tramite un singolo dispositivo.

Questa guida copre la serie **Openterface KVM** — dispositivi che capturano l'uscita video HDMI del bersaglio e trasmettono l'input di tastiera/mouse attraverso l'emulazione HID:

- **Mini-KVM** — Adattatore USB compatto KVM
- **KVM-Go** — KVM portatile in formato toolkit
- **uConsole Estensione KVM** — KVM incorporato per uConsole

> **Piattaforme:** macOS, Windows, Linux (app desktop), **Android** (app mobile) e **iPadOS** (app tablet). Note specifiche Android e iPadOS sono indicate a lungo nel testo.
> **Nota:** L'ipadOS è supportata solo su KVM-Go — l'app per iPadOS si connette tramite Bluetooth LE al dongle KVM-Go.

> Cerchi la **KeyMod** (solo emulatore tastiera e mouse)? Vedi il [tutorial sulla KeyMod](../keymod/index.md).
