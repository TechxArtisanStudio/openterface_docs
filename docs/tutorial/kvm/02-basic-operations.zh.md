
# KVM教程 02 — 基本操作

**受众：** 初学者至中级 — 日常使用功能

---

## 1. 鼠标控制

### 绝对模式（默认）

主机鼠标光标直接映射到目标屏幕。两个光标均可见。

- **最佳用途：** 一般使用、服务器管理、BIOS 导航
- **光标行为：** 自动隐藏或在视频区域上方始终显示主机光标

### 相对 (HID) 模式

鼠标移动通过 HID 接口以相对增量形式发送。主机光标被隐藏。

- **最佳用途：** 游戏、需要原始鼠标输入的应用
- **要求：** macOS 上的辅助功能权限
- **退出：** 全局键盘快捷键（macOS）或长按 Esc（Qt）

### Android 鼠标模式

Android 应用在设置面板中提供三种控制目标鼠标的方式，可切换：

| 模式 | 工作原理 | 最佳用途 |
|---|---|---|
| **绝对（默认）** | 点击任意位置，光标跳至该处并左键单击。位置按比例映射。 | 大多数任务 |
| **相对** | 拖动手指；光标随拖动相对移动，类似笔记本触控板。抬起手指后光标保持不动。 | 精细光标定位 |
| **绝对拖动** | 点击并按住；光标跳转并跟随手指。出现「Drag」标签。松手即释放。 | 拖动文件、选择文本 |

**Android 鼠标按键：** 单击 = 左键，长按 = 右键，双击 = 双击。

### iPadOS 鼠标模式

iPadOS 应用提供两种鼠标模式，可通过工具栏上的鼠标模式按钮切换：

| 模式 | 图标 | 工作原理 | 最佳用途 |
|---|---|---|---|
| **平移模式**（相对） | 手形图标 | 手指如同笔记本触控板 — 拖动移动光标，点击即单击 | 一般桌面使用、平面操作 |
| **iPencil 模式**（绝对） | 铅笔图标 | 触摸位置直接映射到目标屏幕坐标，类似数位板 | 精确指向、Apple Pencil 使用 |

**两种模式下的手势：**

| 手势 | 平移模式 | iPencil 模式 |
|---|---|---|
| **单击** | 左键单击 | 移动光标至该点并左键单击 |
| **点击并拖动** | 移动光标（相对） | 按住左键拖动 |
| **双击** | 双击 | 在该点双击 |
| **长按** | 右键单击 | 在该点右键单击 |
| **双指点击** | 右键单击 | 右键单击 |
| **双指拖动** | 滚轮 | 滚轮 |

**快捷菜单：** 长按视频预览可打开菜单，包含左键单击、右键单击和拖动选项。

**拖动模式：** 双击并按住，或从快捷菜单选择 Drag — 左键保持按下，出现「Dragging Mode Active」标签。

### 性能预设（macOS）

在 **Control > Mouse Mode > Performance Presets** 下：

| 预设 | 节流 | 波特率 | 使用场景 |
|--------|----------|----------|----------|
| Low Performance Target | 30 Hz | 9600 | 慢速目标设备 |
| Casual Use | 80 Hz | 9600 | 日常服务器管理 |
| Gaming | 250 Hz | 115200 | 响应灵敏的游戏 |
| Max Performance | 1000 Hz | 115200 | 最大响应速度 |

更高的节流 = 更灵敏。更高的波特率 = 更快的串口通信。

## 2. 键盘输入

### 标准输入

应用窗口获得焦点时，所有按键均转发至目标。

### 特殊键

通过工具栏按键面板或 **Control > Special Keys** 发送组合键：

- **F1–F12：** 功能键
- **Ctrl+Alt+Del：** Windows 三指敬礼
- **Print Screen：** 截屏键
- **Ctrl+Alt+F2：** Linux VT 切换

### 键盘布局

设置目标 OS 布局以匹配目标计算机：

| 布局 | 行为 |
|--------|----------|
| **Windows** | 将主机按键映射为 Windows 惯例 |
| **Mac** | 将主机按键映射为 Mac 惯例 |
| **Linux** | 将主机按键映射为 Linux 惯例 |

Qt 应用还提供区域布局（QWERTY UK、丹麦语、QWERTZ 德语、AZERTY 法语、日语等）。

### 粘贴到目标

应用将剪贴板文本作为仿真按键发送至目标。适用于用户名、命令、URL。

> **注意：** 仅支持 ASCII 字符。在较旧或繁忙的系统上，长文本可能丢失格式或丢弃字符。

**配置粘贴行为（macOS）：**
- **Ask Every Time：** 每次提示选择主机或目标
- **Host Paste：** 始终发送至目标
- **Local Paste：** 始终在主机上粘贴

### Android 屏幕键盘

Android 应用提供完整屏幕键盘，可通过主屏幕右下角的键盘按钮（⌨）访问：

| 控件 | 功能 |
|---|---|
| **ShortCut** | 预设快捷方式：Ctrl+C/V、Win+L、Ctrl+Alt+Del、Alt+F4 等 |
| **Function** | F1–F12、PrtSc、ScrLk、导航键（Ins、Home、PgUp 等）、方向键 |
| **System** | QWERTY 布局，含字母、数字、标点、Backspace、Enter |
| **Modifier keys** | Ctrl、Shift、Alt、Win — 切换按钮，下一键发送后自动重置 |

发送 **Ctrl+Alt+Del** 等组合键：点击 Ctrl（高亮），点击 Alt（两者均高亮），点击 Del。发送按键后所有修饰键自动重置。

键盘还支持**不同区域布局**（US、日语 JIS、德语 QWERTZ 等），可在设置面板中选择。放大/缩小按钮可调整按键大小。

### iPadOS 键盘输入

iPadOS 应用支持两种键盘输入方式：

**浮动屏幕键盘：** 点击工具栏中的 **Keyboard** 按钮，显示可拖动的 Mac 风格浮动键盘：

| 行 | 按键 |
|---|---|
| **Top** | Esc、F1–F12、Del |
| **Number** | `、1–0、-、=、Backspace |
| **QWERTY** | Tab、q–p、[、]、\、Enter |
| **Home row** | Caps、a–l、;、'、Enter |
| **Bottom** | Shift、z–m、,、.、/、Shift |
| **Modifiers** | Ctrl、Alt、Cmd、Space、Cmd、Alt、Ctrl |

- **切换修饰键：** 点击 Ctrl、Shift、Alt、Cmd 或 Caps 切换开/关（蓝色高亮）
- **键盘模式：** Normal（标准输入）和 Game（针对游戏输入优化的 HID 包头）
- **拖动：** 抓住标题栏的拖动手柄，可将键盘移至屏幕任意位置

**外接 iPad 键盘：** 连接至 iPad 的物理键盘（Bluetooth、Smart Connector、USB）直接透传至目标 PC。修饰键以按下/释放事件发送，因此 `Ctrl+C` 或 `Alt+Tab` 等组合键可自然使用。

**组合键快捷方式：** 应用包含常用快捷方式库，可从工具栏按类别访问：

| 类别 | 示例 |
|---|---|
| **Navigation** | Ctrl+C/V/X/A/F、Ctrl+Home/End、Page Up/Down |
| **Editing** | Ctrl+Z/Y、Ctrl+B/I/U、Ctrl+D |
| **System** | Ctrl+S/O/P/R、F11、Alt+F4 |
| **Application** | Alt+Tab、Cmd+M、Cmd+Shift+3/4（macOS 截图） |

## 3. 视频设置

### 分辨率显示

工具栏显示来自目标的当前输入分辨率和 FPS。分辨率由目标通过 HDMI 输出的内容决定。

### 支持的分辨率

| 分辨率 | 帧率范围 |
|------------|-----------------|
| 640x480 | 5–60 Hz |
| 720x480 | 5–60 Hz |
| 800x600 | 5–60 Hz |
| 1024x768 | 10–60 Hz |
| 1280x720 | 10–60 Hz |
| 1280x1024 | 5–30 Hz |
| 1600x1200 | 5–30 Hz |
| 1920x1080 | 5–30 Hz |

### 更改分辨率

1. 在视频设置中配置首选分辨率

### 宽高比与缩放

| 模式 | 行为 |
|------|----------|
| **Active Resolution** | 自动检测活动视频区域 |
| **HID Resolution** | 使用采集卡硬件的分辨率 |
| **Custom** | 手动设置比例（16:9、4:3、21:9 等） |

**缩放：** Stretch（填满窗口，可能变形）、Fit（留黑边）、Fill（可能裁剪）。

### 缩放

放大/缩小、重置以适应，放大后可滚动平移。

### 视频后端（Qt）

| 后端 | 平台 | 说明 |
|---------|----------|-------|
| **FFmpeg** | All | 推荐，硬件加速 |
| **GStreamer** | Linux | 管道灵活性 |
| **Qt Multimedia** | Windows | 简单备用方案 |

通过 **Preferences > Video > Media Backend** 切换。更改后需重启。

### Android 视频控制

在 Android 应用中，通过设置面板（Menu 按钮 ☰）访问视频设置：

- **Video Format** — 选择分辨率（1920×1080、1280×720、640×480）和帧率（30fps、60fps）。若视频卡顿，可降低分辨率/帧率。
- **Controls** — **brightness**、**contrast** 和 **hue** 的实时滑块
- **Rotate/Flip** — 顺时针/逆时针旋转 90°，水平/垂直翻转。KVM 设备倒置或侧装时很有用

设置会在会话间保留 — 只需配置一次。

### iPadOS 视频控制

在 iPadOS 上，视频控制可从底部工具栏访问：

- **Resolution Switching** — 点击 **Video** 按钮（显示当前分辨率）选择：2160p (4K)、1080p（默认）、720p 或 480p。较慢连接时可降低分辨率以提升性能。
- **Zoom Mode** — 点击 **Zoom** 进入缩放模式，双指捏合放大。缩放指示器显示当前级别（如 `2.5x`）。缩放后单指拖动可平移视口。再次点击 Zoom 退出。
- **Fullscreen** — 点击 **Fullscreen** 隐藏工具栏，视频延伸至全屏。点击左上角箭头按钮退出。
- **Screen Rotation** — 点击 **Rotate** 循环切换方向校正模式（Normal、90° CW、180°、90° CCW）。KVM-Go dongle 侧装或倒置时很有用。旋转同时应用于实时预览和已保存的捕获。

相机启动时会出现「Starting Camera...」加载指示器。若未连接相机但已授予权限，则显示引导图。

## 4. 来自目标的音频

HDMI 采集芯片从 HDMI 信号中提取音频，并将其作为 USB 音频输入呈现给主机。

### 启用音频

1. 点击音频图标或打开音频设置
2. 启用音频采集
3. 选择正确的输入设备（如「OpenterfaceA」）
4. 选择主机的输出设备

大多数平台上音频默认禁用。

### 音量控制

- **目标端：** 在目标计算机上调整
- **主机端：** 使用主机 OS 音频混音器调节采集设备

### iPadOS 音频监听

iPadOS 应用可让您通过 iPad 扬声器或耳机监听目标 PC 的音频：

- 点击工具栏中的 **Audio** 按钮（扬声器图标）切换监听
- **图标状态：** 灰色带斜线扬声器 = 未授权，红色带斜线扬声器 = 关闭，绿色带波纹扬声器 = 开启
- 首次使用时，应用会请求麦克风权限
- 音频通过 iPad 扬声器或已连接的耳机/Bluetooth 音频播放
- **录制期间：** 监听音频暂时静音以防反馈，但音频仍会写入录制文件

## 5. 屏幕捕获与录制

### 截图

点击工具栏上的相机图标。图像保存至 OS 默认媒体文件夹：
- **Linux：** `~/Pictures`
- **Windows：** `C:\Users\<name>\Pictures`
- **macOS：** Camera captures 文件夹（通过 Camera 菜单）

### 录制

点击录制按钮开始/停止录制目标的视频和音频流。录制进行时显示计时器。

**录制设置：**
- 输出格式（MP4、AVI、MOV、MKV）
- 视频比特率、音频编解码器
- 输出目录

### Android 屏幕捕获与录制

在 Android 上，通过设置面板访问：

- **Screen Capture** — 点击将当前视频帧快照保存至设备默认媒体文件夹。需要 **Storage permission**。
- **Record Video** — 点击开始/停止录制。顶部出现带计时器的红色录制指示器。视频保存至设备默认媒体文件夹。

**使用场景：** 录制目标启动过程、捕获错误消息、记录配置步骤。

### iPadOS 屏幕捕获与录制

**截图：** 点击工具栏中的 **Screenshot** 按钮（相机图标）。应用捕获高分辨率帧，校正方向，并保存为 JPEG。

**视频录制：** 点击 **Record** 按钮开始/停止。停止后，应用显示录制详情（时长和文件大小）。

| 设置 | 值 |
|---|---|
| **Video codec** | H.264 at 30 fps |
| **Resolution** | 与采集设备匹配（通常为 1920×1080） |
| **Audio codec** | AAC at 128 kbps, 48 kHz, stereo |
| **Container** | MOV |

**文件位置：**
- **App Documents：** `Documents/Recordings/` — 通过 Files 应用 > On My iPad > Openterface KVM > Recordings 浏览
- **Photos App：** 若已授予 Photo Library 权限并在设置中启用
- **文件命名：** `Openterface_YYYY-MM-DD_HH-mm-ss.jpg`（截图）或 `.mov`（录制）

**使用场景：** 录制目标启动过程、捕获错误消息、记录配置步骤。

## 7. 防止屏幕保护程序

启用 **Prevent Screen Saver**（通过 Edit/Device 菜单或工具栏）以发送周期性事件，保持目标显示唤醒。
