
# KVM教程 02 — 基本操作

**受眾：** 初學者至中級 — 日常使用功能

---

## 1. 鼠標控制

### 絕對模式（默認）

主機鼠標光標直接映射到目標屏幕。兩個光標均可見。

- **最佳用途：** 一般使用、服務器管理、BIOS 導航
- **光標行為：** 自動隱藏或在視頻區域上方始終顯示主機光標

### 相對 (HID) 模式

鼠標移動通過 HID 接口以相對增量形式發送。主機光標被隱藏。

- **最佳用途：** 遊戲、需要原始鼠標輸入的應用
- **要求：** macOS 上的輔助功能權限
- **退出：** 全局鍵盤快捷鍵（macOS）或長按 Esc（Qt）

### Android 鼠標模式

Android 應用在設置面板中提供三種控制目標鼠標的方式，可切換：

| 模式 | 工作原理 | 最佳用途 |
|---|---|---|
| **絕對（默認）** | 點擊任意位置，光標跳至該處並左鍵單擊。位置按比例映射。 | 大多數任務 |
| **相對** | 拖動手指；光標隨拖動相對移動，類似筆記本觸控板。抬起手指後光標保持不動。 | 精細光標定位 |
| **絕對拖動** | 點擊並按住；光標跳轉並跟隨手指。出現「Drag」標籤。鬆手即釋放。 | 拖動文件、選擇文本 |

**Android 鼠標按鍵：** 單擊 = 左鍵，長按 = 右鍵，雙擊 = 雙擊。

### iPadOS 鼠標模式

iPadOS 應用提供兩種鼠標模式，可通過工具欄上的鼠標模式按鈕切換：

| 模式 | 圖標 | 工作原理 | 最佳用途 |
|---|---|---|---|
| **平移模式**（相對） | 手形圖標 | 手指如同筆記本觸控板 — 拖動移動光標，點擊即單擊 | 一般桌面使用、平面操作 |
| **iPencil 模式**（絕對） | 鉛筆圖標 | 觸摸位置直接映射到目標屏幕座標，類似數位板 | 精確指向、Apple Pencil 使用 |

**兩種模式下的手勢：**

| 手勢 | 平移模式 | iPencil 模式 |
|---|---|---|
| **單擊** | 左鍵單擊 | 移動光標至該點並左鍵單擊 |
| **點擊並拖動** | 移動光標（相對） | 按住左鍵拖動 |
| **雙擊** | 雙擊 | 在該點雙擊 |
| **長按** | 右鍵單擊 | 在該點右鍵單擊 |
| **雙指點擊** | 右鍵單擊 | 右鍵單擊 |
| **雙指拖動** | 滾輪 | 滾輪 |

**快捷菜單：** 長按視頻預覽可打開菜單，包含左鍵單擊、右鍵單擊和拖動選項。

**拖動模式：** 雙擊並按住，或從快捷菜單選擇 Drag — 左鍵保持按下，出現「Dragging Mode Active」標籤。

### 性能預設（macOS）

在 **Control > Mouse Mode > Performance Presets** 下：

| 預設 | 節流 | 波特率 | 使用場景 |
|--------|----------|----------|----------|
| Low Performance Target | 30 Hz | 9600 | 慢速目標設備 |
| Casual Use | 80 Hz | 9600 | 日常服務器管理 |
| Gaming | 250 Hz | 115200 | 響應靈敏的遊戲 |
| Max Performance | 1000 Hz | 115200 | 最大響應速度 |

更高的節流 = 更靈敏。更高的波特率 = 更快的串口通信。

## 2. 鍵盤輸入

### 標準輸入

應用窗口獲得焦點時，所有按鍵均轉發至目標。

### 特殊鍵

通過工具欄按鍵面板或 **Control > Special Keys** 發送組合鍵：

- **F1–F12：** 功能鍵
- **Ctrl+Alt+Del：** Windows 三指敬禮
- **Print Screen：** 截屏鍵
- **Ctrl+Alt+F2：** Linux VT 切換

### 鍵盤佈局

設置目標 OS 佈局以匹配目標計算機：

| 佈局 | 行為 |
|--------|----------|
| **Windows** | 將主機按鍵映射為 Windows 慣例 |
| **Mac** | 將主機按鍵映射為 Mac 慣例 |
| **Linux** | 將主機按鍵映射為 Linux 慣例 |

Qt 應用還提供區域佈局（QWERTY UK、丹麥語、QWERTZ 德語、AZERTY 法語、日語等）。

### 粘貼到目標

應用將剪貼板文本作為仿真按鍵發送至目標。適用於用户名、命令、URL。

> **注意：** 僅支持 ASCII 字符。在較舊或繁忙的系統上，長文本可能丟失格式或丟棄字符。

**配置粘貼行為（macOS）：**
- **Ask Every Time：** 每次提示選擇主機或目標
- **Host Paste：** 始終發送至目標
- **Local Paste：** 始終在主機上粘貼

### Android 屏幕鍵盤

Android 應用提供完整屏幕鍵盤，可通過主屏幕右下角的鍵盤按鈕（⌨）訪問：

| 控件 | 功能 |
|---|---|
| **ShortCut** | 預設快捷方式：Ctrl+C/V、Win+L、Ctrl+Alt+Del、Alt+F4 等 |
| **Function** | F1–F12、PrtSc、ScrLk、導航鍵（Ins、Home、PgUp 等）、方向鍵 |
| **System** | QWERTY 佈局，含字母、數字、標點、Backspace、Enter |
| **Modifier keys** | Ctrl、Shift、Alt、Win — 切換按鈕，下一鍵發送後自動重置 |

發送 **Ctrl+Alt+Del** 等組合鍵：點擊 Ctrl（高亮），點擊 Alt（兩者均高亮），點擊 Del。發送按鍵後所有修飾鍵自動重置。

鍵盤還支持**不同區域佈局**（US、日語 JIS、德語 QWERTZ 等），可在設置面板中選擇。放大/縮小按鈕可調整按鍵大小。

### iPadOS 鍵盤輸入

iPadOS 應用支持兩種鍵盤輸入方式：

**浮動屏幕鍵盤：** 點擊工具欄中的 **Keyboard** 按鈕，顯示可拖動的 Mac 風格浮動鍵盤：

| 行 | 按鍵 |
|---|---|
| **Top** | Esc、F1–F12、Del |
| **Number** | `、1–0、-、=、Backspace |
| **QWERTY** | Tab、q–p、[、]、\、Enter |
| **Home row** | Caps、a–l、;、'、Enter |
| **Bottom** | Shift、z–m、,、.、/、Shift |
| **Modifiers** | Ctrl、Alt、Cmd、Space、Cmd、Alt、Ctrl |

- **切換修飾鍵：** 點擊 Ctrl、Shift、Alt、Cmd 或 Caps 切換開/關（藍色高亮）
- **鍵盤模式：** Normal（標準輸入）和 Game（針對遊戲輸入優化的 HID 包頭）
- **拖動：** 抓住標題欄的拖動手柄，可將鍵盤移至屏幕任意位置

**外接 iPad 鍵盤：** 連接至 iPad 的物理鍵盤（Bluetooth、Smart Connector、USB）直接透傳至目標 PC。修飾鍵以按下/釋放事件發送，因此 `Ctrl+C` 或 `Alt+Tab` 等組合鍵可自然使用。

**組合鍵快捷方式：** 應用包含常用快捷方式庫，可從工具欄按類別訪問：

| 類別 | 示例 |
|---|---|
| **Navigation** | Ctrl+C/V/X/A/F、Ctrl+Home/End、Page Up/Down |
| **Editing** | Ctrl+Z/Y、Ctrl+B/I/U、Ctrl+D |
| **System** | Ctrl+S/O/P/R、F11、Alt+F4 |
| **Application** | Alt+Tab、Cmd+M、Cmd+Shift+3/4（macOS 截圖） |

## 3. 視頻設置

### 分辨率顯示

工具欄顯示來自目標的當前輸入分辨率和 FPS。分辨率由目標通過 HDMI 輸出的內容決定。

### 支持的分辨率

| 分辨率 | 幀率範圍 |
|------------|-----------------|
| 640x480 | 5–60 Hz |
| 720x480 | 5–60 Hz |
| 800x600 | 5–60 Hz |
| 1024x768 | 10–60 Hz |
| 1280x720 | 10–60 Hz |
| 1280x1024 | 5–30 Hz |
| 1600x1200 | 5–30 Hz |
| 1920x1080 | 5–30 Hz |

### 更改分辨率

1. 在視頻設置中配置首選分辨率

### 寬高比與縮放

| 模式 | 行為 |
|------|----------|
| **Active Resolution** | 自動檢測活動視頻區域 |
| **HID Resolution** | 使用採集卡硬件的分辨率 |
| **Custom** | 手動設置比例（16:9、4:3、21:9 等） |

**縮放：** Stretch（填滿窗口，可能變形）、Fit（留黑邊）、Fill（可能裁剪）。

### 縮放

放大/縮小、重置以適應，放大後可滾動平移。

### 視頻後端（Qt）

| 後端 | 平台 | 説明 |
|---------|----------|-------|
| **FFmpeg** | All | 推薦，硬件加速 |
| **GStreamer** | Linux | 管道靈活性 |
| **Qt Multimedia** | Windows | 簡單備用方案 |

通過 **Preferences > Video > Media Backend** 切換。更改後需重啓。

### Android 視頻控制

在 Android 應用中，通過設置面板（Menu 按鈕 ☰）訪問視頻設置：

- **Video Format** — 選擇分辨率（1920×1080、1280×720、640×480）和幀率（30fps、60fps）。若視頻卡頓，可降低分辨率/幀率。
- **Controls** — **brightness**、**contrast** 和 **hue** 的實時滑塊
- **Rotate/Flip** — 順時針/逆時針旋轉 90°，水平/垂直翻轉。KVM 設備倒置或側裝時很有用

設置會在會話間保留 — 只需配置一次。

### iPadOS 視頻控制

在 iPadOS 上，視頻控制可從底部工具欄訪問：

- **Resolution Switching** — 點擊 **Video** 按鈕（顯示當前分辨率）選擇：2160p (4K)、1080p（默認）、720p 或 480p。較慢連接時可降低分辨率以提升性能。
- **Zoom Mode** — 點擊 **Zoom** 進入縮放模式，雙指捏合放大。縮放指示器顯示當前級別（如 `2.5x`）。縮放後單指拖動可平移視口。再次點擊 Zoom 退出。
- **Fullscreen** — 點擊 **Fullscreen** 隱藏工具欄，視頻延伸至全屏。點擊左上角箭頭按鈕退出。
- **Screen Rotation** — 點擊 **Rotate** 循環切換方向校正模式（Normal、90° CW、180°、90° CCW）。KVM-Go dongle 側裝或倒置時很有用。旋轉同時應用於實時預覽和已保存的捕獲。

相機啓動時會出現「Starting Camera...」加載指示器。若未連接相機但已授予權限，則顯示引導圖。

## 4. 來自目標的音頻

HDMI 採集芯片從 HDMI 信號中提取音頻，並將其作為 USB 音頻輸入呈現給主機。

### 啓用音頻

1. 點擊音頻圖標或打開音頻設置
2. 啓用音頻採集
3. 選擇正確的輸入設備（如「OpenterfaceA」）
4. 選擇主機的輸出設備

大多數平台上音頻默認禁用。

### 音量控制

- **目標端：** 在目標計算機上調整
- **主機端：** 使用主機 OS 音頻混音器調節採集設備

### iPadOS 音頻監聽

iPadOS 應用可讓您通過 iPad 揚聲器或耳機監聽目標 PC 的音頻：

- 點擊工具欄中的 **Audio** 按鈕（揚聲器圖標）切換監聽
- **圖標狀態：** 灰色帶斜線揚聲器 = 未授權，紅色帶斜線揚聲器 = 關閉，綠色帶波紋揚聲器 = 開啓
- 首次使用時，應用會請求麥克風權限
- 音頻通過 iPad 揚聲器或已連接的耳機/Bluetooth 音頻播放
- **錄製期間：** 監聽音頻暫時靜音以防反饋，但音頻仍會寫入錄製文件

## 5. 屏幕捕獲與錄製

### 截圖

點擊工具欄上的相機圖標。圖像保存至 OS 默認媒體文件夾：
- **Linux：** `~/Pictures`
- **Windows：** `C:\Users\<name>\Pictures`
- **macOS：** Camera captures 文件夾（通過 Camera 菜單）

### 錄製

點擊錄製按鈕開始/停止錄製目標的視頻和音頻流。錄製進行時顯示計時器。

**錄製設置：**
- 輸出格式（MP4、AVI、MOV、MKV）
- 視頻比特率、音頻編解碼器
- 輸出目錄

### Android 屏幕捕獲與錄製

在 Android 上，通過設置面板訪問：

- **Screen Capture** — 點擊將當前視頻幀快照保存至設備默認媒體文件夾。需要 **Storage permission**。
- **Record Video** — 點擊開始/停止錄製。頂部出現帶計時器的紅色錄製指示器。視頻保存至設備默認媒體文件夾。

**使用場景：** 錄製目標啓動過程、捕獲錯誤消息、記錄配置步驟。

### iPadOS 屏幕捕獲與錄製

**截圖：** 點擊工具欄中的 **Screenshot** 按鈕（相機圖標）。應用捕獲高分辨率幀，校正方向，並保存為 JPEG。

**視頻錄製：** 點擊 **Record** 按鈕開始/停止。停止後，應用顯示錄製詳情（時長和文件大小）。

| 設置 | 值 |
|---|---|
| **Video codec** | H.264 at 30 fps |
| **Resolution** | 與採集設備匹配（通常為 1920×1080） |
| **Audio codec** | AAC at 128 kbps, 48 kHz, stereo |
| **Container** | MOV |

**文件位置：**
- **App Documents：** `Documents/Recordings/` — 通過 Files 應用 > On My iPad > Openterface KVM > Recordings 瀏覽
- **Photos App：** 若已授予 Photo Library 權限並在設置中啓用
- **文件命名：** `Openterface_YYYY-MM-DD_HH-mm-ss.jpg`（截圖）或 `.mov`（錄製）

**使用場景：** 錄製目標啓動過程、捕獲錯誤消息、記錄配置步驟。

## 7. 防止屏幕保護程序

啓用 **Prevent Screen Saver**（通過 Edit/Device 菜單或工具欄）以發送週期性事件，保持目標顯示喚醒。
