
# Tutorial de Software KVM

> Control total KVM por USB: control del teclado, video y ratón en un solo dispositivo.

Este tutorial cubre la **serie Openterface KVM** — dispositivos que capturan el salto de video HDMI del objetivo y remiten las entradas de teclado/mouse a través de emulación HID:

- **Mini-KVM** — Adaptador USB compacto KVM
- **KVM-Go** — KVM portátil en un formato de kit
- **uConsole KVM Extension** — KVM integrado para el uConsole

> **Plataformas:** macOS, Windows, Linux (aplicaciones de escritorio), **Android** (aplicación móvil) y **iPadOS** (aplicación de tableta).
> Notas específicas para Android e iPadOS están marcadas a lo largo.
> **Nota:** Solo se apoya iPadOS en KVM-Go — la aplicación de iPadOS conecta vía Bluetooth LE al dongle KVM-Go.

> ¿Buscando **KeyMod** (sólo emulador de teclado y mouse)? Consulte el [tutorial de KeyMod](../keymod/index.md).
