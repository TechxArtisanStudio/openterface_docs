
# درس KVM 03 — الميزات المتقدمة

**الجمهور:** من متوسط إلى خبير — ميزات المستخدم المتقدم والإعداد

## 1. نظام التفضيلات

### الفيديو

- **الدقة ومعدل الإطارات** — إعدادات الالتقاط المفضلة
- **Media backend** — FFmpeg، GStreamer (Linux)، أو Qt Multimedia (Windows)
- **تسريع الأجهزة** — VAAPI (Intel/AMD)، V4L2-M2M (Raspberry Pi)
- **نسبة العرض إلى الارتفاع والتحجيم** — نسبة مخصصة، Stretch/Fit/Fill

### الصوت

- **مفعّل** — تبديل التقاط الصوت من الهدف
- **جهاز الإدخال/الإخراج** — اختيار المصدر وجهاز التشغيل

### التحكم بالهدف

- **وضع الفأرة** — Absolute، Relative (HID)، Relative (Events)
- **تحديد معدل أحداث الفأرة** — 30–1000 حدث/ثانية
- **تخطيط لوحة المفاتيح** — نظام التشغيل الهدف والتخطيطات الإقليمية
- **فترة تكرار ضغط المفتاح** — سرعة التكرار عند الضغط المطول
- **إخفاء المؤشر تلقائيًا** — إخفاء مؤشر المضيف فوق منطقة الفيديو

### التسجيل

- **مستوى السجل** — Debug، Info، Warning، Error
- **التسجيل في ملف** — `~/Documents/openterface.log` (macOS) أو مسار مُعد (Qt)
- **تسجيل Serial** — سجل منفصل للاتصال التسلسلي

## 2. إدارة EDID

### ما هو EDID؟

EDID (Extended Display Identification Data) هي البيانات التي يرسلها جهاز KVM إلى الهدف لوصف قدرات العرض — الدقات المدعومة، معدلات التحديث، معلومات الشركة المصنعة. يعمل KVM كـ«شاشة وهمية»، لذا يحدد EDID الدقات التي سينتجها الهدف.

### تحرير اسم عرض EDID

يمكنك تغيير اسم العرض الذي يُبلّغ به جهاز KVM إلى الهدف. يظهر هذا الاسم في إعدادات العرض لنظام التشغيل الهدف.

> **ملاحظة:** يُدعم حاليًا تحرير اسم العرض فقط. تحرير الدقة والإدخالات المخصصة للدقة غير متاحة بعد.

**الوصول:** Settings > EDID Display Name Editor (macOS) أو Device > Update Display Settings (Qt)

### حالات الاستخدام

- **تحديد العرض** في إعدادات نظام التشغيل الهدف
- **تسمية مخصصة** في إعدادات متعددة الشاشات لتمييز عرض KVM

## 3. نظام الماكرو (macOS)

الماكرو هي تسلسلات محفوظة لإجراءات لوحة المفاتيح، تُشغَّل من لوحة الماكرو في شريط الأدوات.

### تنسيق تسلسل المفاتيح

**وسوم المعدّلات:** `<CTRL>`، `<SHIFT>`، `<ALT>`، `<CMD>` (تُعيَّن إلى Cmd/Win/Super حسب نظام التشغيل الهدف)

**مفاتيح خاصة:** `<ESC>`، `<BACK>`، `<ENTER>`، `<TAB>`، `<SPACE>`، `<LEFT>`، `<RIGHT>`، `<UP>`، `<DOWN>`، `<HOME>`، `<END>`، `<DEL>`، `<PGUP>`، `<PGDN>`، `<F1>`–`<F12>`

**تأخيرات:** `<DELAY05s>`، `<DELAY1S>`، `<DELAY2S>`، `<DELAY5S>`، `<DELAY10S>`

### أمثلة

<CMD>c</CMD>              # Copy on macOS
<CTRL>c</CTRL>            # Copy on Windows
<DELAY05s><ENTER>         # Wait, then press Enter
### التوليد بمساعدة الذكاء الاصطناعي

زر **Magic** في محرر الماكرو يولّد ماكرو من اللغة الطبيعية. صف ما تريده وسينتج الذكاء الاصطناعي تسلسل المفاتيح.

### التحقق

علّم الماكرو كـ **verified** بعد الاختبار. فقط الماكرو المُتحقَّق منها متاحة لوكيل الذكاء الاصطناعي للتنفيذ الذاتي.

## 4. Script Tool (Qt)

لغة scripting مستوحاة من AutoHotKey لأتمتة إجراءات لوحة المفاتيح والفأرة على الهدف.

### الفتح

القائمة: **Device > Script Tool**

### الأوامر

| Command | Description | Example |
|---------|-------------|---------|
| `Sleep` | إيقاف التنفيذ مؤقتًا | `Sleep 1000` |
| `Send` | إرسال ضغطات المفاتيح | `Send Hello World` |
| `Click` | نقرة فأرة | `Click 100 200` |
| `SetCapsLockState` | تبديل CapsLock | `SetCapsLockState On` |
| `FullScreenCapture` | لقطة شاشة | `FullScreenCapture "/tmp/shot.png"` |

### بادئات المعدّلات

`^` = Ctrl، `+` = Shift، `!` = Alt، `#` = Win

## 5. تحديثات Firmware

### متى تُحدَّث

- ميزات hardware جديدة
- إصلاحات أخطاء
- تحسينات التوافق

### عملية التحديث

1. افتح Firmware Update Tool (**Settings > Firmware Update Tool** على macOS، **Device > Update Firmware** على Qt)
2. يتحقق الأداة من أحدث إصدار من الشبكة
3. يُتتبَّع التقدم أثناء عملية الكتابة
4. **لا تفصل الجهاز أثناء التحديث**

### الاستعادة

1. أبقِ الجهاز قيد التشغيل
2. أغلق وأعد فتح Firmware Update Tool، أعد المحاولة
3. استخدم Serial Reset Tool إذا كان الجهاز لا يستجيب

## 6. Serial Reset Tool

**الوصول:** Settings > Serial Reset Tool (macOS) أو Device > Factory Reset HID Chip (Qt)

استخدم عندما:
- الجهاز في حالة غير معروفة بعد فشل تحديث firmware
- شريحة HID لا تستجيب
- تجهيز الجهاز لإعادة البيع

## 7. التشخيص (Qt)

القائمة: **Device > Device Diagnostics**

ينفّذ اختبارات hardware بالتتابع:
1. اختبار اتصال Serial
2. حالة USB الهدف
3. اختبار إعادة ضبط المصنع
4. اختبار baudrate عالي/منخفض
5. اختبار الإجهاد (أوامر سريعة، قياس معدل النجاح)
6. اختبار plug & play (اكتشاف فصل/إعادة توصيل USB)

بعد التشغيل، صدّر النتائج عبر **Support Email Dialog**.

## 8. نظام AI Chat (macOS)

مساعد ذكاء اصطناعي مدمج يمكنه تحليل شاشة الهدف، اقتراح إجراءات، وتنفيذ عمليات لوحة المفاتيح/الفأرة.

### أوضاع الدردشة

| Mode | Description |
|------|-------------|
| **Interactive** | اطرح أسئلة، احصل على إرشاد |
| **Agentic** | الذكاء الاصطناعي يخطط وينفّذ مهام متعددة الخطوات بذاته |
| **Guide** | تعليمة واحدة في كل مرة، خطوة بخطوة |
| **Planner** | الطلبات المعقدة تُقسَّم إلى خطط منظمة |

### الإعداد

Settings > AI Chat: API endpoint، key (مخزّن في Keychain)، model، target system (macOS/Windows/Linux/etc.)

| Scenario | Mode |

## 10. خادم TCP (Qt)

خادم TCP مدمج للتحكم عن بُعد على المنفذ 12345.

### الأوامر

`CHECK_STATUS`، `GET_LAST_IMAGE`، `GET_TARGET_SCREEN`، `SCRIPT_COMMAND`

### مثال Python

```python
import socket
sock = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
sock.connect(("localhost", 12345))
sock.send(b"CHECK_STATUS\n")
print(sock.recv(4096).decode())
sock.close()
> **الأمان:** لا مصادقة ولا تشفير ولا تحديد معدل. فعّل فقط على شبكات موثوقة.

## ميزات خاصة بـ iPadOS

### إدارة اتصال Bluetooth

يتصل تطبيق iPadOS بـ dongle KVM-Go عبر **Bluetooth Low Energy (BLE)** لإدخال HID للوحة المفاتيح/الفأرة:

- **Auto-connect:** مفعّل افتراضيًا. عند البدء، يمسح التطبيق لمدة 5 ثوانٍ ويتصل تلقائيًا بجهاز `kvm*` ذي أقوى إشارة.
- **إعادة الاتصال:** إذا انقطع الاتصال، يحاول التطبيق إعادة الاتصال حتى 3 مرات بتأخير ثانيتين.
- **مراقبة الإشارة:** يُحدَّث RSSI كل ثانيتين. يعرض زر BLE قوة الإشارة (مثل `-45 dBm`) مع مؤشر لوني: أخضر (-50 إلى 0 dBm)، برتقالي (-70 إلى -50 dBm)، أحمر (أقل من -70 dBm).
- **مسح الأجهزة:** تظهر في القائمة فقط الأجهزة التي يبدأ اسمها بـ `kvm` (بغض النظر عن حالة الأحرف).
- **التحكم اليدوي:** افتح شاشة BLE للمسح والاتصال والفصل أو تعطيل auto-connect.

### طبقة Info

انقر زر **Info** لعرض طبقة حالة الإدخال في الوقت الفعلي في الزاوية العلوية اليمنى:

```
┌─ حالة الإدخال ─────────┐
│ Mouse                  │
│ Mode: Absolute         │
│ Position: 512.0, 384.0 │
│ Drag Mode: Active      │
│ Scrolling: Inactive    │
│ Keyboard               │
│ Mode: Normal           │
│ Caps Lock: OFF         │
│ Modifiers: Ctrl, Shift │
└────────────────────────┘
```

الطبقة شفافة للمس — لا تعيق التفاعل مع معاينة الفيديو.

### تصحيح اتجاه الشاشة

انقر زر **Rotate** للتنقل بين أوضاع تصحيح الاتجاه: Normal، 90° CW، 180°، 90° CCW. يصحّح معاينة الفيديو عند تركيب dongle KVM-Go باتجاه غير قياسي. ينطبق التدوير على المعاينة المباشرة واللقطات المحفوظة.

### مؤقت الخمول معطّل

يبقي التطبيق شاشة iPad **مستيقظة** أثناء الاستخدام بتعطيل مؤقت الخمول، ويمنع iPad من القفل التلقائي أثناء مراقبة PC الهدف.

### نظام التسجيل

يتضمن التطبيق `Logger` مدمجًا مع تصفية حسب الفئة:

| Category | Covers |
|---|---|
| `bluetooth` | مسح BLE، الاتصال، نقل البيانات |
| `mouse` | إدخال الفأرة، اكتشاف الإيماءات، تغيير الأوضاع |
| `keyboard` | أحداث المفاتيح، حالة المعدّلات، المفاتيح المركبة |
| `camera` | تسجيل الفيديو، لقطات الشاشة، التقاط الصور |
| `ui` | معالجة اللمس، التعرف على الإيماءات، طبقة المعاينة |
| `general` | دورة حياة التطبيق، معلومات عامة |

يمكن ضبط التسجيل في مصدر التطبيق لتقليل ضوضاء وحدة التحكم.

## ميزات خاصة بـ Android

### لوحة الإعدادات

تحتوي لوحة إعدادات تطبيق Android (زر القائمة ☰) على جميع خيارات الإعداد:

| Setting | Description |
|---|---|
| **Device** | يعرض أجهزة USB المتصلة والحالة. انقر للاختيار أو إعادة المسح. |
| **Disconnect Device** | يحرّر جميع اتصالات USB بأمان. استخدم قبل الفصل. |
| **Baudrate** | سرعة الاتصال Serial: **115200** (افتراضي) أو **9600** (أبطأ، للمشاكل). |
| **Controls** | منزلقات سطوع الكاميرا والتباين والدرجة. |
| **Video Format** | محدد الدقة ومعدل الإطارات. |
| **Rotate/Flip** | تدوير 90° CW/CCW، قلب أفقي/عمودي. |
| **Screen Capture / Record Video** | لقطة شاشة وتسجيل فيديو. |
| **Relative / Absolute / Drag** | تبديل وضع التحكم بالفأرة. |
| **About Device** | يعرض إصدار Android ومعلومات إصدار التطبيق. |

### استمرارية الإعدادات

يتذكر تطبيق Android تفضيلاتك بين الجلسات:

| Setting | Persisted? |
|---|---|
| وضع التحكم بالفأرة | نعم |
| تنسيق الفيديو (الدقة، FPS) | نعم |
| معاملات الكاميرا (السطوع، التباين، الدرجة) | نعم |
| تخطيط لوحة المفاتيح (US، JP، DE) | نعم |
| Baudrate | نعم |
| سجل اتصال الجهاز | نعم |

عند إعادة فتح التطبيق، يستعيد آخر إعداداتك. لإعادة ضبط كل شيء: إعدادات Android → التطبيقات → Openterface → التخزين → **مسح البيانات**.

### الفصل الآمن

قبل فصل جهاز KVM على Android:

1. افتح لوحة الإعدادات
2. انقر **Disconnect Device** (يظهر باللون الأحمر)
3. انتظر حتى يحرّر التطبيق اتصال USB
4. افصل الكابلات

يمنع ذلك تلف البيانات ويضمن أن الكمبيوتر الهدف يحرّر لوحة المفاتيح/الفأرة بشكل صحيح.

### نصائح أداء Android

- **خفّض الدقة** — 640×480 أخف بكثير من 1920×1080
- **قلّل معدل الإطارات** — 30fps يستخدم عرض نطاق أقل من 60fps
- **أغلق التطبيقات الأخرى** — حرّر ذاكرة هاتفك
- **استخدم محول USB OTG جيد** — المحولات الرخيصة قد تعيق الاتصال
- يعمل فريق التطوير على تقليل زمن الاستجابة في مسار الكاميرا نفسه
