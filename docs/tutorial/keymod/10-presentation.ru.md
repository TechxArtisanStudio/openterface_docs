# 10. Презентация

Управляйте слайд-шоу со своего телефона — кликер не нужен.

## Элементы управления

| Button | |
|---|---|
| **Следующий** | Переход к следующему слайду (стрелка вправо). Длительное нажатие = переход к последнему слайду |
| **Предыдущий** | Переход на один слайд назад (стрелка влево). Длительное нажатие = переход к первому слайду |
| **Воспроизвести/Стоп** | Запускает/останавливает презентацию |
| **B (Пустой экран)** | Включает черный экран |
| **Указатель** | Открывает всплывающее окно touchpad для управления мышью |
| **Переключатель приложений** | Открывает переключатель приложений ОС (Cmd+Tab / Alt+Tab) |

## Выбор инструмента презентации

Карусель позволяет выбрать программное обеспечение для презентаций (Keynote, PowerPoint, Google Slides, Word, Adobe Reader). Каждый инструмент имеет уникальные комбинации клавиш для воспроизведения/остановки.

## Таймер слайда

Карта таймера поддерживает режимы обратного и обратного отсчета с индикатором выполнения, вибрацией в заданное время и постоянным состоянием на протяжении всего жизненного цикла приложения.

## Жесты

- **Проведите пальцем влево** → Следующий слайд
- **Смахните вправо** → Предыдущий слайд.
- **Нажмите** → Следующий слайд
