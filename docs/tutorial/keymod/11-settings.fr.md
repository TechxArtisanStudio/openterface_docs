# 11. Paramètres

Configurez le comportement et l'apparence de KeyMod.

## Paramètres généraux

| Paramètre | Descriptif |
|---|---|
| **Connexion automatique** | Reconnectez-vous au dernier appareil (USB ou BLE) au démarrage |
| **Gardez l'écran allumé** | Empêcher l'écran de dormir lors de l'utilisation de l'application |
| **Retour haptique** | Vibration sur button presses |
| **Verrouillage d'orientation** | Verrouiller l'orientation de l'écran en mode portrait ou paysage |
| **Langue** | English, 中文, Español, Français, Deutsch, 日本語 |
| **Thème** | 8 familles de couleurs, Foncé/Clair, Système Follow |
| **BLE Retard de touche** | Délai entre les frappes envoyées sur BLE (ajustez si des caractères sont manqués) |
| **Touchpad sensibilité** | Curseur de sensibilité de défilement |

## Système d'exploitation cible

Définissez le système d'exploitation cible pour qu'il corresponde aux conventions clés de l'ordinateur cible. Cela affecte les étiquettes de raccourci, les méthodes de saisie Unicode et le mappage des touches de modification.

| Cible | Cartographie des touches |
|--------|-------------|
| **Windows** | Comportement des touches Alt, Ctrl, Win |
| **Mac** | Comportement des touches Cmd, Option |
| **Linux** | Comportement des touches Super, Meta |

Modifiez le système d'exploitation cible en appuyant sur l'**icône du système d'exploitation** dans la barre d'en-tête.

Voir [Target-Specific Keyboard](03-target-keyboard.md) pour la disposition du clavier et les détails de saisie Unicode.
