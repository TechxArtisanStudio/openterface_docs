# 3. ターゲット OS

KeyMod はターゲット PC の OS に合わせたキー入力を送信します。正しく設定するとターゲットに正しいキーが届きます。

## 設定方法

ヘッダーの **OS アイコン** をタップしてピッカーを開きます。

<div align="center">
  <img src="images/demo-target-os-picker.png" alt="ターゲット OS ピッカー" width="300" />
  <p><em>ターゲット OS ピッカー — macOS、Windows、Linux を選択。</em></p>
</div>

> **注:** この画面のスクリーンショットはまだありません。ヘッダーの OS アイコンをタップすると、3つのアイコンボタン（macOS、Windows、Linux）があるダイアログが開きます。

## 変更される内容

| ターゲット | キーマッピング |
|--------|-------------|
| **Windows** | Win キーは Windows キー；標準 PC 修飾キー動作 |
| **macOS** | Win キーは Cmd；Alt は Option；ショートカットラベルが正しい |
| **Linux** | Super/Meta キー動作 |

影響する項目：
- **ショートカットハブ** のラベル
- **修飾キーマッピング**（Win キー動作）
- 非 ASCII 文字の **Unicode 入力方法**

## Unicode 文字

非 ASCII（中国語、日本語、絵文字）は OS 固有の入力方法が必要です。

| OS | 方法 |
|---|---|
| **Windows** | Alt+テンキー16進 Unicode |
| **Linux** | Ctrl+Shift+U の後に16進コード |
| **macOS** | Option+16進入力 |

ターゲットで Unicode が正しく表示されない場合は、ターゲット OS 設定を確認してください。

## キーボードモード（レイアウトではない）

| モード | 切り替え |
|---|---|
| **ABC**（文字） | **ABC** キーをタップ |
| **123**（数字） | **123** キーをタップ |
| **!?#**（記号） | **!?#** キーをタップ |

これらはアプリ内の入力切替であり、物理キーボードレイアウトではありません。KeyMod は標準 USB HID スキャンコード（US QWERTY ベース）を送信します。ターゲットが非 US 物理キーボードの場合、同一キー位置の記号が多少ずれることがあります。
