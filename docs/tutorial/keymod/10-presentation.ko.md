# 10. 프레젠테이션

휴대폰에서 슬라이드쇼를 제어하세요. 클릭커가 필요하지 않습니다.

## 컨트롤

| Button | |
|---|---|
| **다음** | 다음 슬라이드로 이동합니다(오른쪽 화살표). 길게 누르기 = 마지막 슬라이드로 이동 |
| **이전** | 한 슬라이드 뒤로 이동합니다(왼쪽 화살표). 길게 누르기 = 첫 번째 슬라이드로 이동 |
| **재생/중지** | 프레젠테이션 시작/중지 |
| **B(빈 화면)** | 검은색 화면을 전환합니다 |
| **포인터** | 마우스 제어를 위한 팝업 열기 touchpad |
| **앱 전환기** | OS 앱 전환기 열기(Cmd+Tab / Alt+Tab) |

## 프레젠테이션 도구 선택기

캐러셀을 사용하면 프레젠테이션 소프트웨어(Keynote, PowerPoint, Google 슬라이드, Word, Adobe Reader)를 선택할 수 있습니다. 각 도구에는 재생/중지를 위한 고유한 키 조합이 있습니다.

## 슬라이드 타이머

타이머 카드는 진행률 채우기 표시줄, 목표 시간에 대한 진동 알림, 앱 수명 주기 전반에 걸친 지속적인 상태를 포함한 카운트다운 및 카운트업 모드를 지원합니다.

## 제스처

- **왼쪽으로 스와이프** → 다음 슬라이드
- **오른쪽으로 스와이프** → 이전 슬라이드
- **탭** → 다음 슬라이드
