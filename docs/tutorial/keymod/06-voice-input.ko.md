# 6. 음성 입력

음성을 대상 컴퓨터로 전송되는 키 입력으로 변환하여 핸즈프리 타이핑 및 접근성을 제공합니다.

## 작동 방식

1. **마이크** button를 탭합니다.
2. 입력하고 싶은 내용을 말하세요.
3. 당신의 말이 텍스트로 변환됩니다
4. 텍스트가 대상 컴퓨터에 키 입력으로 전송됩니다.

## STT 엔진

| 엔진 | 작동 원리 | 설정 |
|---|---|---|
| **시스템 인식기** | Android 내장 음성 인식 사용 | Google 음성 입력 필요 |
| **Whisper** | 온디바이스 또는 클라우드 AI 전사 | 설정 > 음성 입력에서 API 키 설정 |

## 침묵 감지 및 자동 일시 정지

두 엔진 모두 말하기를 멈추면 녹음을 일시 중지하는 자동 무음 감지 기능을 갖추고 있습니다(기본적으로 무음 시간 제한 2.0초). 음성 입력 보기에서 자동 일시 중지를 켜거나 끕니다.

### 무음 감지 문제 해결

| 증상 | 솔루션 |
|---|---|
| **말하지 않아도 녹음은 계속됩니다** | 침묵 시 자동 일시 중지 토글을 확인하세요. 배경 소음을 줄입니다. 마이크 가까이에서 명확하게 말하세요. |
| **녹음이 즉시 중지됩니다** | 더 큰 소리로 말하거나 침묵 감지 시간 제한을 줄이세요. |

## 미니 툴바(Android)

| Button | 그것이 하는 일 |
|---|---|
| **복사** | 복사된 텍스트를 클립보드에 복사 |
| **자동 보내기** | 전사 후 자동으로 텍스트 보내기 |
| **자동 라인 복귀** | 전송 후 Enter 키 입력 추가 |
| **AI 개선** | 개선을 위해 녹음된 텍스트를 AI에 보내기 |

## 음성문자가 전송되지 않습니다

연결 상태를 확인하세요. 연결되지 않으면 "보내기" button가 비활성화됩니다.
