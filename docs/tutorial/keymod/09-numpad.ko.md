# 9. 숫자 패드

데이터 입력을 위한 전체 숫자 키패드. 각 키는 해당하는 HID 숫자 패드 키 코드를 보냅니다.

## 키 매핑

| 열쇠 | HID 사용 코드 |
|------|---------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| 입력 | 0x58 |
| . / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## 애플리케이션별 그리드

일부 바로가기 프로필(Blender, Fusion 360, KiCad)에는 특정 애플리케이션에 맞춰진 **사용자 정의 숫자 패드 그리드**가 포함되어 있습니다.
