# 9. Pavé numérique

Un clavier numérique complet pour la saisie des données. Chaque touche envoie le code de touche du pavé numérique HID correspondant.

## Mappage des touches

| Clé | HID Code d'utilisation |
|-----|---------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| Entrez | 0x58 |
| . / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## Grilles spécifiques aux applications

Certains profils de raccourcis (Blender, Fusion 360, KiCad) incluent des **grilles de pavé numérique personnalisées** adaptées à leurs applications spécifiques.
