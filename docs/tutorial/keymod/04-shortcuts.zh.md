# 4. 快捷方式中心

一键访问常用键盘快捷键，按应用组织。快捷方式标签会根据 **目标系统** 自动适配（Windows/Linux 为 Ctrl+Z，macOS 为 Cmd+Z）。

## 内置配置文件

| 配置文件 | 涵盖内容 |
|---|---|
| **Default** | 常用快捷键（复制、粘贴、撤销、保存等）— 不可删除 |
| **Blender 3D** | 变换、选择、视图、网格、模式与着色快捷键 |
| **KiCAD** | PCB 设计：图层、绘图、元件、属性 |
| **Nomad Sculpt** | 雕刻工具、笔刷、变换、视图、遮罩 |
| **Fusion 360** | CAD：导航、草图、建模、构造、装配 |
| **Photoshop** | 工具、编辑、视图快捷键 |
| **VS Code** | 导航、编辑、代码、视图快捷键 |

## 使用快捷方式

1. 打开 **快捷方式中心**（或在 Android 侧栏选择「Shortcuts」模式）
2. 点击任意配置文件打开
3. 在配置内浏览 **分类标签**，点击任意快捷方式卡片执行
4. 快捷方式标签会根据 **目标系统** 自动适配

## 创建与管理配置文件

| 操作 | 方法 |
|---|---|
| 创建配置文件 | 点击 **「Create Profile」**，输入名称 |
| 编辑快捷方式 | 长按快捷方式 →「Edit」 |
| 删除快捷方式 | 长按快捷方式 →「Delete」 |
| 添加到收藏 | 长按 →「Add to My」 |
| 复制配置文件 | 长按配置文件 →「Duplicate」 |
| 导出配置文件 | 长按 →「Export」— 保存 JSON 文件 |
| 导入配置文件 | 点击 **「Import」** — 粘贴 JSON 或浏览文件 |

每个配置文件还有 **My Shortcuts** 区域，用于个人快捷方式。
