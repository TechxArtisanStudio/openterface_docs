#10. プレゼンテーション

携帯電話からスライドショーを制御します。クリッカーは必要ありません。

## コントロール

| Button |する |
|---|---|
| **次へ** |次のスライドに進みます (右矢印)。長押し = 最後のスライドに移動 |
| **前** | 1 スライド前に戻ります (左矢印)。長押し = 最初のスライドに移動 |
| **再生/停止** |プレゼンテーションを開始/停止します |
| **B (空白の画面)** |黒い画面を切り替えます |
| **ポインタ** |マウス制御用のポップアウト touchpad を開きます |
| **アプリ スイッチャー** | OS アプリスイッチャーを開きます (Cmd+Tab / Alt+Tab) |

## プレゼンテーション ツール ピッカー

カルーセルを使用すると、プレゼンテーション ソフトウェア (Keynote、PowerPoint、Google スライド、Word、Adobe Reader) を選択できます。各ツールには、再生/停止のための固有のキーの組み合わせがあります。

## スライドタイマー

タイマー カードは、進行状況の塗りつぶしバー、目標時間の振動アラート、アプリのライフサイクル全体にわたる永続的な状態を備えたカウントダウン モードとカウントアップ モードをサポートします。

## ジェスチャー

- **左にスワイプ** → 次のスライド
- **右にスワイプ** → 前のスライド
- **タップ** → 次のスライド
