# 1. Начало работы

Установите приложение KeyMod, подключитесь к оборудованию KeyMod и отправьте первое нажатие клавиши менее чем за 5 минут.

## Что вам нужно

- **Openterface KeyMod оборудование** — питание включено и находится в пределах досягаемости.
- **Телефон или планшет** — Android с установленным приложением KeyMod.
- **Кабель USB** (для первоначальной настройки) — USB-C для подключения телефона к устройству KeyMod
- **Bluetooth** (опционально) — для беспроводного подключения после первоначальной настройки.

## Шаг 1. Установите приложение KeyMod

**Android:**

1. Откройте браузер телефона и перейдите на страницу [KeyMod GitHub Releases page](https://github.com/TechxArtisanStudio/Openterface_KeyMod_Android/tags)
2. Загрузите последнюю версию файла `.apk`.
3. Нажмите загруженный файл для установки.
4. Если появится запрос Android, разрешите **"Установить неизвестные приложения"** для вашего браузера.

Альтернативно, создайте сборку из исходного кода — см. [Build from Source](#build-from-source) ниже.

## Шаг 2. Подключитесь к устройству KeyMod

KeyMod подключается к оборудованию Openterface KeyMod двумя способами:

### USB Подключение (рекомендуется при первой настройке)

1. Подключите телефон к устройству KeyMod с помощью кабеля USB-C.
2. Откройте приложение KeyMod.
3. Нажмите значок подключения (правый верхний угол главного экрана).
4. Нажмите **"USB Соединение»**.
5. Примите запрос разрешения USB при появлении соответствующего запроса.
6. Вы должны увидеть зеленый индикатор состояния **Подключено**.

### Соединение Bluetooth (беспроводное)

1. Убедитесь, что на вашем телефоне включен Bluetooth.
2. Откройте KeyMod и коснитесь значка подключения.
3. Нажмите **«Подключение Bluetooth»**.
4. Подождите, пока ваше устройство KeyMod появится в списке сканирования.
5. Коснитесь его, чтобы выполнить сопряжение.
6. Вы должны увидеть зеленый индикатор состояния **Подключено**.

> **Совет:** Включите **"Автоматическое подключение при запуске"** в диалоговом окне подключения, чтобы KeyMod автоматически переподключался каждый раз, когда вы его открываете. Приложение запоминает тип вашего последнего подключения (USB или BLE).

## Шаг 4: Отправьте первое нажатие клавиши

1. Выберите режим **Клавиатура и мышь**.
2. Нажмите любую клавишу на экранной клавиатуре.
3. Соответствующее нажатие клавиши отправляется на целевой компьютер.

Вот и все! Теперь вы управляете своим целевым компьютером удаленно.

## Индикаторы состояния соединения

| Индикатор | Значение |
|---|---|
| **Зеленый** (значок подключения) | Активное соединение, готово к отправке ввода |
| **Желтый/Синий** (значок подключения) | Соединение выполняется |
| **Серый** (значок отключен) | Нет активного соединения |
| **Сигнальные полосы** | BLE уровень сигнала или USB активное состояние |

## Сборка из исходного кода (Android, для разработчиков)```bash
# Clone the repository
git clone https://github.com/TechxArtisanStudio/Openterface_KeyMod_Android.git
cd Openterface_KeyMod_Android

# Build (requires Java 21 and Android SDK 35)
./gradlew assembleDebug

# The APK will be at:
ls app/build/outputs/apk/debug/KeyMod-debug.apk

# Install on a connected device
adb install -r app/build/outputs/apk/debug/KeyMod-debug.apk
