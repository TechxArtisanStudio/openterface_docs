# 10. Apresentação

Controle sua apresentação de slides a partir do seu telefone – não é necessário clicar.

## Controles

| Button | Faz |
|---|---|
| **Próximo** | Avança para o próximo slide (seta para a direita). Pressão longa = ir para o último slide |
| **Anterior** | Retrocede um slide (seta para a esquerda). Pressão longa = ir para o primeiro slide |
| **Reproduzir/Parar** | Inicia/para a apresentação |
| **B (tela em branco)** | Alterna tela preta |
| **Ponteiro** | Abre um pop-out touchpad para controle do mouse |
| **Alterador de aplicativos** | Abre o alternador de aplicativos do SO (Cmd+Tab / Alt+Tab) |

## Seletor de ferramenta de apresentação

Um carrossel permite selecionar seu software de apresentação (Keynote, PowerPoint, Google Slides, Word, Adobe Reader). Cada ferramenta possui combinações de teclas exclusivas para reproduzir/parar.

## Temporizador de slides

O cartão temporizador oferece suporte aos modos de contagem regressiva e crescente, com uma barra de preenchimento de progresso, alerta vibratório no horário desejado e estado persistente durante todo o ciclo de vida do aplicativo.

## Gestos

- **Deslize para a esquerda** → Próximo slide
- **Deslize para a direita** → Slide anterior
- **Toque** → Próximo slide
