# 7. AI 集成

AI 增强的语音输入，含文本润色与自然语言命令转换。

> AI 功能 **默认关闭**。请在设置中启用以使用这些功能。

## 功能

- **文本润色** — 纠正转写错误并提升文字质量
- **命令助手** — 将自然语言语音转换为键盘命令

## AI 提供商

| 提供商 | 选项 |
|---|---|
| **AI provider** | OpenAI、Anthropic、Google Gemini、Mistral AI、Groq、Alibaba (Qwen)、DeepSeek 或 Custom |
| **API endpoint** | 设置 AI 服务 URL |
| **Model** | 选择 AI 模型 |
| **API Key** | 在 设置 > AI Settings 中设置 |
| **AI role** | 「Command Assistant」（语音 → 键盘操作）或「Text Refinement」（语音 → 改进文字） |

## 系统提示角色

- **Text Refinement：** 纠正语音转文字错误，改进语法与清晰度
- **Command Assistant：** 将自然语言转换为键盘命令。针对 Windows、macOS、Linux 的系统提示。
- **Custom：** 用户自定义系统提示，用于定制行为

## AI 中的宏上下文

启用 AI 后，已定义的宏会自动包含在系统提示中，AI 可按名称建议或调用它们。

## 故障排除

### API 密钥无效

| 现象 | 解决方案 |
|---|---|
| **「API key not configured」** | 确认 API 密钥正确 — 检查多余空格或拼写错误。检查 API Base URL — 须包含完整路径（如 `https://api.openai.com/v1`）。确认模型名称在提供商处存在。本地提供商（Ollama）请设置 API Key Optional 标志。 |

### 文本润色较慢

检查网络连接。尝试更快模型 — 较小模型（gpt-3.5-turbo、llama3-8b）响应更快。使用本地提供商（Ollama）消除网络延迟。查看 AI Request History 中的错误信息。
