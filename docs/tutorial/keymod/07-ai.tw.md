# 7. AI 集成

AI 增強的語音輸入，含文本潤色與自然語言命令轉換。

> AI 功能 **默認關閉**。請在設置中啟用以使用這些功能。

## 功能

- **文本潤色** — 糾正轉寫錯誤並提升文字質量
- **命令助手** — 將自然語言語音轉換為鍵盤命令

## AI 提供商

| 提供商 | 選項 |
|---|---|
| **AI provider** | OpenAI、Anthropic、Google Gemini、Mistral AI、Groq、Alibaba (Qwen)、DeepSeek 或 Custom |
| **API endpoint** | 設置 AI 服務 URL |
| **Model** | 選擇 AI 模型 |
| **API Key** | 在 設置 > AI Settings 中設置 |
| **AI role** | 「Command Assistant」（語音 → 鍵盤操作）或「Text Refinement」（語音 → 改進文字） |

## 系統提示角色

- **Text Refinement：** 糾正語音轉文字錯誤，改進語法與清晰度
- **Command Assistant：** 將自然語言轉換為鍵盤命令。針對 Windows、macOS、Linux 的系統提示。
- **Custom：** 用戶自定義系統提示，用於定製行為

## AI 中的宏上下文

啟用 AI 後，已定義的宏會自動包含在系統提示中，AI 可按名稱建議或調用它們。

## 故障排除

### API 密鑰無效

| 現象 | 解決方案 |
|---|---|
| **「API key not configured」** | 確認 API 密鑰正確 — 檢查多餘空格或拼寫錯誤。檢查 API Base URL — 須包含完整路徑（如 `https://api.openai.com/v1`）。確認模型名稱在提供商處存在。本地提供商（Ollama）請設置 API Key Optional 標誌。 |

### 文本潤色較慢

檢查網絡連接。嘗試更快模型 — 較小模型（gpt-3.5-turbo、llama3-8b）響應更快。使用本地提供商（Ollama）消除網絡延遲。查看 AI Request History 中的錯誤信息。
