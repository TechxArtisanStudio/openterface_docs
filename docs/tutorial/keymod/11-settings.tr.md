# 11. Ayarlar

KeyMod'ın davranışını ve görünümünü yapılandırın.

## Genel Ayarlar

| Ayar | Açıklama |
|---|---|
| **Otomatik bağlantı** | Başlangıçta son cihaza (USB veya BLE) yeniden bağlanın |
| **Ekranı açık tut** | Uygulamayı kullanırken ekranın uyku moduna geçmesini önleyin |
| **Dokunsal geri bildirim** | button basışta titreşim |
| **Yön kilidi** | Ekran yönünü dikey veya yatay olarak kilitleyin |
| **Dil** | İngilizce, 中文, Español, Français, Deutsch, 日本語 |
| **Tema** | 8 renk ailesi, Koyu/Açık, Takip sistemi |
| **BLE Tuş Gecikmesi** | BLE üzerinden gönderilen tuş vuruşları arasındaki gecikme (karakterler eksikse ayarlayın) |
| **Touchpad hassasiyet** | Kaydırma duyarlılığı kaydırıcısı |

## Hedef İşletim Sistemi

Hedef işletim sistemini hedef bilgisayarın temel kurallarına uyacak şekilde ayarlayın. Bu, kısayol etiketlerini, Unicode giriş yöntemlerini ve değiştirici tuş eşlemesini etkiler.

| Hedef | Anahtar Eşleme |
|----------|----------------|
| **Windows** | Alt, Ctrl, Win anahtar davranışı |
| **Mac** | Cmd, Option anahtar davranışı |
| **Linux** | Super, Meta anahtar davranışı |

Başlık çubuğundaki **İşletim Sistemi simgesine** dokunarak hedef işletim sistemini değiştirin.

Klavye düzeni ve Unicode giriş ayrıntıları için bkz. [Target-Specific Keyboard](03-target-keyboard.md).
