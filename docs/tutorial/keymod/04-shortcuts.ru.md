# 4. Центр ярлыков

Доступ одним касанием к общим сочетаниям клавиш, организованным по приложениям. Ярлыки ярлыков автоматически адаптируются к **целевой ОС** (Ctrl+Z на Windows/Linux, Cmd+Z на macOS).

## Встроенные профили

| Профиль | Что он охватывает |
|---|---|
| **По умолчанию** | Общие ярлыки (Копировать, Вставить, Отменить, Сохранить и т. д.) — невозможно удалить |
| **Blender 3D** | Ярлыки преобразования, выделения, просмотра, сетки, режима и затенения |
| **KiCAD** | Проектирование печатных плат: слои, чертежи, компоненты, свойства |
| **Nomad Sculpt** | Инструменты для лепки, кисть, трансформация, просмотр, маскирование |
| **Fusion 360** | CAD: навигация, эскиз, моделирование, строительство, сборка |
| **Photoshop** | Инструменты, редактирование, просмотр ярлыков |
| **VS Code** | Навигация, редактирование, код, ярлыки просмотра |

## Использование ярлыков

1. Откройте **Shortcut Hub** (или режим «Ярлыки» на боковой панели Android).
2. Коснитесь любого профиля, чтобы открыть его.
3. В профиле просмотрите **вкладки категорий** и коснитесь любой карточки быстрого доступа, чтобы выполнить ее.
4. Ярлыки ярлыков автоматически адаптируются к **целевой ОС**.

## Создание профилей и управление ими

| Действие | Как |
|---|---|
| Создать профиль | Нажмите **"Создать профиль"**, введите имя |
| Редактировать ярлык | Нажмите и удерживайте ярлык → «Редактировать» |
| Удалить ярлык | Длительное нажатие ярлыка → «Удалить» |
| Добавить в избранное | Длительное нажатие → «Добавить в мое» |
| Дублировать профиль | Длительное нажатие профиля → «Дублировать» |
| Экспортировать профиль | Длительное нажатие → «Экспорт» — сохраняет файл JSON |
| Импортировать профиль | Нажмите ** «Импорт»** — вставьте JSON или найдите файл |

В каждом профиле также есть раздел **Мои ярлыки** для личных ярлыков.
