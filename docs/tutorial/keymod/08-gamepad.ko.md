# 8. 게임 패드

휴대폰을 게임, 레트로 에뮬레이션, 게임 테스트를 위한 가상 게임 컨트롤러로 바꿔보세요.

## 레이아웃

게임패드는 D패드, 작업 버튼, 숄더 버튼, 아날로그 스틱 및 시작/선택이 포함된 전체 컨트롤러 레이아웃을 제공합니다.

| 제어 | 어떻게 |
|---|---|
| D 패드 | 방향 화살표를 탭하세요 |
| 액션 버튼(A, B, X, Y) | 탭하세요 |
| 어깨 버튼 | 상단의 L1, L2, R1, R2를 탭하세요 |
| 아날로그 스틱 | 스틱 원을 터치하고 드래그하세요.
| 시작/선택 | 버튼을 탭하세요 |

## 사전 설정 시스템 (v7)

KeyMod 0.15에서는 **사전 설정 기반 게임패드 시스템**을 도입했습니다. 고정된 내장 레이아웃 대신 게임패드 구성이 이제 순환하고, 가져오고, 내보낼 수 있는 **사전 설정**으로 저장됩니다.

### 사전 설정 관리

- 사용 가능한 레이아웃을 순환하려면 툴바에서 **사전 설정 칩**을 탭하세요.
- 가져오기, 모듈 추가 및 내보내기 옵션이 포함된 전체 사전 설정 목록을 보려면 **사전 설정 칩을 길게 누르세요**
- 번들 **emu-6** 레이아웃은 스타터 사전 설정(`preset_default`)으로 배송됩니다.
- 사전 설정은 레이아웃 **schema v7**을 사용하여 공유 가능한 JSON 파일입니다.

### 모듈 추가

사전 설정 메뉴에서 모든 레이아웃에 새 모듈을 추가할 수 있습니다.

- **D-패드/스틱** — 왼쪽 엄지손가락 모듈 추가(`stick_left`, `stick_left_2` 등)
- **Touchpad** — 번들 L/M/R 마우스 버튼과 함께 touchpad(`touchpad_1`, `touchpad_2` 등)을 추가합니다.
- **버튼** — 페이스 버튼, 숄더 버튼 또는 트리거 추가

## 커스터마이징

- **모든 모듈 구성** - 모듈을 탭하여 구성 대화 상자를 열고 동작을 조정합니다.
- **아날로그 대 키 모드** — 스틱은 `STICK_KEY`(디지털 방향 키) 또는 `STICK_MOUSE`(상대 포인터/마우스 이동)으로 구성할 수 있습니다.
- **WASD 매핑** — PC 게임을 위해 왼쪽 스틱에 WASD 키 할당
- **Button/스틱 크기 조정** — 선호하는 터치 영역에 맞게 크기 조정
- **배경 이미지** — 게임패드 배경을 사용자 정의합니다(공유 사전 설정에 base64, 최대 6 MiB 포함)
- **햅틱 피드백** — button 누를 때 진동(마우스 클릭이 아닌 얼굴 버튼만 해당)
- **자이로** — 게임패드 화면이 활성화된 동안 호스트 포인터를 움직일 수 있도록 장치 자이로스코프를 활성화합니다.

### 모듈 모델

각 화면 컨트롤은 세 개의 레이어로 구성된 **모듈**입니다.

| 레이어 | 그것이 정의하는 것 |
|---|---|
| **슬롯/ID** | 캔버스의 어떤 컨트롤(예: `stick_left`, `stick_right`, `touchpad_1`) |
| **행동(유형)** | 호스트가 받는 것: `STICK_KEY`, `STICK_MOUSE`, `DPAD`, `BUTTON`, `TOUCHPAD` |
| **매개변수** | 동일한 모듈에서 튜닝: `dpadVariant`, `stickMouseSensitivity`, `stickVisualVariant`, 크기, 색상 |

### 아날로그 스틱

- **왼쪽 스틱 → 키보드 키:** 대각선을 지원하는 화살표 키에 매핑됩니다. 모듈 구성에서 WASD로 구성 가능합니다.
- **오른쪽 스틱 → 마우스 움직임:** 감도를 구성할 수 있는 `STICK_MOUSE` 모드(`stickMouseSensitivity`), 드리프트를 방지하기 위한 데드 존.
- **히스테리시스:** 활성화(0.6) 및 비활성화(0.4) 임계값은 경계에서 주요 대화를 방지합니다.

### Touchpad

- **다중 touchpad 지원**: 단일 레이아웃에 여러 개의 터치패드 추가(`touchpad_1`, `touchpad_2` 등)
- 기본적으로 길게 누르면 크기가 조정되는 **정사각형 면적**
- **번들 마우스 버튼**(L/M/R)은 모든 터치패드에서 공유됩니다.
- **마우스 button 크기 조정**: touchpad을 길게 눌러 **마우스 button 크기**를 조정하거나 개별 마우스 button를 길게 눌러 **이 button 크기**를 조정합니다.

> **참고:** 게임패드 HID 프로토콜은 현재 개발 중입니다. 기본 button 지원 작동; 아날로그 스틱의 정밀도는 다를 수 있습니다.

## 문제 해결

### 아날로그 스틱이 응답하지 않음

| 증상 | 솔루션 |
|---|---|
| **스틱이 동작하지 않음** | 모듈 구성을 확인하십시오. 스틱이 데드존(중앙 영역)에 끼어 있지 않은지 확인하십시오. 히스테리시스 임계값을 확인하십시오. 트리거하려면 스틱이 0.6 활성화를 지나 움직여야 합니다. |
| **버튼이 잘못된 키를 전송함** | 모듈 구성을 열고 button의 키 할당을 확인하십시오. button를 눌러 구성 팝업을 열고 매핑을 수정하세요. |
| **Touchpad 마우스 버튼이 클릭되지 않음** | 번들 L/M/R 버튼이 프리셋에 있는지 확인하세요. touchpad을 추가하면 공유 마우스 버튼이 자동으로 추가됩니다. 할당된 HID 키의 모듈 구성을 확인하세요. |
