#8. ゲームパッド

携帯電話をゲーム、レトロエミュレーション、ゲームテスト用の仮想ゲームコントローラーに変えます。

## レイアウト

ゲームパッドは、D パッド、アクション ボタン、ショルダー ボタン、アナログ スティック、スタート/選択を備えた完全なコントローラー レイアウトを提供します。

|コントロール |どのように |
|---|---|
|十字キー |方向矢印 | をタップします。
|アクションボタン (A、B、X、Y) |それらをタップします |
|肩ボタン |上部のL1、L2、R1、R2をタップ |
|アナログスティック |スティックの円をタッチしてドラッグします |
|開始 / 選択 |ボタンをタップします |

## プリセット システム (v7)

KeyMod 0.15 では **プリセットベースのゲームパッド システム**が導入されました。固定の組み込みレイアウトの代わりに、ゲームパッド設定が **プリセット**として保存され、循環、インポート、エクスポートできるようになりました。

### プリセットの管理

- **ツールバーのプリセット チップをタップ**して、利用可能なレイアウトを順番に切り替えます
- **プリセット チップを長押し**すると、インポート、モジュールの追加、エクスポートのオプションを含む完全なプリセット リストが表示されます
- バンドルされた **emu-6** レイアウトはスターター プリセット (`preset_default`) として出荷されます。
- プリセットは、レイアウト **schema v7** を使用して共有可能な JSON ファイルです

### モジュールの追加

プリセット メニューから、任意のレイアウトに新しいモジュールを追加できます。

- **D-Pad / Stick** — 左手親指モジュール (`stick_left`、`stick_left_2` など) を追加します。
- **Touchpad** — バンドルされた L/M/R マウス ボタンを備えた touchpad (`touchpad_1`、`touchpad_2` など) を追加します。
- **ボタン** — 顔ボタン、肩ボタン、またはトリガーを追加します。

## カスタマイズする

- **任意のモジュールを構成** — モジュールをタップして構成ダイアログを開き、動作を調整します
- **アナログ vs キー モード** — スティックは `STICK_KEY` (デジタル方向キー) または `STICK_MOUSE` (ポインタ/マウスの相対移動) として設定できます。
- **WASD マッピング** — PC ゲーム用に WASD キーを左スティックに割り当てます
- **Button/スティック サイズ スケーリング** — 好みのタッチ領域に合わせてサイズを調整します
- **背景画像** — ゲームパッドの背景をカスタマイズします (共有プリセットに base64、最大 6 MiB として埋め込まれます)
- **触覚フィードバック** — button を押すと振動します（マウスのクリックではなくフェイスボタンのみ）
- **ジャイロ** — ゲームパッド画面がアクティブなときにデバイスのジャイロスコープを有効にしてホスト ポインターを移動します

### モジュールモデル

それぞれの画面上のコントロールは、次の 3 つのレイヤーを持つ **モジュール** です。

|レイヤー |定義するもの |
|---|---|
| **スロット/アイデンティティ** |キャンバス上のどのコントロール (例: `stick_left`、`stick_right`、`touchpad_1`) |
| **動作 (タイプ)** |ホストが受け取るもの: `STICK_KEY`、`STICK_MOUSE`、`DPAD`、`BUTTON`、`TOUCHPAD` |
| **パラメータ** |同じモジュールでチューニング: `dpadVariant`、`stickMouseSensitivity`、`stickVisualVariant`、サイズ、色 |

### アナログスティック

- **左スティック → キーボード キー:** 対角線サポート付きの矢印キーにマップされます。モジュール構成で WASD まで設定可能。
- **右スティック → マウスの動き:** 設定可能な感度 (`stickMouseSensitivity`) を備えた`STICK_MOUSE` モード、ドリフトを防ぐデッド ゾーン。
- **ヒステリシス:** アクティブ化 (0.6) と非アクティブ化 (0.4) のしきい値により、境界でのキーのチャタリングを防止します。

### Touchpad

- **マルチ touchpad サポート**: 単一のレイアウトに複数のタッチパッドを追加します (`touchpad_1`、`touchpad_2` など)。
- 長押しでサイズ変更するとデフォルトで **正方形のフットプリント**
- **付属のマウス ボタン** (L/M/R) はすべてのタッチパッドで共有
- **マウス button サイズ**: touchpad を長押しして **マウス button サイズ**を調整するか、個々のマウス button を長押しして **この button サイズ**にします

> **注意:** ゲームパッド HID プロトコルは現在開発中です。基本的な button サポートは動作します。アナログスティックの精度は異なる場合があります。

## トラブルシューティング

### アナログスティックが反応しない

|症状 |ソリューション |
|---|---|
| **スティックがアクションを生成しない** |モジュール構成を確認してください。スティックがデッドゾーン (中央領域) に詰まっていないことを確認します。ヒステリシスのしきい値を確認します。トリガーするには、スティックが 0.6 アクティベーションを超えて移動する必要があります。 |
| **ボタンが間違ったキーを送信する** |モジュール構成を開き、button のキー割り当てを確認します。 button をタップして構成ポップアップを開き、マッピングを修正します。 |
| **Touchpad マウス ボタンがクリックされません** |同梱されている L/M/R ボタンがプリセットに存在することを確認してください。 touchpad を追加すると、共有マウス ボタンが自動的に追加されます。割り当てられた HID キーのモジュール構成を確認してください。 |
