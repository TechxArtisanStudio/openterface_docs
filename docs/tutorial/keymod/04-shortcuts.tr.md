# 4. Kısayol Merkezi

Uygulamaya göre düzenlenen ortak klavye kısayollarına tek dokunuşla erişim. Kısayol etiketleri otomatik olarak **hedef işletim sistemine** uyarlanır (Windows/Linux'de Ctrl+Z, macOS'de Cmd+Z).

## Yerleşik Profiller

| Profil | Neleri kapsıyor |
|---|---|
| **Varsayılan** | Yaygın kısayollar (Kopyala, Yapıştır, Geri Al, Kaydet vb.) — silinemez |
| **Blender 3D** | Dönüştürme, seçme, görüntüleme, ağ oluşturma, mod ve gölgelendirme kısayolları |
| **KiCAD** | PCB tasarımı: katmanlar, çizim, bileşenler, özellikler |
| **Nomad Sculpt** | Şekillendirme araçları, fırça, dönüştürme, görünüm, maskeleme |
| **Fusion 360** | CAD: navigasyon, eskiz, modelleme, inşaat, montaj |
| **Photoshop** | Araçlar, düzenleme, görüntüleme kısayolları |
| **VS Code** | Gezinme, düzenleme, kod, görüntüleme kısayolları |

## Kısayolları Kullanma

1. **Kısayol Merkezini** (veya Android kenar çubuğundan "Kısayollar" modunu) açın.
2. Açmak için herhangi bir profile dokunun
3. Bir profilin içinde **kategori sekmelerine** göz atın ve bunu yürütmek için herhangi bir kısayol kartına dokunun
4. Kısayol etiketleri **hedef işletim sistemine** otomatik olarak uyum sağlar

## Profil Oluşturma ve Yönetme

| Eylem | Nasıl |
|---|---|
| Profil oluştur | **"Profil Oluştur"**'a dokunun, bir ad girin |
| Kısayolu düzenleyin | Kısayola uzun basın → "Düzenle" |
| Kısayolu silme | Kısayola uzun basın → "Sil" |
| Favorilere ekle | Uzun basın → "Benim Ekle" |
| Profili çoğalt | Bir profile uzun basın → "Çoğalt" |
| Profili dışa aktar | Uzun basıldığında → "Dışa aktar" — JSON dosyasını kaydeder |
| Profili içe aktar | **"İçe Aktar"** öğesine dokunun — JSON yapıştırın veya bir dosyaya göz atın |

Her profilde ayrıca kişisel kısayollar için bir **Kısayollarım** bölümü bulunur.
