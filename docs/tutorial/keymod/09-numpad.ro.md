# 9. Numpad

O tastatură numerică completă pentru introducerea datelor. Fiecare tastă trimite codul corespunzător al tastei HID.

## Maparea tastelor

| Cheie | HID Cod de utilizare |
|-----|----------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| Introduceți | 0x58 |
| . / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## Grile specifice aplicației

Unele profiluri de comenzi rapide (Blender, Fusion 360, KiCad) includ **grile personalizate de taste numerice** adaptate aplicațiilor lor specifice.
