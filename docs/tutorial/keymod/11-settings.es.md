# 11. Configuración

Configura el comportamiento y la apariencia de KeyMod.

## Configuración general

| Configuración | Descripción |
|---|---|
| **Conexión automática** | Vuelva a conectarse al último dispositivo (USB o BLE) al iniciar |
| **Mantener la pantalla encendida** | Evite que la pantalla se duerma mientras usa la aplicación |
| **Retroalimentación háptica** | Vibración en button pulsaciones |
| **Bloqueo de orientación** | Orientación de la pantalla de bloqueo en vertical u horizontal |
| **Idioma** | Inglés, 中文, Español, Français, Deutsch, 日本語 |
| **Tema** | 8 familias de colores, Oscuro/Claro, Sistema de seguimiento |
| **BLE Retardo de tecla** | Retraso entre pulsaciones de teclas enviadas a través de BLE (ajustar si faltan caracteres) |
| **Touchpad sensibilidad** | Control deslizante de sensibilidad de desplazamiento |

## SO de destino

Configure el sistema operativo de destino para que coincida con las convenciones clave de la computadora de destino. Esto afecta las etiquetas de los accesos directos, los métodos de entrada Unicode y la asignación de teclas modificadoras.

| Objetivo | Mapeo de claves |
|--------|-------------|
| **Windows** | Alt, Ctrl, Win comportamiento clave |
| **Mac** | Cmd, Option comportamiento clave |
| **Linux** | Super, Meta comportamiento clave |

Cambie el sistema operativo de destino tocando el **icono del sistema operativo** en la barra de encabezado.

Consulte [Target-Specific Keyboard](03-target-keyboard.md) para conocer la distribución del teclado y los detalles de entrada Unicode.
