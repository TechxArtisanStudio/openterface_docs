# 4. ショートカットハブ

ワンタップで一般的なキーボードショートカットにアクセス。アプリ別に整理され、ラベルは **ターゲット OS** に自動適応（Windows/Linux は Ctrl+Z、macOS は Cmd+Z）。

## 組み込みプロファイル

| プロファイル | 内容 |
|---|---|
| **Default** | 一般的なショートカット（コピー、ペースト、元に戻す、保存など）— 削除不可 |
| **Blender 3D** | 変換、選択、ビュー、メッシュ、モード、シェーディング |
| **KiCAD** | PCB：レイヤー、描画、部品、プロパティ |
| **Nomad Sculpt** | スカルプトツール、ブラシ、変換、ビュー、マスク |
| **Fusion 360** | CAD：ナビ、スケッチ、モデリング、構築、アセンブリ |
| **Photoshop** | ツール、編集、ビュー |
| **VS Code** | ナビ、編集、コード、ビュー |

## ショートカットの使い方

1. **Shortcut Hub** を開く（Android ではサイドバーの「Shortcuts」モード）
2. プロファイルをタップして開く
3. **カテゴリタブ** を閲覧し、ショートカットカードをタップして実行
4. ラベルは **ターゲット OS** に自動適応

## プロファイルの作成と管理

| 操作 | 方法 |
|---|---|
| プロファイル作成 | **「Create Profile」** をタップし名前を入力 |
| ショートカット編集 | 長押し →「Edit」 |
| ショートカット削除 | 長押し →「Delete」 |
| お気に入り追加 | 長押し →「Add to My」 |
| プロファイル複製 | プロファイル長押し →「Duplicate」 |
| エクスポート | 長押し →「Export」— JSON 保存 |
| インポート | **「Import」** — JSON 貼り付けまたはファイル選択 |

各プロファイルには個人用 **My Shortcuts** セクションもあります。
