# 11. Ustawienia

Skonfiguruj zachowanie i wygląd KeyMod.

## Ustawienia ogólne

| Ustawienie | Opis |
|---|---|
| **Automatyczne połączenie** | Podłącz ponownie do ostatniego urządzenia (USB lub BLE) podczas uruchamiania |
| **Zachowaj włączony ekran** | Zapobiegaj zasypianiu ekranu podczas korzystania z aplikacji |
| **Opinia dotykowa** | Wibracje na button naciśnięciach |
| **Blokada orientacji** | Zablokuj orientację ekranu do pionowej lub poziomej |
| **Język** | Angielski, 中文, hiszpański, francuski, niemiecki, 日本語 |
| **Temat** | 8 rodzin kolorów, Ciemny/Jasny, System podążania |
| **BLE Opóźnienie klawisza** | Opóźnienie między naciśnięciami klawiszy wysyłanymi powyżej BLE (dostosuj, jeśli brakuje znaków) |
| **Touchpad czułość** | Przewiń suwak czułości |

## Docelowy system operacyjny

Ustaw docelowy system operacyjny tak, aby odpowiadał kluczowym konwencjom komputera docelowego. Ma to wpływ na etykiety skrótów, metody wprowadzania Unicode i mapowanie klawiszy modyfikujących.

| Cel | Mapowanie klawiszy |
|------------|------------|
| **Windows** | Alt, Ctrl, Win zachowanie klawiszy |
| **Mac** | Cmd, Option zachowanie klawiszy |
| **Linux** | Super, Meta zachowanie klawiszy |

Zmień docelowy system operacyjny, dotykając **ikony systemu operacyjnego** na pasku nagłówka.

Zobacz [Target-Specific Keyboard](03-target-keyboard.md), aby poznać układ klawiatury i szczegóły dotyczące wprowadzania znaków Unicode.
