# 8. Геймпад

Превратите свой телефон в виртуальный игровой контроллер для игр, ретро-эмуляции и тестирования игр.

## Макет

Геймпад представляет собой полноценную компоновку контроллера с крестовиной, кнопками действий, плечевыми кнопками, аналоговыми джойстиками и кнопками «Пуск/Выбор».

| Контроль | Как |
|---|---|
| Крестовина | Коснитесь стрелок направления |
| Кнопки действий (A, B, X, Y) | Нажмите их |
| Плечевые пуговицы | Нажмите L1, L2, R1, R2 вверху |
| Аналоговые джойстики | Нажмите и перетащите кружочки |
| Пуск/Выбрать | Нажмите кнопки |

## Система предустановок (v7)

В KeyMod 0.15 появилась **система геймпада на основе предустановок**. Вместо фиксированных встроенных макетов конфигурации геймпада теперь сохраняются в виде **предустановок**, которые можно переключать, импортировать и экспортировать.

### Управление пресетами

- **Нажмите значок «Предустановки»** на панели инструментов, чтобы просмотреть доступные макеты.
- **Длительное нажатие на чип предустановок** для просмотра полного списка предустановок с опциями импорта, добавления модуля и экспорта.
- Входящая в комплект раскладка **emu-6** поставляется как стартовая предустановка (`preset_default`)
- Пресеты представляют собой файлы JSON, которыми можно делиться с использованием макета **schema v7**.

### Добавление модулей

Из предустановленного меню вы можете добавлять новые модули в любой макет:

- **D-Pad/Stick** — добавляет модуль левого большого пальца (`stick_left`, `stick_left_2` и т. д.)
- **Touchpad** — добавляет touchpad (`touchpad_1`, `touchpad_2` и т. д.) со встроенными кнопками мыши L/M/R.
- **Кнопки** — добавьте кнопки на лице, на плечах или триггеры.

## Настройка

- **Настроить любой модуль** — коснитесь модуля, чтобы открыть диалоговое окно его настройки и настроить поведение.
- **Аналоговый режим или режим клавиатуры** — джойстики можно настроить как `STICK_KEY` (цифровые клавиши направления) или `STICK_MOUSE` (относительное движение указателя/мыши).
- **WASD сопоставление** — назначьте клавиши WASD левому джойстику для игр на ПК.
- **Button/масштабирование размера джойстика** — отрегулируйте размеры в соответствии с предпочитаемой вами сенсорной областью.
- **Фоновое изображение** — настройка фона геймпада (встраивается в общие настройки как base64, до 6 MiB)
- **Тактильная обратная связь** — вибрация при нажатии button (только кнопки на лице, без щелчков мышью)
- **Гироскоп** — включить гироскоп устройства для перемещения указателя хоста, когда экран геймпада активен.

### Модель модуля

Каждый экранный элемент управления представляет собой **модуль** с тремя слоями:

| Слой | Что это определяет |
|---|---|
| **Слот/идентификатор** | Какой элемент управления на холсте (например, `stick_left`, `stick_right`, `touchpad_1`) |
| **Поведение (тип)** | Что получает хост: `STICK_KEY`, `STICK_MOUSE`, `DPAD`, `BUTTON`, `TOUCHPAD` |
| **Параметры** | Тюнинг на одном модуле: `dpadVariant`, `stickMouseSensitivity`, `stickVisualVariant`, размер, цвет |

### Аналоговые джойстики

- **Левый джойстик → Клавиши клавиатуры:** Сопоставляется с клавишами со стрелками с диагональной поддержкой. Настраивается на WASD в конфигурации модуля.
- **Правый джойстик → Движение мыши:** Режим `STICK_MOUSE` с настраиваемой чувствительностью (`stickMouseSensitivity`), мертвая зона для предотвращения дрейфа.
- **Гистезис:** Пороги активации (0,6) и деактивации (0,4) предотвращают дребезжание клавиш на границе.

### Touchpad

- **Поддержка нескольких touchpad**: добавление нескольких сенсорных панелей в один макет (`touchpad_1`, `touchpad_2` и т. д.)
- **Квадратная площадь** по умолчанию при изменении размера при длительном нажатии.
- **Комплексные кнопки мыши** (Л/С/П), общие для всех сенсорных панелей.
- **Размер мыши button**: нажмите и удерживайте кнопку touchpad, чтобы отрегулировать **Размер мыши button**, или нажмите и удерживайте отдельную мышь button для **Этого размера button**

> **Примечание:** Протокол геймпада HID находится в стадии активной разработки. Базовые button вспомогательные работы; Точность аналогового джойстика может варьироваться.

## Устранение неполадок

### Аналоговый джойстик не отвечает

| Симптом | Решение |
|---|---|
| **Палка не производит действия** | Проверьте конфигурацию модуля. Убедитесь, что джойстик не застрял в мертвой зоне (центральной зоне). Проверьте пороги гистерезиса — для срабатывания джойстик должен пройти уровень активации 0,6. |
| **Кнопки отправляют неправильные ключи** | Откройте конфигурацию модуля и проверьте назначение клавиш button. Коснитесь button, чтобы открыть всплывающее окно конфигурации и исправить сопоставление. |
| **Touchpad кнопки мыши не щелкают** | Убедитесь, что в предустановке присутствуют кнопки L/M/R. При добавлении touchpad автоматически добавляются общие кнопки мыши. Проверьте конфигурацию модуля для назначенной клавиши HID. |
