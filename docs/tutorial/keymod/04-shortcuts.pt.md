# 4. Central de atalhos

Acesso com um toque a atalhos de teclado comuns, organizados por aplicativo. Os rótulos de atalho se adaptam automaticamente ao **SO de destino** (Ctrl+Z em Windows/Linux, Cmd+Z em macOS).

## Perfis integrados

| Perfil | O que cobre |
|---|---|
| **Padrão** | Atalhos comuns (Copiar, Colar, Desfazer, Salvar, etc.) — não podem ser excluídos |
| **Blender 3D** | Atalhos de transformação, seleção, visualização, malha, modo e sombreamento |
| **KiCAD** | Projeto de PCB: camadas, desenho, componentes, propriedades |
| **Nomad Sculpt** | Ferramentas de escultura, pincel, transformação, visualização, mascaramento |
| **Fusion 360** | CAD: navegação, esboço, modelagem, construção, montagem |
| **Photoshop** | Ferramentas, editar, visualizar atalhos |
| **VS Code** | Navegação, edição, código, atalhos de visualização |

## Usando atalhos

1. Abra o **Shortcut Hub** (ou modo "Atalhos" na barra lateral em Android)
2. Toque em qualquer perfil para abri-lo
3. Dentro de um perfil, navegue nas **guias de categoria** e toque em qualquer cartão de atalho para executá-lo
4. Os rótulos dos atalhos se adaptam automaticamente ao **SO de destino**

## Criando e gerenciando perfis

| Ação | Como |
|---|---|
| Crie um perfil | Toque em **"Criar perfil"**, digite um nome |
| Editar um atalho | Pressione longamente o atalho → "Editar" |
| Excluir um atalho | Pressione longamente o atalho → "Excluir" |
| Adicionar aos favoritos | Pressione longamente → "Adicionar ao meu" |
| Duplicar um perfil | Mantenha um perfil pressionado → "Duplicar" |
| Exportar um perfil | Pressionar longamente → "Exportar" — salva um arquivo JSON |
| Importar um perfil | Toque em **"Importar"** — cole JSON ou procure um arquivo |

Cada perfil também possui uma seção **Meus atalhos** para atalhos pessoais.
