# 7. Integración de IA

Entrada de voz mejorada por IA con refinamiento de texto y conversión de comandos en lenguaje natural.

> Las funciones de IA están **deshabilitadas de forma predeterminada**. Habilítelos en Configuración para acceder a estas funciones.

## Características

- **Refinamiento de texto**: corrige errores de transcripción y mejora la calidad del texto.
- **Asistente de comandos**: convierte voz en lenguaje natural en comandos de teclado

## Proveedores de IA

| Proveedor | Opciones |
|---|---|
| **Proveedor de IA** | OpenAI, Anthropic, Google Gemini, Mistral AI, Groq, Alibaba (Qwen), DeepSeek o Personalizado |
| **Punto final API** | Establecer la URL para el servicio de IA |
| **Modelo** | Elija el modelo de IA |
| **Clave API** | Establecer en Configuración> Configuración de AI |
| **Rol de la IA** | "Asistente de comando" (voz → acciones de teclado) o "Refinamiento de texto" (voz → texto mejorado) |

## Roles de aviso del sistema

- **Refinamiento de texto:** Corrige errores de voz a texto, mejora la gramática y la claridad.
- **Asistente de comandos:** Convierte el lenguaje natural en comandos de teclado. Mensajes específicos del sistema operativo para Windows, macOS y Linux.
- **Personalizado:** Aviso del sistema definido por el usuario para comportamiento especializado

## Contexto macro en IA

Cuando la IA está habilitada, las macros definidas se incluyen automáticamente en el mensaje del sistema, lo que permite que la IA las sugiera o las invoque por su nombre.

## Solución de problemas

### La clave API no funciona

| Síntoma | Solución |
|---|---|
| **"Clave API no configurada"** | Verifique que la clave API sea correcta; verifique si hay espacios adicionales o errores tipográficos. Verifique la URL base de la API; debe incluir la ruta completa (por ejemplo, `https://api.openai.com/v1`). Verifique que el nombre del modelo exista en el proveedor. Para proveedores locales (Ollama), asegúrese de que el indicador Clave API opcional esté configurado. |

### Refinamiento de texto lento

Verifique su conexión de red. Pruebe con un modelo más rápido: los modelos más pequeños (gpt-3.5-turbo, llama3-8b) responden más rápido. Utilice un proveedor local (Ollama) para eliminar la latencia de la red. Consulte el historial de solicitudes de IA para ver si hay mensajes de error.
