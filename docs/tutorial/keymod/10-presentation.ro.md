# 10. Prezentare

Controlați expunerea de diapozitive de pe telefon - nu este nevoie de clic.

## Controale

| Button | Are |
|---|---|
| **Următorul** | Avansează la următorul diapozitiv (Săgeata dreapta). Apăsare lungă = mergeți la ultimul diapozitiv |
| **Anterior** | Se întoarce cu un diapozitiv (Săgeata stânga). Apăsare lungă = mergeți la primul diapozitiv |
| **Play / Stop** | Pornește/oprește prezentarea |
| **B (Ecran alb)** | Comută ecranul negru |
| **Indicator** | Deschide o fereastră pop-out touchpad pentru controlul mouse-ului |
| **Commutător de aplicații** | Deschide comutatorul aplicației OS (Cmd+Tab / Alt+Tab) |

## Selector de instrumente de prezentare

Un carusel vă permite să selectați software-ul de prezentare (Keynote, PowerPoint, Google Slides, Word, Adobe Reader). Fiecare instrument are combinații unice de taste pentru redare/oprire.

## Cronometru pentru diapozitive

Cardul de cronometru acceptă modurile numărătoare inversă și numărătoare, cu o bară de umplere de progres, alertă de vibrație la momentul țintă și stare persistentă pe parcursul ciclului de viață al aplicației.

## Gesturi

- **Glisați spre stânga** → Următorul diapozitiv
- **Glisează spre dreapta** → Diapozitivul anterior
- **Atinge** → Următorul diapozitiv
