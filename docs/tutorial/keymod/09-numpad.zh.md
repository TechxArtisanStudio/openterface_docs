# 9. 数字键盘

完整数字键盘，用于数据录入。每个按键发送对应的 HID 小键盘键码。

## 按键映射

| 按键 | HID Usage Code |
|-----|---------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| Enter | 0x58 |
| . / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## 应用专用网格

部分快捷方式配置文件（Blender、Fusion 360、KiCad）包含针对各应用的 **自定义数字键盘网格**。
