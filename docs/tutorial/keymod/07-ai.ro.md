# 7. Integrarea AI

Intrare vocală îmbunătățită prin inteligență artificială, cu rafinare a textului și conversie a comenzilor în limbaj natural.

> Caracteristicile AI sunt **dezactivate în mod implicit**. Activați-le în Setări pentru a accesa aceste funcții.

## Caracteristici

- **Rafinarea textului** — Corectați erorile de transcriere și îmbunătățiți calitatea textului
- **Command Assistant** — Transformă vorbirea în limbaj natural în comenzi de la tastatură

## Furnizori AI

| Furnizor | Opțiuni |
|---|---|
| **Furnizor AI** | OpenAI, Anthropic, Google Gemini, Mistral AI, Groq, Alibaba (Qwen), DeepSeek sau Personalizat |
| **Punctul final API** | Setați adresa URL pentru serviciul AI |
| **Model** | Alegeți modelul AI |
| **Cheie API** | Setați în Setări > Setări AI |
| **Rolul AI** | „Asistent de comandă” (voce → acțiuni de la tastatură) sau „Rafinare text” (voce → text îmbunătățit) |

## Roluri de prompt de sistem

- **Rafinarea textului:** Corectează erorile din vorbire în text, îmbunătățește gramatica și claritatea
- **Asistent de comandă:** Convertește limbajul natural în comenzi de la tastatură. Solicitări specifice sistemului de operare pentru Windows, macOS și Linux.
- **Personalizat:** Solicitare de sistem definită de utilizator pentru comportament specializat

## Context macro în AI

Când AI este activat, macrocomenzile definite sunt incluse automat în promptul de sistem, permițând AI să le sugereze sau să le invoce după nume.

## Depanare

### Cheia API nu funcționează

| Simptom | Soluție |
|---|---|
| **„Cheia API nu este configurată”** | Verificați cheia API este corectă - verificați dacă există spații suplimentare sau greșeli de scriere. Verificați adresa URL de bază API - trebuie să includă calea completă (de exemplu, `https://api.openai.com/v1`). Verificați că numele modelului există la furnizor. Pentru furnizorii locali (Ollama), asigurați-vă că este setat indicatorul API Key Optional. |

### Rafinarea textului Lentă

Verificați conexiunea la rețea. Încercați un model mai rapid — modelele mai mici (gpt-3.5-turbo, llama3-8b) răspund mai repede. Utilizați un furnizor local (Ollama) pentru a elimina latența rețelei. Verificați istoricul solicitărilor AI pentru mesaje de eroare.
