# 9. Klawiatura numeryczna

Pełna klawiatura numeryczna do wprowadzania danych. Każdy klawisz wysyła odpowiedni kod klawisza numerycznego HID.

## Mapowanie klawiszy

| Klucz | HID Kod użycia |
|---------|--------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| Wpisz | 0x58 |
| . / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## Siatki specyficzne dla aplikacji

Niektóre profile skrótów (Blender, Fusion 360, KiCad) zawierają **niestandardowe siatki klawiatury numerycznej** dostosowane do ich konkretnych zastosowań.
