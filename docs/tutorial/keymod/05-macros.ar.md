# 5. وحدات الماكرو

قم بتسجيل وإعادة تشغيل تسلسلات المفاتيح الآلية بنقرة واحدة.

## ما هو الماكرو؟

الماكرو هو **تسلسل مسجل من ضغطات المفاتيح** التي يمكنك إعادة تشغيلها. على سبيل المثال:
- اكتب توقيع البريد الإلكتروني الخاص بك بنقرة واحدة
- أرسل `Ctrl+Shift+Esc` متبوعًا بـ `Alt+D` بالتسلسل
- أتمتة تسلسل أوامر متعدد الخطوات مع تأخير بين الخطوات

## بناء جملة رمز الماكرو

| الرمز المميز | معنى |
|---|---|
| `<CTRL>` ... `</CTRL>` | عقد / تحرير التحكم |
| `<SHIFT>` ... `</SHIFT>` | اضغط مع الاستمرار/حرر Shift |
| `<ALT>` ... `</ALT>` | تعليق/تحرير Alt/Option |
| `<CMD>` ... `</CMD>` | اضغط على الأمر/حرره/Win/Super |
| `<ESC>`, `<BACK>`, `<ENTER>`, `<SPACE>` | مفاتيح خاصة |
| `<LEFT>`, `<RIGHT>`, `<UP>`, `<DOWN>` | مفاتيح الأسهم |
| `<HOME>`, `<END>`, `<TAB>`, `<DEL>` | مفاتيح التنقل |
| `<F1>` إلى `<F12>` | مفاتيح الوظائف |
| `<DELAY1S>`, `<DELAY2S>`, `<DELAY5S>`, `<DELAY10S>` | وقفات |

**مثال:**```
<CTRL><ALT>t</ALT></CTRL><DELAY1S>ls -la<ENTER>
يؤدي هذا إلى فتح الوحدة الطرفية (Ctrl+Alt+T)، وينتظر ثانية واحدة، ثم يكتب `ls -la` ويضغط على Enter.

## إنشاء ماكرو

1. انتقل إلى وضع **وحدات الماكرو**
2. اضغط على **"+"** لإنشاء ماكرو جديد
3. أدخل **اسم/تسمية الماكرو**
4. أنشئ تسلسل أوامر الماكرو باستخدام حقل النص ورقائق الرمز المميز للإدراج السريع
5. اضبط **Send Char Interval** (التأخير بين ضغطات المفاتيح بالمللي ثانية)
6. اضغط على **"حفظ"**
