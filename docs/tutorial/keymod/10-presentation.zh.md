# 10. 演示

用手机控制幻灯片——无需翻页笔。

## 控制

| 按钮 | 功能 |
|---|---|
| **Next** | 下一张幻灯片（右箭头）。长按 = 跳到最后一张 |
| **Previous** | 上一张（左箭头）。长按 = 跳到第一张 |
| **Play / Stop** | 开始/停止演示 |
| **B (Blank Screen)** | 切换黑屏 |
| **Pointer** | 打开弹出触控板进行鼠标控制 |
| **App Switcher** | 打开系统应用切换器（Cmd+Tab / Alt+Tab） |

## 演示工具选择器

轮播可选择演示软件（Keynote、PowerPoint、Google Slides、Word、Adobe Reader）。各工具有独特的播放/停止按键组合。

## 幻灯片计时器

计时器卡片支持倒计时与正计时，带进度填充条、到达目标时间振动提醒，并在应用生命周期内保持状态。

## 手势

- **左滑** → 下一张
- **右滑** → 上一张
- **点击** → 下一张
