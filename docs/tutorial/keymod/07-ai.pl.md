# 7. Integracja AI

Wprowadzanie głosowe wspomagane sztuczną inteligencją z udoskonalaniem tekstu i konwersją poleceń na język naturalny.

> Funkcje AI są **domyślnie wyłączone**. Włącz je w Ustawieniach, aby uzyskać dostęp do tych funkcji.

## Funkcje

- **Udoskonalenie tekstu** — Poprawia błędy w transkrypcji i poprawia jakość tekstu
- **Asystent poleceń** — Konwertuj mowę w języku naturalnym na polecenia klawiaturowe

## Dostawcy sztucznej inteligencji

| Dostawca | Opcje |
|---|---|
| **Dostawca sztucznej inteligencji** | OpenAI, Anthropic, Google Gemini, Mistral AI, Groq, Alibaba (Qwen), DeepSeek lub Niestandardowe |
| **Punkt końcowy API** | Ustaw adres URL usługi AI |
| **Modelka** | Wybierz model AI |
| **Klucz API** | Ustaw w Ustawieniach > Ustawienia AI |
| **Rola sztucznej inteligencji** | „Asystent poleceń” (głos → akcje klawiaturowe) lub „Udoskonalanie tekstu” (głos → poprawiony tekst) |

## Role podpowiedzi systemowych

- **Udoskonalanie tekstu:** koryguje błędy zamiany mowy na tekst, poprawia gramatykę i przejrzystość
- **Asystent poleceń:** Konwertuje język naturalny na polecenia klawiaturowe. Monity specyficzne dla systemu operacyjnego dla Windows, macOS i Linux.
- **Niestandardowy:** Zdefiniowany przez użytkownika monit systemowy dotyczący wyspecjalizowanego zachowania

## Kontekst makro w AI

Gdy włączona jest sztuczna inteligencja, zdefiniowane przez Ciebie makra są automatycznie uwzględniane w wierszu poleceń, umożliwiając sztucznej inteligencji sugerowanie lub wywoływanie ich po nazwie.

## Rozwiązywanie problemów

### Klucz API nie działa

| Objaw | Rozwiązanie |
|---|---|
| **„Klucz API nie jest skonfigurowany”** | Sprawdź, czy klucz API jest poprawny — sprawdź, czy nie ma dodatkowych spacji lub literówek. Sprawdź podstawowy adres URL interfejsu API — musi zawierać pełną ścieżkę (np. `https://api.openai.com/v1`). Sprawdź, czy nazwa modelu istnieje u dostawcy. W przypadku dostawców lokalnych (Ollama) upewnij się, że ustawiona jest flaga Opcjonalny klucz API. |

### Powolne udoskonalanie tekstu

Sprawdź połączenie sieciowe. Wypróbuj szybszy model — mniejsze modele (gpt-3.5-turbo, llama3-8b) reagują szybciej. Skorzystaj z lokalnego dostawcy (Ollama), aby wyeliminować opóźnienia sieci. Sprawdź historię żądań AI pod kątem komunikatów o błędach.
