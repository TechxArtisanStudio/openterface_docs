# 10. Presentación

Controle su presentación de diapositivas desde su teléfono, sin necesidad de hacer clic.

## Controles

| Button | Hace |
|---|---|
| **Siguiente** | Avanza a la siguiente diapositiva (flecha derecha). Pulsación larga = ir a la última diapositiva |
| **Anterior** | Retrocede una diapositiva (flecha izquierda). Pulsación larga = ir a la primera diapositiva |
| **Reproducir / Detener** | Inicia/detiene la presentación |
| **B (Pantalla en blanco)** | Alterna la pantalla negra |
| **Puntero** | Abre una ventana emergente touchpad para controlar el mouse |
| **Conmutador de aplicaciones** | Abre el selector de aplicaciones del sistema operativo (Cmd+Tab / Alt+Tab) |

## Selector de herramientas de presentación

Un carrusel le permite seleccionar su software de presentación (Keynote, PowerPoint, Google Diapositivas, Word, Adobe Reader). Cada herramienta tiene combinaciones de teclas únicas para reproducir/detener.

## Temporizador de diapositivas

La tarjeta del temporizador admite modos de cuenta atrás y cuenta atrás, con una barra de progreso, alerta de vibración en el momento objetivo y estado persistente durante todo el ciclo de vida de la aplicación.

## Gestos

- **Desliza hacia la izquierda** → Siguiente diapositiva
- **Desliza hacia la derecha** → Diapositiva anterior
- **Toca** → Siguiente diapositiva
