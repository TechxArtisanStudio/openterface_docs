# 7. AI 통합

텍스트 개선 및 자연어 명령 변환을 통해 AI로 강화된 음성 입력.

> AI 기능은 **기본적으로 비활성화되어 있습니다**. 이러한 기능에 액세스하려면 설정에서 활성화하세요.

## 기능

- **텍스트 개선** — 전사 오류를 수정하고 텍스트 품질을 향상시킵니다.
- **명령 보조자** — 자연어 음성을 키보드 명령으로 변환합니다.

## AI 제공업체

| 공급자 | 옵션 |
|---|---|
| **AI 제공업체** | OpenAI, Anthropic, Google Gemini, Mistral AI, Groq, Alibaba(Qwen), DeepSeek 또는 Custom |
| **API 엔드포인트** | AI 서비스의 URL 설정 |
| **모델** | AI 모델 선택 |
| **API 키** | 설정 > AI 설정 |
| **AI 역할** | "명령어 지원"(음성 → 키보드 동작) 또는 "텍스트 구체화"(음성 → 향상된 텍스트) |

## 시스템 프롬프트 역할

- **텍스트 개선:** 음성-텍스트 오류를 수정하고 문법과 명확성을 향상시킵니다.
- **명령 보조자:** 자연어를 키보드 명령으로 변환합니다. Windows, macOS 및 Linux에 대한 OS별 프롬프트.
- **사용자 정의:** 특수 동작을 위한 사용자 정의 시스템 프롬프트

## AI의 매크로 컨텍스트

AI가 활성화되면 정의된 매크로가 시스템 프롬프트에 자동으로 포함되어 AI가 이름으로 매크로를 제안하거나 호출할 수 있습니다.

## 문제 해결

### API 키가 작동하지 않음

| 증상 | 솔루션 |
|---|---|
| **"API 키가 구성되지 않음"** | API 키가 올바른지 확인하세요. 추가 공백이나 오타가 있는지 확인하세요. API 기본 URL을 확인하세요. 전체 경로(예: `https://api.openai.com/v1`)를 포함해야 합니다. 공급자에 모델 이름이 있는지 확인하십시오. 로컬 공급자(Ollama)의 경우 API 키 옵션 플래그가 설정되어 있는지 확인하세요. |

### 텍스트 개선 속도가 느림

네트워크 연결을 확인하세요. 더 빠른 모델을 사용해 보십시오. 더 작은 모델(gpt-3.5-turbo, llama3-8b)이 더 빠르게 반응합니다. 네트워크 지연 시간을 없애려면 현지 공급자(Ollama)를 이용하세요. 오류 메시지는 AI 요청 기록을 확인하세요.
