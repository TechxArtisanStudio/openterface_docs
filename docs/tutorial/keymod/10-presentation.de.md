# 10. Präsentation

Steuern Sie Ihre Diashow von Ihrem Telefon aus – kein Clicker erforderlich.

## Steuerelemente

| Button | Tut |
|---|---|
| **Weiter** | Geht zur nächsten Folie (Rechtspfeil). Lang drücken = zur letzten Folie gehen |
| **Vorherige** | Geht eine Folie zurück (Pfeil nach links). Lang drücken = zur ersten Folie gehen |
| **Wiedergabe / Stopp** | Startet/stoppt die Präsentation |
| **B (leerer Bildschirm)** | Schaltet den schwarzen Bildschirm um |
| **Zeiger** | Öffnet ein Pop-Out touchpad zur Maussteuerung |
| **App-Umschalter** | Öffnet den OS-App-Umschalter (Cmd+Tab / Alt+Tab) |

## Präsentationstool-Auswahl

Über ein Karussell können Sie Ihre Präsentationssoftware (Keynote, PowerPoint, Google Slides, Word, Adobe Reader) auswählen. Jedes Werkzeug verfügt über einzigartige Tastenkombinationen für Wiedergabe/Stopp.

## Slide-Timer

Die Timer-Karte unterstützt Countdown- und Countup-Modi mit einem Fortschrittsbalken, einem Vibrationsalarm zur Zielzeit und einem dauerhaften Status über den gesamten App-Lebenszyklus.

## Gesten

- **Nach links wischen** → Nächste Folie
- **Nach rechts wischen** → Vorherige Folie
- **Tippen** → Nächste Folie
