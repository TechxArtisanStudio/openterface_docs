# 12. 문제 해결

Android의 KeyCmd 앱에 대한 일반적인 문제 및 해결 방법.

## 연결 문제

### 연결되지 않음

| 증상 | 솔루션 |
|---|---|
| **"연결되지 않음"** 표시 | 케이블 연결을 확인하십시오. 다시 연결해 보세요. BLE의 경우 Bluetooth를 끄거나 켜고 다시 페어링하세요. |
| **USB 권한이 거부됨** | Android 설정 → 앱 → KeyMod → 권한 → USB 활성화로 이동합니다. 케이블을 다시 연결하십시오. |
| **블루투스가 페어링되지 않습니다** | Bluetooth를 끄거나 켭니다. Bluetooth 설정에서 장치를 삭제하고 다시 페어링하세요. KeyMod 장치가 페어링 모드에 있는지 확인하세요. |
| **연결이 자주 끊김** | 앱에서 BLE button 아래의 RSSI 값을 확인하세요. -75dBm 미만은 신호가 약함을 나타냅니다. 더 가까이 이동하세요. 물리적 장애물을 제거하십시오. |

### 연결 상태 표시기

| 지표 | 의미 |
|---|---|
| **연결됨** | 녹색 아이콘 — 입력을 보낼 준비가 되었습니다 |
| **연결 중** | 황색 아이콘 - 연결 진행 중 |
| **연결 끊김** | 회색 아이콘 - 활성 연결 없음 |
| **신호바** | BLE 신호 강도 또는 USB 활성 상태 |

### 자동 연결

연결 대화 상자에서 **"시작 시 자동 연결"**을 활성화합니다. KeyMod은 마지막 연결 유형(USB 또는 BLE)과 마지막으로 페어링된 BLE 장치를 기억합니다.

### USB 부착/탈착 감지

KeyMod는 Android의 USB 방송 이벤트 연결/분리를 모니터링합니다. USB 케이블을 분리하면 연결 상태가 즉시 업데이트됩니다. 자동 연결이 활성화된 경우 다시 연결하면 다시 연결 시도가 트리거됩니다.

## 키보드 문제

### 키가 등록되지 않음

| 증상 | 솔루션 |
|---|---|
| **키가 전송되지 않음** | 연결에 "연결됨"(녹색)이 표시되는지 확인합니다. 모드를 전환했다가 다시 시도해 보세요. 대상 컴퓨터가 KeyMod 장치를 키보드로 인식하는지 확인하십시오. |
| **매크로가 실행되지 않습니다** | 연결되었는지 확인하세요. 매크로 데이터에 유효한 토큰이 포함되어 있는지 확인하세요(토큰 이름에 오타가 없는지). |
| **잘못된 문자가 나타남** | **대상 OS** 설정을 확인하세요. OS가 일치하지 않으면 키 매핑 문제가 발생할 수 있습니다. 대상 컴퓨터의 키보드 레이아웃(QWERTY 대 AZERTY)을 확인하십시오. |

### 유니코드 문자가 작동하지 않음

ASCII가 아닌 문자(중국어, 일본어, 이모티콘)에는 OS별 입력 방법이 필요합니다.

| OS | 방법 |
|---|---|
| **Windows** | Alt+NumPad 16진수 유니코드 입력 |
| **Linux** | Ctrl+Shift+U 뒤에 16진수 코드 |
| **macOS** | Option+16진수 입력 |

유니코드 문자가 잘못 나타나는 경우 **대상 OS**가 올바르게 설정되었는지 확인하세요.

## TouchPad 문제

| 증상 | 솔루션 |
|---|---|
| **Touchpad 응답하지 않음** | 설정에서 햅틱 피드백이 활성화되어 있는지 확인하세요. TouchPad 도움말 오버레이(?)를 사용해 제스처 지원을 확인하세요. |
| **스크롤이 작동하지 않음** | 설정 → 일반에서 touchpad 스크롤 감도를 확인하세요. |

## 음성 입력 문제

### 음성 인식기를 사용할 수 없음

Play 스토어에서 Google 음성 입력을 설치하세요. Android 11+에서 KeyMod에는 쿼리 권한이 필요합니다(APK에 포함됨).

### 침묵 감지가 작동하지 않음

| 증상 | 솔루션 |
|---|---|
| **말하지 않아도 녹음은 계속됩니다** | 침묵 시 자동 일시 중지 토글을 확인하세요. 배경 소음을 줄입니다. 마이크 가까이에서 명확하게 말하세요. |
| **녹음이 즉시 중지됩니다** | 더 큰 소리로 말하거나 침묵 감지 시간 제한을 줄이세요. |

### 음성문자가 전송되지 않습니다

연결 상태를 확인하세요. 연결되지 않으면 "보내기" button가 비활성화됩니다.

## AI 문제

### API 키가 작동하지 않음

| 증상 | 솔루션 |
|---|---|
| **"API 키가 구성되지 않음"** | API 키가 올바른지 확인하세요. 추가 공백이나 오타가 있는지 확인하세요. API 기본 URL을 확인하세요. 전체 경로(예: `https://api.openai.com/v1`)를 포함해야 합니다. 공급자에 모델 이름이 있는지 확인하십시오. 로컬 공급자(Ollama)의 경우 API 키 옵션 플래그가 설정되어 있는지 확인하세요. |

### 텍스트 개선 속도가 느림

네트워크 연결을 확인하세요. 더 빠른 모델을 사용해 보세요. 더 작은 모델(gpt-3.5-turbo, llama3-8b)이 더 빠르게 반응합니다. 네트워크 지연 시간을 없애려면 현지 공급자(Ollama)를 이용하세요. 오류 메시지는 AI 요청 기록을 확인하세요.
