# 7. Integração de IA

Entrada de voz aprimorada por IA com refinamento de texto e conversão de comandos em linguagem natural.

> Os recursos de IA estão **desativados por padrão**. Ative-os em Configurações para acessar esses recursos.

## Recursos

- **Refinamento de texto** — Corrija erros de transcrição e melhore a qualidade do texto
- **Command Assistant** — Converta fala em linguagem natural em comandos de teclado

## Provedores de IA

| Provedor | Opções |
|---|---|
| **Provedor de IA** | OpenAI, Anthropic, Google Gemini, Mistral AI, Groq, Alibaba (Qwen), DeepSeek ou Personalizado |
| **Endpoint da API** | Defina o URL do serviço de IA |
| **Modelo** | Escolha o modelo de IA |
| **Chave de API** | Defina em Configurações > Configurações de IA |
| **Função de IA** | "Assistente de Comando" (voz → ações do teclado) ou "Refinamento de Texto" (voz → texto aprimorado) |

## Funções de prompt do sistema

- **Refinamento de texto:** corrige erros de fala para texto, melhora a gramática e a clareza
- **Assistente de Comando:** Converte linguagem natural em comandos de teclado. Solicitações específicas do sistema operacional para Windows, macOS e Linux.
- **Personalizado:** Solicitação do sistema definida pelo usuário para comportamento especializado

## Macro Contexto em IA

Quando a IA está habilitada, suas macros definidas são incluídas automaticamente no prompt do sistema, permitindo que a IA as sugira ou invoque pelo nome.

## Solução de problemas

### Chave de API não funciona

| Sintoma | Solução |
|---|---|
| **"Chave API não configurada"** | Verifique se a chave da API está correta – verifique se há espaços extras ou erros de digitação. Verifique o URL base da API — deve incluir o caminho completo (por exemplo, `https://api.openai.com/v1`). Verifique se o nome do modelo existe no provedor. Para provedores locais (Ollama), certifique-se de que o sinalizador API KeyOptional esteja definido. |

### Refinamento de texto lento

Verifique sua conexão de rede. Experimente um modelo mais rápido — modelos menores (gpt-3.5-turbo, llama3-8b) respondem mais rápido. Use um provedor local (Ollama) para eliminar a latência da rede. Verifique o histórico de solicitações de IA em busca de mensagens de erro.
