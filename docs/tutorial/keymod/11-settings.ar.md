# 11. الإعدادات

قم بتكوين سلوك ومظهر KeyMod.

## الإعدادات العامة

| الإعداد | الوصف |
|---|---|
| **الاتصال التلقائي** | أعد الاتصال بالجهاز الأخير (USB أو BLE) عند بدء التشغيل |
| ** حافظ على الشاشة ** | منع سكون الشاشة أثناء استخدام التطبيق |
| ** ردود الفعل اللمسية ** | الاهتزاز عند الضغط على button |
| **قفل الاتجاه** | اتجاه شاشة القفل إلى الوضع الرأسي أو الأفقي |
| **اللغة** | الإنجليزية، 中文، الأسبانية، الفرنسية، الألمانية، 日本語 |
| ** الموضوع ** | 8 مجموعات ألوان، داكن/فاتح، نظام المتابعة |
| **BLE تأخير المفتاح** | التأخير بين ضغطات المفاتيح المرسلة عبر BLE (يتم ضبطه في حالة فقدان الأحرف) |
| **Touchpad حساسية** | تمرير شريط تمرير الحساسية |

## نظام التشغيل المستهدف

قم بتعيين نظام التشغيل الهدف ليتوافق مع الاصطلاحات الرئيسية للكمبيوتر الهدف. يؤثر هذا على تسميات الاختصارات وطرق إدخال Unicode وتعيين مفتاح التعديل.

| الهدف | رسم الخرائط الرئيسية |
|--------|------------|
| **Windows** | Alt، Ctrl، Win السلوك الرئيسي |
| **ماك** | Cmd، Option السلوك الرئيسي |
| **Linux** | Super، Meta السلوك الرئيسي |

قم بتغيير نظام التشغيل المستهدف من خلال النقر على **رمز نظام التشغيل** في شريط الرأس.

راجع [Target-Specific Keyboard](03-target-keyboard.md) للتعرف على تخطيط لوحة المفاتيح وتفاصيل إدخال Unicode.
