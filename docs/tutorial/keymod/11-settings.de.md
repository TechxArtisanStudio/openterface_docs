# 11. Einstellungen

Konfigurieren Sie das Verhalten und Erscheinungsbild von KeyMod.

## Allgemeine Einstellungen

| Einstellung | Beschreibung |
|---|---|
| **Automatisch verbinden** | Beim Start erneut mit dem letzten Gerät (USB oder BLE) verbinden |
| **Bildschirm eingeschaltet lassen** | Bildschirmschlaf während der Nutzung der App verhindern |
| **Haptisches Feedback** | Vibration ein button drückt |
| **Ausrichtungssperre** | Bildschirmausrichtung auf Hoch- oder Querformat sperren |
| **Sprache** | Englisch, 中文, Español, Français, Deutsch, 日本語 |
| **Thema** | 8 Farbfamilien, Dunkel/Hell, Follow-System |
| **BLE Tastenverzögerung** | Verzögerung zwischen gesendeten Tastenanschlägen über BLE (passen Sie an, wenn Zeichen fehlen) |
| **Touchpad Empfindlichkeit** | Schieberegler für Scroll-Empfindlichkeit |

## Zielbetriebssystem

Stellen Sie das Zielbetriebssystem so ein, dass es den wichtigsten Konventionen des Zielcomputers entspricht. Dies betrifft Verknüpfungsbezeichnungen, Unicode-Eingabemethoden und die Zuordnung von Zusatztasten.

| Ziel | Tastenzuordnung |
|--------|-------------|
| **Windows** | Alt, Ctrl, Win Tastenverhalten |
| **Mac** | Cmd, Option Tastenverhalten |
| **Linux** | Super, Meta Tastenverhalten |

Ändern Sie das Zielbetriebssystem, indem Sie in der Kopfleiste auf das **Betriebssystemsymbol** tippen.

Weitere Informationen zum Tastaturlayout und zur Unicode-Eingabe finden Sie in [Target-Specific Keyboard](03-target-keyboard.md).
