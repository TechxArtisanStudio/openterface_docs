# 11. Настройки

Настройте поведение и внешний вид KeyMod.

## Общие настройки

| Настройка | Описание |
|---|---|
| **Автоподключение** | Повторно подключиться к последнему устройству (USB или BLE) при запуске |
| **Не отключать экран** | Запретить спящий режим экрана во время использования приложения |
| **Тактильная обратная связь** | Вибрация на button прессах |
| **Блокировка ориентации** | Заблокировать ориентацию экрана: портретную или альбомную |
| **Язык** | Английский, 中文, испанский, французский, немецкий, 日本語 |
| **Тема** | 8 цветовых семейств, Темный/Светлый, Следующая система |
| **BLE Задержка клавиш** | Задержка между нажатиями клавиш, отправляемых через BLE (отрегулируйте, если символы пропущены) |
| **Touchpad чувствительность** | Ползунок чувствительности прокрутки |

## Целевая ОС

Установите целевую ОС в соответствии с основными соглашениями целевого компьютера. Это влияет на ярлыки ярлыков, методы ввода в Юникоде и сопоставление клавиш-модификаторов.

| Цель | Сопоставление клавиш |
|--------|-------------|
| **Windows** | Поведение клавиш Alt, Ctrl, Win |
| **Мак** | Поведение клавиш Cmd, Option |
| **Linux** | Поведение клавиш Super, Meta |

Измените целевую ОС, коснувшись **значка ОС** в строке заголовка.

См. [Target-Specific Keyboard](03-target-keyboard.md) для получения информации о раскладке клавиатуры и вводе данных в Юникоде.
