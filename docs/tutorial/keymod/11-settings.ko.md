# 11. 설정

KeyMod의 동작과 모양을 구성합니다.

## 일반 설정

| 설정 | 설명 |
|---|---|
| **자동 연결** | 시작 시 마지막 장치(USB 또는 BLE)에 다시 연결 |
| **화면을 켜두세요** | 앱 사용 중 화면 절전 방지 |
| **햅틱 피드백** | button 프레스의 진동 |
| **방향 잠금** | 화면 방향을 세로 또는 가로로 고정 |
| **언어** | 영어, 中文, Español, Français, Deutsch, 日本語 |
| **테마** | 8가지 색상군, Dark/Light, Follow 시스템 |
| **BLE 키 지연** | BLE를 통해 전송된 키 입력 사이의 지연(문자가 누락된 경우 조정) |
| **Touchpad 감도** | 스크롤 감도 슬라이더 |

## 대상 OS

대상 컴퓨터의 주요 규칙과 일치하도록 대상 OS를 설정합니다. 이는 단축키 레이블, 유니코드 입력 방법 및 수정자 키 매핑에 영향을 미칩니다.

| 대상 | 키 매핑 |
|---------|-------------|
| **Windows** | Alt, Ctrl, Win 키 동작 |
| **맥** | Cmd, Option 주요 동작 |
| **Linux** | Super, Meta 주요 동작 |

헤더 표시줄에서 **OS 아이콘**을 탭하여 대상 OS를 변경하세요.

키보드 레이아웃 및 유니코드 입력에 대한 자세한 내용은 [Target-Specific Keyboard](03-target-keyboard.md)을 참조하세요.
