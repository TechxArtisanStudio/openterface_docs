# 11. 設置

配置 KeyMod 的行為與外觀。

## 常規設置

| 設置 | 說明 |
|---|---|
| **Auto-connect** | 啟動時重連上次設備（USB 或 BLE） |
| **Keep screen on** | 使用應用時防止屏幕休眠 |
| **Haptic feedback** | 按鍵時振動 |
| **Orientation lock** | 將屏幕方向鎖定為豎屏或橫屏 |
| **Language** | English、中文、Español、Français、Deutsch、日本語 |
| **Theme** | 8 種色系、深色/淺色、跟隨系統 |
| **BLE Key Delay** | BLE 發送按鍵間的延遲（若漏字可調整） |
| **Touchpad sensitivity** | 滾動靈敏度滑塊 |

## 目標系統

設置目標系統以匹配目標電腦的按鍵習慣。影響快捷方式標籤、Unicode 輸入方式與修飾鍵映射。

| 目標 | 按鍵映射 |
|--------|-------------|
| **Windows** | Alt、Ctrl、Win 鍵行為 |
| **Mac** | Cmd、Option 鍵行為 |
| **Linux** | Super、Meta 鍵行為 |

點擊標題欄 **系統圖標** 可更改目標系統。

鍵盤佈局與 Unicode 輸入詳情見 [目標系統](03-target-keyboard.md)。
