# 4. مركز الاختصار

الوصول بنقرة واحدة إلى اختصارات لوحة المفاتيح الشائعة، والتي يتم تنظيمها حسب التطبيق. تتكيف تسميات الاختصارات تلقائيًا مع **نظام التشغيل المستهدف** (Ctrl+Z على Windows/Linux، Cmd+Z على macOS).

## ملفات التعريف المضمنة

| الملف الشخصي | ما يغطيه |
|---|---|
| **الافتراضي** | الاختصارات الشائعة (نسخ، لصق، تراجع، حفظ، إلخ.) — لا يمكن حذفها |
| **Blender ثلاثي الأبعاد** | اختصارات التحويل والتحديد والعرض والشبكة والوضع والتظليل |
| **KiCAD** | تصميم ثنائي الفينيل متعدد الكلور: الطبقات، الرسم، المكونات، الخصائص |
| **Nomad Sculpt** | أدوات النحت، الفرشاة، التحويل، العرض، الإخفاء |
| **Fusion 360** | CAD: التنقل، الرسم، النمذجة، البناء، التجميع |
| **Photoshop** | أدوات، تحرير، عرض الاختصارات |
| **VS Code** | التنقل، التحرير، التعليمات البرمجية، عرض الاختصارات |

## استخدام الاختصارات

1. افتح **Shortcut Hub** (أو وضع "الاختصارات" من الشريط الجانبي على Android)
2. اضغط على أي ملف تعريف لفتحه
3. داخل الملف الشخصي، تصفح **علامات تبويب الفئات** ثم انقر فوق أي بطاقة اختصار لتنفيذها
4. تتكيف تسميات الاختصارات تلقائيًا مع **نظام التشغيل المستهدف**

## إنشاء وإدارة الملفات الشخصية

| العمل | كيف |
|---|---|
| إنشاء ملف تعريف | اضغط على **"إنشاء ملف تعريف"**، وأدخل اسمًا |
| تحرير الاختصار | اضغط لفترة طويلة على الاختصار → "تحرير" |
| حذف اختصار | اضغط لفترة طويلة على الاختصار → "حذف" |
| أضف إلى المفضلة | اضغط لفترة طويلة → "أضف إلى" |
| تكرار ملف تعريف | اضغط لفترة طويلة على الملف الشخصي ← "نسخة مكررة" |
| تصدير ملف تعريف | الضغط مطولاً على → "تصدير" — يحفظ ملف JSON |
| استيراد ملف تعريف | اضغط **"استيراد"** — الصق JSON أو استعرض بحثًا عن ملف |

يحتوي كل ملف شخصي أيضًا على قسم **اختصاراتي** للاختصارات الشخصية.
