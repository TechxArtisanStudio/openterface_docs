# 5. 매크로

한 번의 탭으로 자동화된 키 시퀀스를 기록하고 재생할 수 있습니다.

## 매크로란 무엇인가요?

매크로는 재생할 수 있는 **기록된 키 입력 순서**입니다. 예를 들면:
- 탭 한 번으로 이메일 서명을 입력하세요
- `Ctrl+Shift+Esc` 다음에 `Alt+D`을 차례로 전송합니다.
- 단계 간 지연을 통해 다단계 명령 시퀀스를 자동화합니다.

## 매크로 토큰 구문

| 토큰 | 의미 |
|---|---|
| `<CTRL>` ... `</CTRL>` | 보류/해제 제어 |
| `<SHIFT>` ... `</SHIFT>` | 보류/해제 Shift |
| `<ALT>` ... `</ALT>` | 유지/해제 Alt/Option |
| `<CMD>` ... `</CMD>` | 보류/해제 명령/Win/Super |
| `<ESC>`, `<BACK>`, `<ENTER>`, `<SPACE>` | 특수 키 |
| `<LEFT>`, `<RIGHT>`, `<UP>`, `<DOWN>` | 화살표 키 |
| `<HOME>`, `<END>`, `<TAB>`, `<DEL>` | 탐색 키 |
| `<F1>`부터 `<F12>`까지 | 기능 키 |
| `<DELAY1S>`, `<DELAY2S>`, `<DELAY5S>`, `<DELAY10S>` | 일시중지 |

**예:**```
<CTRL><ALT>t</ALT></CTRL><DELAY1S>ls -la<ENTER>
그러면 터미널(Ctrl+Alt+T)이 열리고 1초 동안 기다린 후 `ls -la`를 입력하고 Enter를 누릅니다.

## 매크로 만들기

1. **매크로** 모드로 이동
2. **"+"**를 탭하여 새 매크로를 만듭니다.
3. **매크로 이름/라벨**을 입력하세요.
4. 텍스트 필드와 빠른 삽입 토큰 칩을 사용하여 매크로 명령 시퀀스를 구축합니다.
5. **문자 전송 간격**(키 입력 간 지연 시간(밀리초))을 조정합니다.
6. **"저장"**을 탭하세요.
