# 4. Centro de accesos directos

Acceso con un solo toque a atajos de teclado comunes, organizados por aplicación. Las etiquetas de acceso directo se adaptan automáticamente al **SO de destino** (Ctrl+Z en Windows/Linux, Cmd+Z en macOS).

## Perfiles integrados

| Perfil | Qué cubre |
|---|---|
| **Predeterminado** | Atajos comunes (Copiar, Pegar, Deshacer, Guardar, etc.): no se pueden eliminar |
| **Blender 3D** | Atajos de transformación, selección, visualización, malla, modo y sombreado |
| **KiCAD** | Diseño de PCB: capas, dibujo, componentes, propiedades |
| **Nomad Sculpt** | Herramientas para esculpir, pincel, transformar, ver, enmascarar |
| **Fusion 360** | CAD: navegación, croquis, modelado, construcción, montaje |
| **Photoshop** | Herramientas, editar, ver accesos directos |
| **VS Code** | Navegación, edición, código, ver accesos directos |

## Usando atajos

1. Abra **Shortcut Hub** (o el modo "Atajos" desde la barra lateral en Android).
2. Toca cualquier perfil para abrirlo.
3. Dentro de un perfil, busque **pestañas de categorías** y toque cualquier tarjeta de acceso directo para ejecutarla.
4. Las etiquetas de los accesos directos se adaptan automáticamente al **SO de destino**

## Creación y gestión de perfiles

| Acción | Cómo |
|---|---|
| Crear un perfil | Toca **"Crear perfil"**, ingresa un nombre |
| Editar un acceso directo | Mantenga presionado el acceso directo → "Editar" |
| Eliminar un acceso directo | Mantenga presionado el acceso directo → "Eliminar" |
| Añadir a favoritos | Mantenga presionado → "Agregar a Mi" |
| Duplicar un perfil | Mantenga presionado un perfil → "Duplicar" |
| Exportar un perfil | Mantenga presionado → "Exportar": guarda un archivo JSON |
| Importar un perfil | Toca **"Importar"**: pega JSON o busca un archivo |

Cada perfil también tiene una sección **Mis atajos** para atajos personales.
