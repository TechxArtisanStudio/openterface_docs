# 9. Numpad

Een volledig numeriek toetsenbord voor gegevensinvoer. Elke toets verzendt de bijbehorende numerieke toetscode HID.

## Sleuteltoewijzing

| Sleutel | HID Gebruikscode |
|-----|--------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| Voer in | 0x58 |
| . / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## Toepassingsspecifieke rasters

Sommige snelkoppelingsprofielen (Blender, Fusion 360, KiCad) bevatten **aangepaste numerieke rasters** die zijn afgestemd op hun specifieke toepassingen.
