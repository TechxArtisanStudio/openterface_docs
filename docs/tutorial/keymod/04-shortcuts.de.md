# 4. Shortcut-Hub

Zugriff auf gängige Tastaturkürzel mit nur einem Fingertipp, geordnet nach Anwendung. Verknüpfungsbezeichnungen passen sich automatisch an das **Zielbetriebssystem** an (Ctrl+Z auf Windows/Linux, Cmd+Z auf macOS).

## Integrierte Profile

| Profil | Was es abdeckt |
|---|---|
| **Standard** | Allgemeine Verknüpfungen (Kopieren, Einfügen, Rückgängig machen, Speichern usw.) – können nicht gelöscht werden |
| **Blender 3D** | Tastenkombinationen für Transformation, Auswahl, Ansicht, Netz, Modus und Schattierung |
| **KiCAD** | PCB-Design: Schichten, Zeichnung, Komponenten, Eigenschaften |
| **Nomad Sculpt** | Bildhauerwerkzeuge, Pinsel, Transformieren, Anzeigen, Maskieren |
| **Fusion 360** | CAD: Navigation, Skizze, Modellierung, Konstruktion, Montage |
| **Photoshop** | Tools, Bearbeiten, Verknüpfungen anzeigen |
| **VS Code** | Navigation, Bearbeitung, Code, Verknüpfungen anzeigen |

## Verknüpfungen verwenden

1. Öffnen Sie den **Shortcut Hub** (oder den „Shortcuts“-Modus in der Seitenleiste auf Android).
2. Tippen Sie auf ein beliebiges Profil, um es zu öffnen
3. Durchsuchen Sie in einem Profil **Kategorieregisterkarten** und tippen Sie auf eine Verknüpfungskarte, um sie auszuführen
4. Die Verknüpfungsbezeichnungen passen sich automatisch an das **Zielbetriebssystem** an.

## Profile erstellen und verwalten

| Aktion | Wie |
|---|---|
| Erstellen Sie ein Profil | Tippen Sie auf **„Profil erstellen“**, geben Sie einen Namen ein |
| Bearbeiten Sie eine Verknüpfung | Drücken Sie lange auf die Tastenkombination → „Bearbeiten“ |
| Eine Verknüpfung löschen | Drücken Sie lange auf die Tastenkombination → „Löschen“ |
| Zu Favoriten hinzufügen | Langes Drücken → „Zu „Mein“ hinzufügen“ |
| Ein Profil duplizieren | Drücken Sie lange auf ein Profil → „Duplizieren“ |
| Ein Profil exportieren | Langes Drücken → „Exportieren“ – speichert eine JSON-Datei |
| Ein Profil importieren | Tippen Sie auf **„Importieren“** – fügen Sie JSON ein oder suchen Sie nach einer Datei |

Jedes Profil verfügt außerdem über einen Abschnitt **Meine Verknüpfungen** für persönliche Verknüpfungen.
