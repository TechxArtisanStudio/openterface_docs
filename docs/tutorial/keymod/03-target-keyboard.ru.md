# 3. Целевая ОС

KeyMod отправляет нажатия клавиш, которые адаптируются к операционной системе целевого компьютера. Правильная настройка гарантирует, что правильные ключи попадут в цель.

## Как установить

Коснитесь **значка ОС** в строке заголовка, чтобы открыть окно выбора:

<div align="center">
  <img src="images/demo-target-os-picker.png" alt="Target OS picker dialog" width="300" />
  <p><em> Выбор целевой ОС — выберите macOS, Windows или Linux.</em></p>
</div>

> **Примечание.** Скриншота для этого пока нет. Средство выбора ОС представляет собой диалоговое окно с тремя кнопками со значками (macOS, Windows, Linux), которое появляется при нажатии значка ОС в строке заголовка.

## Что это меняет

| Цель | Сопоставление клавиш |
|--------|-------------|
| **Windows** | Клавиша Win сопоставлена ​​с клавишей Windows; стандартное поведение модификатора ПК |
| **macOS** | Клавиша Win сопоставлена ​​с Cmd; Alt отображается на Option; правильные ярлыки |
| **Linux** | Поведение клавиш Super/Meta |

Это влияет на:
- **Ярлыки ярлыков** отображаются в Центре ярлыков.
- **Сопоставление клавиш-модификаторов** (поведение Win клавиш)
- **Метод ввода Unicode** используется для символов, отличных от ASCII.

## Символы Юникода

Для символов, отличных от ASCII (китайский, японский, эмодзи), требуются методы ввода, специфичные для ОС:

| ОС | Метод |
|---|---|
| **Windows** | Alt+NumPad шестнадцатеричный ввод Юникода |
| **Linux** | Ctrl+Shift+U, за которым следует шестнадцатеричный код |
| **macOS** | Option+шестнадцатеричный ввод |

Если символы Юникода отображаются на целевой системе неправильно, убедитесь, что целевая ОС установлена ​​правильно.

## Режимы клавиатуры (не раскладки)

KeyMod обеспечивает три режима клавиатуры для набора текста:

| Режим | Как переключиться |
|---|---|
| **ABC** (буквы) | Нажмите кнопку **ABC** |
| **123** (цифры) | Нажмите клавишу **123** |
| **!?#** (символы) | Нажмите кнопку **!?#** |

Это переключатели методов ввода в приложении, а не физические раскладки клавиатуры. KeyMod в настоящее время отправляет стандартные скан-коды USB HID (база QWERTY для США). Если вы используете на целевой клавиатуре неамериканскую физическую клавиатуру, вы можете увидеть небольшие несоответствия символов в одних и тех же позициях клавиш.
