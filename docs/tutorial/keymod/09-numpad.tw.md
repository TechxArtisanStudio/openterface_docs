# 9. 數字鍵盤

完整數字鍵盤，用於數據錄入。每個按鍵發送對應的 HID 小鍵盤鍵碼。

## 按鍵映射

| 按鍵 | HID Usage Code |
|-----|---------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| Enter | 0x58 |
| . / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## 應用專用網格

部分快捷方式配置文件（Blender、Fusion 360、KiCad）包含針對各應用的 **自定義數字鍵盤網格**。
