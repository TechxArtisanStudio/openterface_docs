# 1. البدء

قم بتثبيت تطبيق KeyMod، واتصل بجهاز KeyMod الخاص بك، وأرسل أول ضغطة على المفتاح في أقل من 5 دقائق.

## ما تحتاجه

- **Openterface KeyMod الأجهزة** — قيد التشغيل وداخل النطاق
- **الهاتف أو الجهاز اللوحي** — Android مع تثبيت تطبيق KeyMod
- **USB كابل** (للإعداد الأولي) — USB-C لتوصيل هاتفك بجهاز KeyMod
- **بلوتوث** (اختياري) — للاتصال اللاسلكي بعد الإعداد الأولي

## الخطوة 1: قم بتثبيت تطبيق KeyMod

**Android:**

1. افتح متصفح هاتفك وانتقل إلى [KeyMod GitHub Releases page](https://github.com/TechxArtisanStudio/Openterface_KeyMod_Android/tags)
2. قم بتنزيل أحدث ملف `.apk`
3. اضغط على الملف الذي تم تنزيله للتثبيت
4. إذا طلب Android السماح بـ **"تثبيت تطبيقات غير معروفة"** لمتصفحك

وبدلاً من ذلك، يمكنك البناء من المصدر — راجع [Build from Source](#build-from-source) أدناه.

## الخطوة 2: اتصل بجهاز KeyMod الخاص بك

يتصل KeyMod بجهاز Openterface KeyMod بطريقتين:

### USB اتصال (موصى به للإعداد لأول مرة)

1. قم بتوصيل هاتفك بجهاز KeyMod باستخدام كابل USB-C
2. افتح تطبيق KeyMod
3. اضغط على أيقونة الاتصال (الزاوية العلوية اليمنى من الشاشة الرئيسية)
4. اضغط على **"USB اتصال"**
5. اقبل مطالبة الإذن USB عندما يُطلب منك ذلك
6. يجب أن تشاهد مؤشر الحالة **"متصل"** باللون الأخضر

### اتصال بلوتوث (لاسلكي)

1. تأكد من تمكين البلوتوث على هاتفك
2. افتح KeyMod واضغط على أيقونة الاتصال
3. اضغط على **"اتصال بلوتوث"**
4. انتظر حتى يظهر جهازك KeyMod في قائمة المسح
5. اضغط عليه للاقتران
6. يجب أن تشاهد مؤشر الحالة **"متصل"** باللون الأخضر

> **نصيحة:** قم بتمكين **"الاتصال التلقائي عند بدء التشغيل"** في مربع حوار الاتصال حتى يقوم KeyMod بإعادة الاتصال تلقائيًا في كل مرة تفتحه. يتذكر التطبيق نوع الاتصال الأخير (USB أو BLE).

**"تخطي" button** — تجاوز شاشة الترحيب وادخل إلى الوضع المستخدم مسبقًا على الفور.

## الخطوة 4: أرسل ضغطة المفتاح الأولى

1. حدد وضع **لوحة المفاتيح والماوس**
2. اضغط على أي مفتاح على لوحة المفاتيح التي تظهر على الشاشة
3. يتم إرسال ضغطة المفتاح المقابلة إلى الكمبيوتر الهدف

هذا كل شيء! أنت الآن تتحكم في جهاز الكمبيوتر المستهدف الخاص بك عن بعد.

## مؤشرات حالة الاتصال

| المؤشر | معنى |
|---|---|
| **الأخضر** (أيقونة متصلة) | اتصال نشط، جاهز لإرسال الإدخال |
| **كهرماني/أزرق** (رمز الاتصال) | الاتصال قيد التقدم |
| **الرمادي** (أيقونة غير متصلة) | لا يوجد اتصال نشط |
| **أشرطة الإشارة** | BLE قوة الإشارة أو USB الحالة النشطة |

## البناء من المصدر (Android، للمطورين)```bash
# Clone the repository
git clone https://github.com/TechxArtisanStudio/Openterface_KeyMod_Android.git
cd Openterface_KeyMod_Android

# Build (requires Java 21 and Android SDK 35)
./gradlew assembleDebug

# The APK will be at:
ls app/build/outputs/apk/debug/KeyMod-debug.apk

# Install on a connected device
adb install -r app/build/outputs/apk/debug/KeyMod-debug.apk
