# 9. Tastierino numerico

Un tastierino numerico completo per l'immissione dei dati. Ogni tasto invia il corrispondente codice del tastierino numerico HID.

## Mappatura dei tasti

| Chiave | HID Codice utilizzo |
|-----|---------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| Inserisci | 0x58 |
| . / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## Griglie specifiche dell'applicazione

Alcuni profili di scelta rapida (Blender, Fusion 360, KiCad) includono **griglie personalizzate del tastierino numerico** su misura per le loro applicazioni specifiche.
