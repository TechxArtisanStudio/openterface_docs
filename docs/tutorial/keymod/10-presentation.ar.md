# 10. العرض التقديمي

تحكم في عرض الشرائح الخاص بك من هاتفك - دون الحاجة إلى النقر.

## الضوابط

| Button | هل |
|---|---|
| **التالي** | يتقدم إلى الشريحة التالية (السهم الأيمن). الضغط لفترة طويلة = انتقل إلى الشريحة الأخيرة |
| **السابق** | للرجوع إلى شريحة واحدة (السهم الأيسر). الضغط لفترة طويلة = انتقل إلى الشريحة الأولى |
| ** تشغيل / إيقاف ** | يبدأ/يوقف العرض التقديمي |
| **ب (شاشة فارغة)** | تبديل الشاشة السوداء |
| **المؤشر** | فتح نافذة منبثقة touchpad للتحكم بالماوس |
| **محول التطبيقات** | يفتح مبدل تطبيق نظام التشغيل (Cmd+Tab / Alt+Tab) |

## منتقي أداة العرض التقديمي

يتيح لك الرف الدائري تحديد برنامج العرض التقديمي (Keynote، PowerPoint، Google Slides، Word، Adobe Reader). تحتوي كل أداة على مجموعات مفاتيح فريدة للتشغيل/الإيقاف.

## مؤقت الشريحة

تدعم بطاقة المؤقت أوضاع العد التنازلي والعد التنازلي، مع شريط تعبئة التقدم، وتنبيه الاهتزاز في الوقت المستهدف، والحالة المستمرة عبر دورة حياة التطبيق.

## الإيماءات

- **اسحب لليسار** → الشريحة التالية
- **اسحب لليمين** → الشريحة السابقة
- **اضغط** ← الشريحة التالية
