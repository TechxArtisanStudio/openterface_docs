# 9. Teclado numérico

Um teclado numérico completo para entrada de dados. Cada tecla envia o código de tecla HID correspondente do teclado numérico.

## Mapeamento de teclas

| Chave | HID Código de uso |
|-----|---------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| Entrar | 0x58 |
| . / = | 0x63/0x67 |
| NumLock | 0x53 |

## Grades específicas do aplicativo

Alguns perfis de atalho (Blender, Fusion 360, KiCad) incluem **grades de teclado numérico personalizadas** adaptadas às suas aplicações específicas.
