# KeyMod البرنامج التعليمي

{% include "partials/keymod-tutorial-slideshow.html" %}

يغطي هذا البرنامج التعليمي الإصدار **Android** من تطبيق KeyMod. إصدار iOS قيد التطوير.

## ما هو KeyMod؟

KeyMod يحول هاتفك أو جهازك اللوحي إلى **جهاز إدخال عالمي** لأي جهاز كمبيوتر. وهو يتصل بالأجهزة **Openterface KeyMod** (KVM — لوحة المفاتيح والفيديو والماوس)، والتي ترسل بعد ذلك ضغطات المفاتيح وحركات الماوس ومدخلات لوحة الألعاب في هاتفك إلى الكمبيوتر المستهدف كما لو كانت قادمة من لوحة مفاتيح وماوس USB حقيقيين.

### كيف يعمل الاتصال

[ Your Phone ] ──USB/BLE──> [ KeyMod Hardware ] ──USB HID──> [ Target Computer ]
   (KeyCmd app)                (CH9329 protocol)              (Windows/macOS/Linux)
```

يتواصل التطبيق مع أجهزة KeyMod باستخدام بروتوكول **CH9329** عبر اتصال تسلسلي (USB-C عند 115200 baud، 8N1، أو Bluetooth BLE). يظهر جهاز KeyMod للكمبيوتر المستهدف كلوحة مفاتيح وماوس USB قياسيين — لا حاجة إلى برامج تشغيل.

### لمن هذا؟

| أنت... | KeyMod يساعدك... |
|---|---|
| **مسؤول النظام** | قم بإدارة الخوادم من هاتفك دون حمل لوحة مفاتيح وشاشة احتياطية |
| **المقدم / المتحدث** | التحكم في الشرائح من أي مكان في الغرفة، دون الحاجة إلى النقر |
| **اللاعب** | استخدم هاتفك كلوحة ألعاب للألعاب القديمة أو كوحدة تحكم إضافية |
| **صانع المحتوى** | تشغيل الاختصارات ووحدات الماكرو والإدخال الصوتي أثناء التسجيل على جهاز آخر |
| ** مستخدم قوي ** | أرسل اختصارات لوحة المفاتيح المعقدة أو مقتطفات نصية أو تسلسلات تلقائية من هاتفك |
| **أي شخص** | اكتب على جهاز الكمبيوتر الخاص بك من الأريكة أو السرير أو في جميع أنحاء الغرفة |
