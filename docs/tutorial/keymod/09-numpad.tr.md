# 9. Sayısal tuş takımı

Veri girişi için tam sayısal tuş takımı. Her tuş karşılık gelen HID sayısal tuş takımı tuş kodunu gönderir.

## Anahtar Eşleme

| Anahtar | HID Kullanım Kodu |
|-----|---------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| Girin | 0x58 |
| . / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## Uygulamaya Özel Izgaralar

Bazı kısayol profilleri (Blender, Fusion 360, KiCad) özel uygulamalara göre tasarlanmış **özel sayısal tuş takımı ızgaraları** içerir.
