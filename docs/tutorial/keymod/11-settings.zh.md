# 11. 设置

配置 KeyMod 的行为与外观。

## 常规设置

| 设置 | 说明 |
|---|---|
| **Auto-connect** | 启动时重连上次设备（USB 或 BLE） |
| **Keep screen on** | 使用应用时防止屏幕休眠 |
| **Haptic feedback** | 按键时振动 |
| **Orientation lock** | 将屏幕方向锁定为竖屏或横屏 |
| **Language** | English、中文、Español、Français、Deutsch、日本語 |
| **Theme** | 8 种色系、深色/浅色、跟随系统 |
| **BLE Key Delay** | BLE 发送按键间的延迟（若漏字可调整） |
| **Touchpad sensitivity** | 滚动灵敏度滑块 |

## 目标系统

设置目标系统以匹配目标电脑的按键习惯。影响快捷方式标签、Unicode 输入方式与修饰键映射。

| 目标 | 按键映射 |
|--------|-------------|
| **Windows** | Alt、Ctrl、Win 键行为 |
| **Mac** | Cmd、Option 键行为 |
| **Linux** | Super、Meta 键行为 |

点击标题栏 **系统图标** 可更改目标系统。

键盘布局与 Unicode 输入详情见 [目标系统](03-target-keyboard.md)。
