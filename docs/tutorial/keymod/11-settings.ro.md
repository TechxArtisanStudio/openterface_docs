# 11. Setări

Configurați comportamentul și aspectul lui KeyMod.

## Setări generale

| Setare | Descriere |
|---|---|
| **Conectare automată** | Reconectați-vă la ultimul dispozitiv (USB sau BLE) la pornire |
| **Păstrați ecranul aprins** | Preveniți adormirea ecranului în timp ce utilizați aplicația |
| **Feedback haptic** | Vibrații la button apăsări |
| **Blocare de orientare** | Blocați orientarea ecranului către portret sau peisaj |
| **Limba** | Engleză, 中文, Español, Français, Deutsch, 日本語 |
| **Temă** | 8 familii de culori, întunecat/luminos, sistem de urmărire |
| **BLE Întârziere tastă** | Întârziere între apăsările de taste trimise peste BLE (ajustați dacă caracterele sunt ratate) |
| **Touchpad sensibilitate** | Glisor pentru sensibilitate de defilare |

## Sistemul de operare țintă

Setați sistemul de operare țintă pentru a se potrivi cu convențiile cheie ale computerului țintă. Acest lucru afectează etichetele comenzilor rapide, metodele de introducere Unicode și maparea tastelor modificatoare.

| Țintă | Maparea cheilor |
|--------|--------------|
| **Windows** | Alt, Ctrl, Win comportament cheie |
| **Mac** | Cmd, Option comportament cheie |
| **Linux** | Super, Meta comportament cheie |

Schimbați sistemul de operare țintă atingând **pictograma OS** din bara de antet.

Consultați [Target-Specific Keyboard](03-target-keyboard.md) pentru aspectul tastaturii și detaliile de intrare Unicode.
