# 9. Teclado numérico

Un teclado numérico completo para la entrada de datos. Cada tecla envía el código de tecla del teclado numérico HID correspondiente.

## Mapeo de claves

| Clave | HID Código de uso |
|-----|---------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| Entrar | 0x58 |
| . / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## Cuadrículas específicas de la aplicación

Algunos perfiles de acceso directo (Blender, Fusion 360, KiCad) incluyen **cuadrículas de teclado numérico personalizadas** adaptadas a sus aplicaciones específicas.
