#9. テンキー

データ入力用のフルテンキーパッド。各キーは、対応する HID テンキー キー コードを送信します。

## キーのマッピング

|キー | HID 使用コード |
|-----|--------------|
| 0-9 | 0x62、0x59-0x61 |
| +、-、*、/ | 0x57、0x56、0x55、0x54 |
| | を入力してください0x58 |
| 。 / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## アプリケーション固有のグリッド

一部のショートカット プロファイル (Blender、Fusion 360、KiCad) には、特定のアプリケーションに合わせた **カスタム テンキー グリッド**が含まれています。
