# 7. Интеграция ИИ

Голосовой ввод с поддержкой искусственного интеллекта, уточнением текста и преобразованием команд на естественном языке.

> Функции искусственного интеллекта **отключены по умолчанию**. Включите их в настройках, чтобы получить доступ к этим функциям.

## Особенности

- **Уточнение текста** — исправляйте ошибки транскрипции и улучшайте качество текста.
- **Command Assistant** — преобразуйте речь на естественном языке в команды, вводимые с клавиатуры.

## Поставщики ИИ

| Провайдер | Опции |
|---|---|
| **Поставщик искусственного интеллекта** | OpenAI, Anthropic, Google Gemini, Mistral AI, Groq, Alibaba (Qwen), DeepSeek или Пользовательский |
| **Конечная точка API** | Установите URL-адрес службы AI |
| **Модель** | Выберите модель ИИ |
| **Ключ API** | Установите в «Настройки» > «Настройки AI» |
| **Роль ИИ** | «Помощник по командам» (голос → действия с клавиатуры) или «Уточнение текста» (голос → улучшенный текст) |

## Роли системных подсказок

- **Уточнение текста:** исправляет ошибки преобразования речи в текст, улучшает грамматику и ясность.
- **Command Assistant:** преобразует естественный язык в команды клавиатуры. Запросы для конкретной ОС: Windows, macOS и Linux.
- **Пользовательский:** определяемое пользователем системное приглашение для особого поведения.

## Макроконтекст в ИИ

Когда ИИ включен, определенные вами макросы автоматически включаются в системную подсказку, что позволяет ИИ предлагать или вызывать их по имени.

## Устранение неполадок

### API-ключ не работает

| Симптом | Решение |
|---|---|
| **"Ключ API не настроен"** | Убедитесь, что ключ API верен — проверьте наличие лишних пробелов и опечаток. Проверьте базовый URL-адрес API — он должен включать полный путь (например, `https://api.openai.com/v1`). Убедитесь, что имя модели существует у поставщика. Для местных поставщиков (Ollama) убедитесь, что установлен флаг «Необязательный ключ API». |

### Уточнение текста медленно

Проверьте сетевое соединение. Попробуйте более быструю модель — модели меньшего размера (gpt-3.5-turbo, llama3-8b) реагируют быстрее. Используйте местного провайдера (Ollama), чтобы устранить задержку в сети. Проверьте историю запросов AI на наличие сообщений об ошибках.
