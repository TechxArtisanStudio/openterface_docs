# 10. Sunum

Slayt gösterinizi telefonunuzdan kontrol edin; tıklamaya gerek yok.

## Kontroller

| Button | |
|---|---|
| **Sonraki** | Sonraki slayda ilerler (Sağ Ok). Uzun basma = son slayda git |
| **Önceki** | Bir slayt geri gider (Sol Ok). Uzun basma = ilk slayda git |
| **Oynat / Durdur** | Sunumu başlatır/durdurur |
| **B (Boş Ekran)** | Siyah ekranı açar/kapatır |
| **İşaretçi** | Fare kontrolü için touchpad açılır penceresini açar |
| **Uygulama Değiştirici** | İşletim sistemi uygulama değiştiricisini açar (Cmd+Sekme / Alt+Sekme) |

## Sunum Aracı Seçici

Döner menü sunum yazılımınızı seçmenizi sağlar (Keynote, PowerPoint, Google Slides, Word, Adobe Reader). Her aracın oynatma/durdurma için benzersiz tuş kombinasyonları vardır.

## Slayt Zamanlayıcısı

Zamanlayıcı kartı, ilerleme doldurma çubuğu, hedef zamanda titreşim uyarısı ve uygulama yaşam döngüsü boyunca kalıcı durumla geri sayım ve sayım modlarını destekler.

## Hareketler

- **Sola kaydırın** → Sonraki slayt
- **Sağa kaydırın** → Önceki slayt
- **Dokunun** → Sonraki slayt
