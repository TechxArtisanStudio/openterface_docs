# 7. Intégration de l'IA

Saisie vocale améliorée par l'IA avec raffinement du texte et conversion des commandes en langage naturel.

> Les fonctionnalités d'IA sont **désactivées par défaut**. Activez-les dans Paramètres pour accéder à ces fonctionnalités.

## Fonctionnalités

- **Text Refinement** — Corrigez les erreurs de transcription et améliorez la qualité du texte
- **Command Assistant** — Convertissez la parole en langage naturel en commandes clavier

## Fournisseurs d'IA

| Fournisseur | Options |
|---|---|
| **Fournisseur d'IA** | OpenAI, Anthropic, Google Gemini, Mistral AI, Groq, Alibaba (Qwen), DeepSeek ou personnalisé |
| **Point de terminaison de l'API** | Définir l'URL du service AI |
| **Modèle** | Choisissez le modèle IA |
| **Clé API** | Définir dans Paramètres > Paramètres IA |
| **Rôle de l'IA** | "Assistant de commande" (voix → actions clavier) ou "Affinement du texte" (voix → texte amélioré) |

## Rôles d'invite système

- **Affinement du texte :** Corrige les erreurs de synthèse vocale, améliore la grammaire et la clarté
- **Command Assistant :** Convertit le langage naturel en commandes clavier. Invites spécifiques au système d'exploitation pour Windows, macOS et Linux.
- **Personnalisé :** Invite système définie par l'utilisateur pour un comportement spécialisé

## Contexte macro dans l'IA

Lorsque l'IA est activée, vos macros définies sont automatiquement incluses dans l'invite du système, permettant à l'IA de les suggérer ou de les invoquer par leur nom.

## Dépannage

### La clé API ne fonctionne pas

| Symptôme | Solutions |
|---|---|
| **"Clé API non configurée"** | Vérifiez que la clé API est correcte : vérifiez les espaces supplémentaires ou les fautes de frappe. Vérifiez l'URL de base de l'API : elle doit inclure le chemin complet (par exemple, `https://api.openai.com/v1`). Vérifiez que le nom du modèle existe sur le fournisseur. Pour les fournisseurs locaux (Ollama), assurez-vous que l'indicateur Clé API facultative est défini. |

### Affinement du texte lent

Vérifiez votre connexion réseau. Essayez un modèle plus rapide : les modèles plus petits (gpt-3.5-turbo, llama3-8b) répondent plus rapidement. Utilisez un fournisseur local (Ollama) pour éliminer la latence du réseau. Vérifiez l’historique des demandes AI pour les messages d’erreur.
