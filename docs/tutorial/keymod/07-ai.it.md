# 7. Integrazione IA

Input vocale potenziato dall'intelligenza artificiale con perfezionamento del testo e conversione dei comandi in linguaggio naturale.

> Le funzionalità AI sono **disabilitate per impostazione predefinita**. Abilitali nelle Impostazioni per accedere a queste funzionalità.

## Caratteristiche

- **Perfezionamento del testo**: correggi gli errori di trascrizione e migliora la qualità del testo
- **Assistente comandi**: converti il parlato in linguaggio naturale in comandi da tastiera

## Fornitori di intelligenza artificiale

| Fornitore | Opzioni |
|---|---|
| **Fornitore di intelligenza artificiale** | OpenAI, Anthropic, Google Gemini, Mistral AI, Groq, Alibaba (Qwen), DeepSeek o Personalizzato |
| **Endpoint API** | Imposta l'URL per il servizio AI |
| **Modello** | Scegli il modello AI |
| **Chiave API** | Impostalo in Impostazioni > Impostazioni AI |
| **Ruolo dell'IA** | "Assistente ai comandi" (voce → azioni da tastiera) o "Perfezionamento del testo" (voce → testo migliorato) |

## Ruoli dei prompt di sistema

- **Perfezionamento del testo:** corregge gli errori di sintesi vocale, migliora la grammatica e la chiarezza
- **Assistente comandi:** converte il linguaggio naturale in comandi da tastiera. Richieste specifiche del sistema operativo per Windows, macOS e Linux.
- **Personalizzato:** prompt di sistema definito dall'utente per un comportamento specializzato

## Contesto macro nell'intelligenza artificiale

Quando l'intelligenza artificiale è abilitata, le macro definite vengono automaticamente incluse nel prompt del sistema, consentendo all'intelligenza artificiale di suggerirle o invocarle per nome.

## Risoluzione dei problemi

### Chiave API non funzionante

| Sintomo | Soluzione |
|---|---|
| **"Chiave API non configurata"** | Verifica che la chiave API sia corretta: controlla la presenza di spazi aggiuntivi o errori di battitura. Controlla l'URL di base dell'API: deve includere il percorso completo (ad esempio, `https://api.openai.com/v1`). Verificare che il nome del modello esista nel provider. Per i provider locali (Ollama), assicurarsi che il flag API Key Opzionale sia impostato. |

### Perfezionamento del testo lento

Controlla la tua connessione di rete. Prova un modello più veloce: i modelli più piccoli (gpt-3.5-turbo, llama3-8b) rispondono più velocemente. Utilizzare un provider locale (Ollama) per eliminare la latenza di rete. Controlla la cronologia delle richieste AI per i messaggi di errore.
