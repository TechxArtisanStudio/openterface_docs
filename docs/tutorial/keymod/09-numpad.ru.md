# 9. Цифровая клавиатура

Полноценная цифровая клавиатура для ввода данных. Каждая клавиша отправляет соответствующий код цифровой клавиши HID.

## Сопоставление клавиш

| Ключ | HID Код использования |
|-----|---------------|
| 0-9 | 0x62, 0x59-0x61 |
| +, -, *, / | 0x57, 0x56, 0x55, 0x54 |
| Войти | 0x58 |
| . / = | 0x63/0x67 |
| NumLock | 0x53 |

## Сетки для конкретных приложений

Некоторые профили ярлыков (Blender, Fusion 360, KiCad) включают **настраиваемые сетки цифровой клавиатуры**, адаптированные к конкретным приложениям.
