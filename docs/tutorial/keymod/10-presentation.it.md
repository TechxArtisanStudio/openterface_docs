# 10. Presentazione

Controlla la tua presentazione dal tuo telefono: non è necessario alcun clicker.

## Controlli

| Button | Fa |
|---|---|
| **Avanti** | Avanza alla diapositiva successiva (Freccia destra). Pressione prolungata = vai all'ultima diapositiva |
| **Precedente** | Torna indietro di una diapositiva (Freccia sinistra). Pressione prolungata = vai alla prima diapositiva |
| **Riproduci/Interrompi** | Avvia/arresta la presentazione |
| **B (schermata vuota)** | Attiva/disattiva lo schermo nero |
| **Puntatore** | Apre un pop-out touchpad per il controllo del mouse |
| **Commutatore di app** | Apre il commutatore di app del sistema operativo (Cmd+Tab / Alt+Tab) |

## Selettore strumenti di presentazione

Un carosello ti consente di selezionare il software di presentazione (Keynote, PowerPoint, Google Slides, Word, Adobe Reader). Ogni strumento ha combinazioni di tasti uniche per play/stop.

## Timer diapositiva

La scheda timer supporta le modalità di conto alla rovescia e conteggio alla rovescia, con una barra di riempimento di avanzamento, un avviso con vibrazione all'ora target e uno stato persistente durante il ciclo di vita dell'app.

## Gesti

- **Scorri verso sinistra** → Diapositiva successiva
- **Scorri verso destra** → Diapositiva precedente
- **Tocca** → Diapositiva successiva
