#11. 設定

KeyMod の動作と外観を構成します。

## 一般設定

|設定 |説明 |
|---|---|
| **自動接続** |起動時に最後のデバイス (USB または BLE) に再接続します。
| **画面をオンのままにしてください** |アプリの使用中に画面がスリープ状態になるのを防ぐ |
| **触覚フィードバック** | button を押すと振動 |
| **方向ロック** |画面の向きを縦または横にロックする |
| **言語** |英語、中国語、スペイン語、フランス語、ドイツ語、日本語 |
| **テーマ** | 8色ファミリー、ダーク/ライト、フォローシステム |
| **BLE キー遅延** | BLE を超えて送信されるキーストローク間の遅延 (文字が欠落している場合は調整します) |
| **Touchpad 感度** |スクロール感度スライダー |

## ターゲット OS

ターゲット OS をターゲット コンピュータの主要な規則に一致するように設定します。これは、ショートカット ラベル、Unicode 入力メソッド、および修飾キー マッピングに影響します。

|ターゲット |キーのマッピング |
|----------|---------------|
| **Windows** | Alt、Ctrl、Win キーの動作 |
| **マック** | Cmd、Option キーの動作 |
| **Linux** | Super、Meta キーの動作 |

ヘッダー バーの **OS アイコン**をタップして、ターゲット OS を変更します。

キーボードのレイアウトと Unicode 入力の詳細については、[Target-Specific Keyboard](03-target-keyboard.md) を参照してください。
