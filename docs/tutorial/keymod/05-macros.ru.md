# 5. Макросы

Записывайте и воспроизводите автоматические последовательности клавиш одним касанием.

## Что такое макрос?

Макрос – это **записанная последовательность нажатий клавиш**, которую можно воспроизвести. Например:
- Введите подпись электронной почты одним нажатием
- Отправьте `Ctrl+Shift+Esc`, а затем `Alt+D` последовательно.
- Автоматизировать многоэтапную последовательность команд с задержками между шагами.

## Синтаксис токена макроса

| Токен | Значение |
|---|---|
| `<CTRL>` ... `</CTRL>` | Удержать/отпустить Управление |
| `<SHIFT>` ... `</SHIFT>` | Удерживайте/отпустите Shift |
| `<ALT>` ... `</ALT>` | Удерживайте/отпустите Alt/Option |
| `<CMD>` ... `</CMD>` | Удержать/отпустить команду/Win/Super |
| `<ESC>`, `<BACK>`, `<ENTER>`, `<SPACE>` | Специальные клавиши |
| `<LEFT>`, `<RIGHT>`, `<UP>`, `<DOWN>` | Клавиши со стрелками |
| `<HOME>`, `<END>`, `<TAB>`, `<DEL>` | Клавиши навигации |
| с `<F1>` по `<F12>` | Функциональные клавиши |
| `<DELAY1S>`, `<DELAY2S>`, `<DELAY5S>`, `<DELAY10S>` | Паузы |

**Пример:**```
<CTRL><ALT>t</ALT></CTRL><DELAY1S>ls -la<ENTER>
Это открывает терминал (Ctrl+Alt+T), ждет 1 секунду, затем набирает `ls -la` и нажимает Enter.

## Создание макроса

1. Перейдите в режим **Макросы**.
2. Нажмите **"+"**, чтобы создать новый макрос.
3. Введите **имя/метку макроса**.
4. Создайте последовательность макрокоманд, используя текстовое поле и жетоны быстрой вставки.
5. Настройте **Интервал отправки символов** (задержка между нажатиями клавиш в миллисекундах).
6. Нажмите **"Сохранить"**.
