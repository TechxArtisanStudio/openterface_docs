# 9. اللوحة الرقمية

لوحة مفاتيح رقمية كاملة لإدخال البيانات. يرسل كل مفتاح رمز مفتاح اللوحة الرقمية HID المطابق.

## رسم الخرائط الرئيسية

| مفتاح | HID رمز الاستخدام |
|-----|--------------|
| 0-9 | 0x62، 0x59-0x61 |
| +، -، *، / | 0x57، 0x56، 0x55، 0x54 |
| أدخل | 0x58 |
| . / = | 0x63 / 0x67 |
| NumLock | 0x53 |

## شبكات خاصة بالتطبيقات

تتضمن بعض ملفات تعريف الاختصارات (Blender، Fusion 360، KiCad) **شبكات لوحة أرقام مخصصة** مصممة خصيصًا لتطبيقاتها المحددة.
