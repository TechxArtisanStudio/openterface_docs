# 6. 语音输入

将语音转换为发送到目标电脑的按键——免提输入与无障碍使用。

## 工作原理

1. 点击 **麦克风** 按钮
2. 说出要输入的内容
3. 语音转换为文字
4. 文字作为按键发送到目标电脑

## STT 引擎

| 引擎 | 工作方式 | 设置 |
|---|---|---|
| **System Recognizer** | 使用 Android 内置语音识别 | 需要 Google 语音输入 |
| **Whisper** | 设备端或云端 AI 转写 | 在 设置 > 语音输入 中设置 API 密钥 |

## 静音检测与自动暂停

两种引擎均支持静音检测：停止说话后自动暂停录音（默认 2.0 秒静音超时）。可在语音输入界面开关自动暂停。

### 静音检测故障排除

| 现象 | 解决方案 |
|---|---|
| **未说话时仍在录音** | 检查「静音时自动暂停」开关。减少背景噪音。清晰、靠近麦克风说话。 |
| **立即停止录音** | 提高音量或缩短静音检测超时。 |

## 迷你工具栏（Android）

| 按钮 | 功能 |
|---|---|
| **Copy** | 将转写文字复制到剪贴板 |
| **Auto Send** | 转写后自动发送文字 |
| **Auto Line Return** | 发送后追加 Enter 按键 |
| **AI Refine** | 将转写文字发送给 AI 润色 |

## 语音文字未发送

检查连接状态。未连接时「Send」按钮为禁用状态。
