# 6. 語音輸入

將語音轉換為發送到目標電腦的按鍵——免提輸入與無障礙使用。

## 工作原理

1. 點擊 **麥克風** 按鈕
2. 說出要輸入的內容
3. 語音轉換為文字
4. 文字作為按鍵發送到目標電腦

## STT 引擎

| 引擎 | 工作方式 | 設置 |
|---|---|---|
| **System Recognizer** | 使用 Android 內置語音識別 | 需要 Google 語音輸入 |
| **Whisper** | 設備端或雲端 AI 轉寫 | 在 設置 > 語音輸入 中設置 API 密鑰 |

## 靜音檢測與自動暫停

兩種引擎均支持靜音檢測：停止說話後自動暫停錄音（默認 2.0 秒靜音超時）。可在語音輸入界面開關自動暫停。

### 靜音檢測故障排除

| 現象 | 解決方案 |
|---|---|
| **未說話時仍在錄音** | 檢查「靜音時自動暫停」開關。減少背景噪音。清晰、靠近麥克風說話。 |
| **立即停止錄音** | 提高音量或縮短靜音檢測超時。 |

## 迷你工具欄（Android）

| 按鈕 | 功能 |
|---|---|
| **Copy** | 將轉寫文字複製到剪貼板 |
| **Auto Send** | 轉寫後自動發送文字 |
| **Auto Line Return** | 發送後追加 Enter 按鍵 |
| **AI Refine** | 將轉寫文字發送給 AI 潤色 |

## 語音文字未發送

檢查連接狀態。未連接時「Send」按鈕為禁用狀態。
