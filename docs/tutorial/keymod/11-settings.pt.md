# 11. Configurações

Configure o comportamento e a aparência de KeyMod.

## Configurações Gerais

| Configuração | Descrição |
|---|---|
| **Conexão automática** | Reconecte ao último dispositivo (USB ou BLE) na inicialização |
| **Manter a tela ligada** | Evitar suspensão da tela ao usar o aplicativo |
| **Feedback tátil** | Vibração ao pressionar button |
| **Bloqueio de orientação** | Bloquear orientação da tela para retrato ou paisagem |
| **Idioma** | Inglês, 中文, Español, Français, Deutsch, 日本語 |
| **Tema** | 8 famílias de cores, Escuro/Claro, Sistema Follow |
| **BLE Atraso de teclas** | Atraso entre as teclas enviadas por BLE (ajuste se faltarem caracteres) |
| **Touchpad sensibilidade** | Controle deslizante de sensibilidade de rolagem |

## SO alvo

Defina o sistema operacional de destino para corresponder às principais convenções do computador de destino. Isso afeta rótulos de atalho, métodos de entrada Unicode e mapeamento de teclas modificadoras.

| Alvo | Mapeamento de Chaves |
|--------|------------|
| **Windows** | Comportamento das teclas Alt, Ctrl, Win |
| **Mac** | Comportamento das teclas Cmd, Option |
| **Linux** | Comportamento das teclas Super, Meta |

Altere o sistema operacional de destino tocando no **ícone do sistema operacional** na barra de cabeçalho.

Consulte [Target-Specific Keyboard](03-target-keyboard.md) para ver o layout do teclado e detalhes de entrada Unicode.
