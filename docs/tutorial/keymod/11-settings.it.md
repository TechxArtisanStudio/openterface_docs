# 11. Impostazioni

Configura il comportamento e l'aspetto di KeyMod.

## Impostazioni generali

| Impostazione | Descrizione |
|---|---|
| **Connessione automatica** | Riconnettiti all'ultimo dispositivo (USB o BLE) all'avvio |
| **Mantieni lo schermo acceso** | Evita lo spegnimento dello schermo durante l'utilizzo dell'app |
| **Feedback tattile** | La vibrazione su button preme |
| **Blocco orientamento** | Blocca l'orientamento dello schermo in verticale o in orizzontale |
| **Lingua** | inglese, 中文, spagnolo, francese, tedesco, 日本語 |
| **Tema** | 8 famiglie di colori, Scuro/Chiaro, Sistema Follow |
| **BLE Ritardo tasto** | Ritardo tra le battute dei tasti inviate oltre BLE (regolare se mancano i caratteri) |
| **Touchpad sensibilità** | Dispositivo di scorrimento della sensibilità di scorrimento |

## Sistema operativo di destinazione

Imposta il sistema operativo di destinazione in modo che corrisponda alle convenzioni chiave del computer di destinazione. Ciò influisce sulle etichette delle scorciatoie, sui metodi di input Unicode e sulla mappatura dei tasti di modifica.

| Obiettivo | Mappatura tasti |
|--------|-------------|
| **Windows** | Comportamento chiave Alt, Ctrl, Win |
| **Mac** | Cmd, Option comportamento chiave |
| **Linux** | Super, Meta comportamento chiave |

Cambia il sistema operativo di destinazione toccando l'**icona del sistema operativo** nella barra dell'intestazione.

Vedere [Target-Specific Keyboard](03-target-keyboard.md) per il layout della tastiera e i dettagli sull'input Unicode.
