# VGA 轉 HDMI 轉換線

![CABLE100-VGA2HDMI](https://assets.openterface.com/images/product/part/CABLE100-VGA2HDMI-1.webp){:style="max-height:360px"}

此線纜將**VGA 視頻**和**3.5mm 音頻**組合成單個 HDMI 輸出，通過一個連接提供圖像和聲音。

-   **音頻輸出**: 嵌入 HDMI 信號中
-   **電源**: USB 供電

## ⚡ 重要説明

!!! warning "需要 USB 供電"
USB 插頭**必須連接**到有電源的 USB 端口，內部的 VGA 到 HDMI 轉換芯片才能工作。  
沒有電源時，HDMI 顯示器將顯示**黑屏**。

!!! important "僅單向轉換"
此線纜**僅轉換 VGA → HDMI**（VGA 設備到 HDMI 顯示器）。  
它**無法**反向工作（HDMI 到 VGA）。

## 故障排除

#### :material-chat-question:{ .faq } 為什麼使用此線纜時屏幕是黑的？ {: #vga-black-screen }

我們的轉換線**需要外部 USB 電源**。  
如果您看到黑屏，最常見的原因是**缺少電源**。

??? info "修復步驟"

    1. **連接USB電源**
        - 將USB連接器插入有電源的USB端口（如Mini-KVM的[可切換USB端口](/product/minikvm/usb-switch/)或直接插入計算機）。
        - 這為內部轉換芯片供電。

    2. **檢查分辨率設置**
       - 確保VGA源設備設置為支持的分辨率，如1280×1024或1024×768，頻率為60Hz。
       - 不支持的分辨率可能導致空白或扭曲的屏幕。

    3. **測試其他線纜或適配器**
       - 一些第三方VGA到HDMI適配器缺乏適當的功耗，可能會失敗。
       - 如果可能，嘗試第二根線纜來確認。

    > 還是卡住了？拍攝您完整設置的照片併發送給我們的支持團隊進行故障排除。
