# **包裝內容** | 預發佈套裝 | Openterface KVM-Go 系列

我們提供三種完整的工具包選項——**HDMI**、**DP** 或 **VGA** 版本。它們之間唯一的區別是核心產品本身。所有其他內容在三個選項中都是相同的。

每個工具包包含：

1. **核心產品**：Openterface KVM-GO（選擇 HDMI、DP 或 VGA 版本）
2. **工具包收納袋**：緊湊型便攜包
3. **USB 數據線**： 
   - 0.5米黑色 Type-C 轉 USB-A 數據線，配 Type-C 轉接頭
   - 2.5米橙色 Type-C 轉 Type-C 數據線，配 USB-A 轉接頭
4. **3D 打印保護帽**：定製保護帽，帶 microSD 存儲
5. **快速入門指南**
