# Openterface KVM-Go — 评测指南（工程样机）

## 概述

感谢您花时间测试我们即将推出的产品 **[Openterface KVM-Go](https://openterface.com/product/kvm-go/)**。

本单元为**工程样机**，我们的固件和软件正在快速迭代。您的反馈将直接帮助我们在量产前改进产品。

如果您在测试过程中遇到任何问题，请直接联系我们。**我们会在您录制视频前提供即时支持，帮助您解决问题。**

## 重要说明

### 样机免责声明

本设备为**工程样机**。固件和软件可能仍包含 bug 或不完整的功能。如果您遇到不稳定或影响工作流程的问题，请告知我们。我们将在量产版本发货前修复这些问题。

### 使用最新软件

为获得最佳性能和兼容性，请使用我们 GitHub Releases 页面上的 [Openterface 软件](https://openterface.com/app/overview/) **最新版本**。我们更新频繁，旧版本可能与您的样机固件不匹配。

## 已知问题与说明

> **注意：** 以下列出的所有问题都将在量产版本发布前得到解决。

### 表面温度

设备在使用过程中可能感觉温热甚至发烫。这是预期现象，因为样机使用了更高性能的芯片。

请注意：

* 所有温度均保持在安全运行范围内
* 内置**温度传感器**在软件中实时报告热状态
* 多日压力测试显示无稳定性问题

我们将在量产前继续优化散热性能。

### 软件分发

我们目前支持多个平台：

* **macOS 和 Windows**
  这些是最稳定的平台，推荐用于全功能测试。

* **Linux**
  请使用 **AppImage** 版本。
  `.deb` 和 `.rpm` 包可能因发行版不同而存在依赖问题。我们正在改进这些安装程序。

* **Android**
  **Google Play** 上提供可用版本，用于基本控制和监控。
  如果您想探索移动工作流程，欢迎尝试。

* **iPadOS**
  通过 **TestFlight** 提供。
  如果您想测试，请发送您的 **Apple ID**，我们将把您添加到测试者列表。

### 复制粘贴功能

您设备上的固件可能不包含我们最新的剪贴板修复。这些问题已在最新固件中解决。如需测试最新版本，可使用 [固件升级指南](firmware-upgrade.md) 进行更新。

### 拆解（可选）

如果您喜欢拆解，欢迎拆开本单元。

您的样机包含以下组件：

* **MS2130S** — 视频采集芯片
* **WCH CH32V208** — USB 键盘和鼠标模拟 MCU
* **标准硅胶导热膏** — 应用于此样机

我们目前正在测试使用**铝制组件**和**高性能导热硅脂**的升级散热方案。这些改进已通过内部测试，但由于样机库存有限，**尚未**包含在评测单元中。

您的单元仍使用**硅胶导热膏**，但散热性能仍在安全范围内。

### 高级功能（Mini-KVM 已支持，KVM-Go 即将推出）

KVM-Go 遵循与 Openterface Mini-KVM 相同的设计理念。多项高级功能正在积极开发中，但在当前样机中**尚不可用**：

* **自定义 EDID**
  Mini-KVM 允许通过我们的 QT 应用程序加载或修改 EDID 以解决兼容性问题。
  我们也正在将此功能引入 KVM-Go。

* **基于软件的 SD 卡切换**
  Mini-KVM 支持通过软件在其 USB-A 端口与 PC 之间切换。
  对于 KVM-Go，我们正在开发 micro-SD 插槽的类似软件切换功能，但您的固件中尚未启用。

我们希望您了解这些即将推出的功能，即使它们在您的单元上尚未激活。

### 开源承诺

是的，KVM-Go 将保持完全开源。硬件设计在量产最终确定后，我们将申请 OSHWA 认证（Open Source Hardware Association）。所有硬件设计文件和 STL 模型将上传至我们的 GitHub 仓库：[https://github.com/TechxArtisanStudio/Openterface_KVM-GO_Hardware](https://github.com/TechxArtisanStudio/Openterface_KVM-GO_Hardware)。
