# Обновление прошивки KVM-Go

## Обзор

KVM-Go использует чип CH32V208 от WCH для эмуляции клавиатуры и мыши. В настоящее время прошивка требует официального инструмента программирования WCH, доступного только для Windows. Поэтому обновления прошивки пока необходимо выполнять в системе Windows.

Мы активно работаем над кроссплатформенным собственным решением для обновления прошивки, которое будет интегрировано непосредственно в устройство. После готовности оно будет поддерживать обновления прошивки во всех основных ОС — без сторонних инструментов.

> **Примечание:** Эта процедура ручного обновления прошивки — временное решение для ранних опытных образцов. Для официальных серийных продуктов обновления прошивки будут бесшовно интегрированы в наше ПО, позволяя обновлять прошивку напрямую через приложение без сторонних инструментов и ручных процедур.

## Предварительные требования

Перед началом убедитесь, что у вас есть:

- Компьютер с Windows
- Установленный WCH ISP Tool
- Файл прошивки (формат `.hex`), готовый к прошивке

### Загрузка прошивки

Загрузите последний файл прошивки KVM-Go:

- [BLE_USB.hex](https://download.openterface.com/BLE_USB_20251209.hex) — Последняя прошивка для эмуляции клавиатуры и мыши KVM-Go (чип CH32V208)

Сохраните файл прошивки в легкодоступном месте на компьютере Windows перед обновлением.

### Загрузка WCH ISP Tool

Загрузите и установите [WCHISPTool](https://www.wch.cn/downloads/WCHISPTool_Setup_exe.html?spm=a2ty_o01.29997173.0.0.697cc921DiYWE0 "WCHISPTool") (только Windows).

Спасибо за терпение и поддержку!

## Пошаговая инструкция

### Шаг 1: Загрузите и откройте инструмент в Windows

Запустите WCH ISP Tool на компьютере Windows.

![Интерфейс WCH ISP Tool](https://assets.openterface.com/images/post/kvmgo-firmware/image-1763953443609.webp)

### Шаг 2: Подготовьте KVM-Go к прошивке

Для прошивки KVM-Go:

1. Убедитесь, что устройство выключено
2. Удерживайте кнопку при подключении к порту USB Type-C

**Совет:** Прошивать можно через любой порт, но порт «target» обычно стабильнее во время прошивки.

![Подключение и схема KVM-Go](https://assets.openterface.com/images/post/kvmgo-firmware/image-1763982667349.webp)

### Шаг 3: Выберите файл прошивки

При успешном подключении инструмент автоматически определит модель чипа (серия CH32V20X).

1. Нажмите кнопку «...» для выбора файла прошивки
2. Выберите файл прошивки `.hex`
3. **Важно:** Не забудьте отметить флажок рядом с файлом прошивки

![Обнаруженная модель чипа в WCH ISP Tool](https://assets.openterface.com/images/post/kvmgo-firmware/image-1763954642761.webp)

![Выбор файла прошивки](https://assets.openterface.com/images/post/kvmgo-firmware/image-1763954858836.webp)

![Выбранный файл прошивки с отмеченным флажком](https://assets.openterface.com/images/post/kvmgo-firmware/image-1763955070638.webp)

### Шаг 4: Снимите защиту текущей прошивки

Перед прошивкой новой прошивки необходимо снять защиту записи текущей:

1. Нажмите опцию «Deprotect» в инструменте
2. Кратко нажмите физическую кнопку на KVM-Go для входа в режим прошивки
3. Дождитесь завершения снятия защиты

![Опция Deprotect в инструменте](https://assets.openterface.com/images/post/kvmgo-firmware/image-1763955617253.webp)

![Нажатие кнопки KVM-Go для режима прошивки](https://assets.openterface.com/images/post/kvmgo-firmware/image-1763955858115.webp)

### Шаг 5: Загрузите и прошейте прошивку

После снятия защиты и выбора прошивки:

1. Нажмите кнопку «Download» в инструменте прошивки
2. Дождитесь завершения прошивки
3. Инструмент сообщит об успешной прошивке

![Процесс загрузки и прошивки](https://assets.openterface.com/images/post/kvmgo-firmware/image-1763956095046.webp)
