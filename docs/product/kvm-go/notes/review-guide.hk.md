# Openterface KVM-Go — 評測指南（工程樣機）

## 概述

感謝您花時間測試我們即將推出的產品 **[Openterface KVM-Go](https://openterface.com/product/kvm-go/)**。

本單元為**工程樣機**，我們的固件和軟件正在快速迭代。您的反饋將直接幫助我們在量產前改進產品。

如果您在測試過程中遇到任何問題，請直接聯繫我們。**我們會在您錄製視頻前提供即時支持，幫助您解決問題。**

## 重要説明

### 樣機免責聲明

本設備為**工程樣機**。固件和軟件可能仍包含 bug 或不完整的功能。如果您遇到不穩定或影響工作流程的問題，請告知我們。我們將在量產版本發貨前修復這些問題。

### 使用最新軟件

為獲得最佳性能和兼容性，請使用我們 GitHub Releases 頁面上的 [Openterface 軟件](https://openterface.com/app/overview/) **最新版本**。我們更新頻繁，舊版本可能與您的樣機固件不匹配。

## 已知問題與説明

> **注意：** 以下列出的所有問題都將在量產版本發佈前得到解決。

### 表面温度

設備在使用過程中可能感覺温熱甚至發燙。這是預期現象，因為樣機使用了更高性能的芯片。

請注意：

* 所有温度均保持在安全運行範圍內
* 內置**温度傳感器**在軟件中實時報告熱狀態
* 多日壓力測試顯示無穩定性問題

我們將在量產前繼續優化散熱性能。

### 軟件分發

我們目前支持多個平台：

* **macOS 和 Windows**
  這些是最穩定的平台，推薦用於全功能測試。

* **Linux**
  請使用 **AppImage** 版本。
  `.deb` 和 `.rpm` 包可能因發行版不同而存在依賴問題。我們正在改進這些安裝程序。

* **Android**
  **Google Play** 上提供可用版本，用於基本控制和監控。
  如果您想探索移動工作流程，歡迎嘗試。

* **iPadOS**
  通過 **TestFlight** 提供。
  如果您想測試，請發送您的 **Apple ID**，我們將把您添加到測試者列表。

### 複製粘貼功能

您設備上的固件可能不包含我們最新的剪貼板修復。這些問題已在最新固件中解決。如需測試最新版本，可使用 [固件升級指南](firmware-upgrade.md) 進行更新。

### 拆解（可選）

如果您喜歡拆解，歡迎拆開本單元。

您的樣機包含以下組件：

* **MS2130S** — 視頻採集芯片
* **WCH CH32V208** — USB 鍵盤和鼠標模擬 MCU
* **標準硅膠導熱膏** — 應用於此樣機

我們目前正在測試使用**鋁製組件**和**高性能導熱硅脂**的升級散熱方案。這些改進已通過內部測試，但由於樣機庫存有限，**尚未**包含在評測單元中。

您的單元仍使用**硅膠導熱膏**，但散熱性能仍在安全範圍內。

### 高級功能（Mini-KVM 已支持，KVM-Go 即將推出）

KVM-Go 遵循與 Openterface Mini-KVM 相同的設計理念。多項高級功能正在積極開發中，但在當前樣機中**尚不可用**：

* **自定義 EDID**
  Mini-KVM 允許通過我們的 QT 應用程序加載或修改 EDID 以解決兼容性問題。
  我們也正在將此功能引入 KVM-Go。

* **基於軟件的 SD 卡切換**
  Mini-KVM 支持通過軟件在其 USB-A 端口與 PC 之間切換。
  對於 KVM-Go，我們正在開發 micro-SD 插槽的類似軟件切換功能，但您的固件中尚未啓用。

我們希望您瞭解這些即將推出的功能，即使它們在您的單元上尚未激活。

### 開源承諾

是的，KVM-Go 將保持完全開源。硬件設計在量產最終確定後，我們將申請 OSHWA 認證（Open Source Hardware Association）。所有硬件設計文件和 STL 模型將上傳至我們的 GitHub 倉庫：[https://github.com/TechxArtisanStudio/Openterface_KVM-GO_Hardware](https://github.com/TechxArtisanStudio/Openterface_KVM-GO_Hardware)。
