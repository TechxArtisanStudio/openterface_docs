# **USB 端口切換指南** | Openterface Mini-KVM

mini-KVM 設備有一個 USB-A 2.0 端口，可以**連接到**主機或目標計算機，但**絕不能同時連接兩者**。

控制來自兩個開關：

- **硬件開關**：設備上的物理雙位撥動開關 ![Toggle Switch](https://assets.openterface.com/images/shell-icons/toggle-h-t.svg#only-light){:style="max-height:20px"} ![Toggle Switch](https://assets.openterface.com/images/shell-icons/toggle-h-t_1.svg#only-dark){:style="max-height:20px"}（向內=主機，向外=目標）。
- **軟件開關**：主機應用程序中的撥動按鈕，可立即將 USB 端口重定向到主機或目標。

## 操作狀態

USB-A 端口的連接取決於**硬件開關**和**軟件開關**的位置。下表總結了四種可能的狀態：

| **狀態** | **硬件開關** | **軟件開關** | **端口連接到** | **同步狀態**           |
| -------- | ------------ | ------------ | -------------- | ---------------------- |
| 1        | Host         | Host         | Host           | Synced                 |
| 2        | Target       | Target       | Target         | Synced                 |
| 3        | Target       | Host         | Host           | Out of Sync (→ Host)   |
| 4        | Host         | Target       | Target         | Out of Sync (→ Target) |

- **Synced**表示硬件和軟件設置匹配。
- **Out of Sync**表示軟件暫時覆蓋硬件開關，直到硬件開關再次移動。

硬件開關的任何手動移動都會更新軟件顯示並返回到同步狀態。

啟動時，設備默認為主機連接。軟件檢測硬件開關的位置並相應同步。

!!! warning "記住在切換開關前彈出閃存驅動器"
如果 USB 端口正在被閃存驅動器使用，請確保在切換開關以將端口的使用轉移到另一臺計算機之前彈出閃存驅動器。

??? note "如何在主機和目標設備之間共享 USB 閃存盤/磁盤？"
可以通過以下步驟在主機和目標之間傳輸文件：

    1. 當小黑開關設置為主機Type-C端口一側時，在主機上掛載USB閃存盤驅動器。
    2. 將文件複製到此掛載的驅動器上。
    3. 複製後，卸載驅動器而不物理拔出它。
    4. 將小黑開關翻轉到另一側。此操作將USB-A端口的連接切換到目標。
    5. 在目標設備上掛載USB閃存盤並從驅動器複製/移動文件，完成從主機到目標的文件傳輸過程。

    此方法也可以反向使用。

!!! Note "用戶指導" - **軟件開關優先級**：無論硬件開關位置如何，點擊軟件開關都會立即改變電路方向。

    - **硬件開關同步**：硬件開關的任何手動切換都會使其狀態與軟件開關對齊，從不同步狀態3或狀態4轉換到狀態1或狀態2。但是，這種同步不一定會改變實際的電路連接。

    - **硬件開關監控**：儘管硬件開關是物理的，但它由軟件監控，不直接控制電路方向。相反，軟件解釋開關位置並管理實際的電路切換。
