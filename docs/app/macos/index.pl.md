# Openterface MacOS

Wir arbeiten derzeit daran, detaillierte Dokumentacjaen dla unsere Oprogramowanie hinzuzufügen. Bitte schauen Sie bald wieder vorbei!

In der Zwischenzeit können Sie gerne unser Open-Source-**GitHub-Repository** erkien: [Openterface_MacOS](https://github.com/TechxArtisanStudio/Openterface_MacOS) dla den neuesten Code, Aktualizacje, Beispiele i um Probleme zu melden.

Sie können auch unserer [Discord-Community](/discord) beitreten, um sich z unserem Entwicklerteam i anderen großartigen Nutzern auszutauschen i o KVM-bezogene Themen zu diskutieren.

Für direkten Wsparcie können Sie uns gerne eine E-Mail an [support@openterface.com](mailto:support@openterface.com) senden.
