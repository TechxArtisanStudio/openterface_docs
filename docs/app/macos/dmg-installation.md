# macOS DMG Package Installation Guide

## 1. Download

To download the DMG package, follow these steps:

1. Open your web browser.
2. You can download the DMG package from either of these sources:
   - **Official website**: Visit [openterface.com](https://openterface.com) and go to the download section.
   - **GitHub releases**: Go to the [GitHub releases page](https://github.com/TechxArtisanStudio/Openterface_MacOS/releases) to find the latest version.
3. Find the download link for the DMG file.
4. Click the link to start the download. The file is usually saved in your `Downloads` folder.

## 2. Installation steps

Once the DMG file is downloaded, follow these steps to install the application:

1. Open the DMG file and drag the Openterface logo into the Applications folder.
2. A new window opens showing the contents of the DMG.
3. Drag the application icon into the Applications folder to install it.
![Installation1](https://assets.openterface.com/images/guide/macos-dmg-installation1.webp)
4. When copying is complete, you can eject the DMG by clicking the eject button next to it in the Finder sidebar.
5. Open the Openterface app from Launchpad.
![Installation1](https://assets.openterface.com/images/guide/macos-dmg-installation2.webp)

## 3. Security settings

If you see a security warning that the application "Openterface" cannot be opened, we are a fully open-source project and have passed malware checks from [Hybrid Analysis](https://www.hybrid-analysis.com/). You can bypass this warning by following these steps:
![SecurityWarning](https://assets.openterface.com/images/guide/macos-dmg-installation3-not-opened.webp)

1. Go to `System Settings` > `Privacy & Security`.
![privacysecurity](https://assets.openterface.com/images/guide/macos-dmg-installation4-privacysecurity.webp)
2. On the `General` tab, you may see a message that the app was blocked. Click `Open Anyway`.
3. You may be prompted for your administrator password. Enter it to allow the app to run.
![password](https://assets.openterface.com/images/guide/macos-dmg-installation5-password.webp)
4. After that, you should be able to open the application without issues.
![password](https://assets.openterface.com/images/guide/macos-dmg-installation6-opened.webp)

### Note

Only download applications from trusted sources to keep your system secure.
