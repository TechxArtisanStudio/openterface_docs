# macOS DMG 包安裝指南

## 1. 如何下載

要下載 DMG 包，請按照以下步驟操作：

1. 打開您的網頁瀏覽器。
2. 您可以從以下來源之一下載 DMG 包：
   - **官方網站**：訪問 [openterface.com](https://openterface.com) 並導航到下載部分。
   - **GitHub 發佈**：前往 [GitHub 發佈頁面](https://github.com/TechxArtisanStudio/Openterface_MacOS/releases) 查找最新版本。
3. 找到 DMG 文件的下載鏈接。
4. 點擊鏈接開始下載。文件通常會保存在您的 `Downloads` 文件夾中。

## 2. 安裝步驟

DMG 文件下載完成後，請按照以下步驟安裝應用程序：

1. 打開 DMG 文件並將 Openterface 徽標拖拽到應用程序文件夾。
2. 將打開一個新窗口，顯示 DMG 的內容。
3. 將應用程序圖標拖拽到應用程序文件夾中進行安裝。
![Installation1](https://assets.openterface.com/images/guide/macos-dmg-installation1.webp)
4. 複製完成後，您可以點擊 Finder 側邊欄中 DMG 旁邊的彈出按鈕來彈出 DMG。
5. 從啟動臺打開 Openterface 應用程序。
![Installation1](https://assets.openterface.com/images/guide/macos-dmg-installation2.webp)


## 3. 安全設置

如果您遇到安全警告，提示無法打開應用程序"Openterface"，請放心。我們是一個完全開源的項目，已成功通過 [Hybrid-Analysis](https://www.hybrid-analysis.com/) 進行的惡意軟件檢查。您可以通過以下步驟繞過此安全警告：
![SecurityWarning](https://assets.openterface.com/images/guide/macos-dmg-installation3-not-opened.webp)

1. 前往 `系統偏好設置` > `安全性與隱私`。
![privacysecurity](https://assets.openterface.com/images/guide/macos-dmg-installation4-privacysecurity.webp)
2. 在 `通用` 標籤頁中，您可能會看到應用程序被阻止的消息。點擊 `仍要打開` 按鈕。
3. 系統可能會提示您輸入管理員密碼。輸入密碼以允許應用程序運行。
![password](https://assets.openterface.com/images/guide/macos-dmg-installation5-password.webp)
macos-dmg-installation5-password
4. 之後，您應該能夠無任何問題地打開應用程序。
![password](https://assets.openterface.com/images/guide/macos-dmg-installation6-opened.webp)

### 注意

請確保僅從可信來源下載應用程序，以確保系統安全。
