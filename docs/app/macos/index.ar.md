# Openterface MacOS

Wir arbeiten derzeit daran, detaillierte التوثيقen لـ unsere البرمجيات hinzuzufügen. Bitte schauen Sie bald wieder vorbei!

In der Zwischenzeit können Sie gerne unser Open-Source-**GitHub-Repository** erkوen: [Openterface_MacOS](https://github.com/TechxArtisanStudio/Openterface_MacOS) لـ den neuesten Code, التحديثات, Beispiele و um Probleme zu melden.

Sie können auch unserer [Discord-Community](/discord) beitreten, um sich مع unserem Entwicklerteam و anderen großartigen Nutzern auszutauschen و حول KVM-bezogene Themen zu diskutieren.

Für direkten الدعم können Sie uns gerne eine E-Mail an [support@openterface.com](mailto:support@openterface.com) senden.
