## Grوlegende Host-App-Steuerungen

### 💻 Kompatibilität

-   **Host-البرمجيات**: Installieren Sie unsere Host-App لـ macOS, Windows أو Linux.
-   **Zielgeräte**: Keine Einrichtung erforderlich—verbinden Sie einfach jedes Gerät مع Videoausgabe (HDMI, VGA, etc.) و einem USB-Port لـ Tastatur/Maus-Steuerung. Funktioniert مع Windows, macOS, Linux, Android و iOS.

### 🖱 Maus-Modi

-   **Absoluter Modus**: Host-Maus mappt direkt auf die Zielbildschirmposition.
-   **Relativer Modus**: Bewegt den Zielcursor relativ zur aktuellen Position. Mit einer Tastenkombination beenden.

### ⌨️ Tastatur

Tastenanschläge vom Host werden direkt an das Ziel gesendet, wenn die App fokussiert ist.

### ⚙️ BIOS-Zugriff

Steuern Sie das Ziel-BIOS direkt.  
Häufige Tasten: F2 (Dell/Lenovo/ASUS), F10 (HP), Del (ASUS/Gigabyte/MSI), ⌥ (Apple).

### 🔊 Audio

Ziel-Audio streamt حول HDMI و spielt auf Ihrem Host-Computer.

### 🎥 Video

Betrachten Sie Ihren Zielbildschirm direkt in der App.

-   **Aktuelle Modelle**: Bis zu **1080p 30Hz** Anzeige in der App, مع Unterstützung لـ **4K 30Hz Eingang** حول HDMI.
-   **Andere Eingänge**: Kompatibel مع VGA, DVI, Micro HDMI و mehr bei Verwendung geeigneter Adapter.
-   **Zukünftige Modelle**: Höhere Auflösungen و Bildwiederholraten werden unterstützt, wenn neue الأجهزة-Versionen veröffentlicht werden.

### 🔄 Umschaltbare Ports

Einige Openterface-Geräte enthalten Ports, die **zwischen Host و Ziel umgeschaltet** werden können, wie USB 2.0-Ports أو micro-SD-Kartensteckplätze (auf kommenden Modellen).

-   **Einzelnutzung**: Nur eine Seite (Host أو Ziel) kann gleichzeitig auf den Port zugreifen.
-   **Umschaltmethoden**:
    -   **الأجهزة-Umschalter** — physischer Schalter am Gerät
    -   **البرمجيات-Button** — Steuerung حول die Host-App
-   **Wichtig**:
    -   Entfernen Sie Speichergeräte (USB-Laufwerke أو micro-SD-Karten) sicher vor dem Umschalten.
    -   Vermeiden Sie das Anschließen von Hochleistungsgeräten, um Instabilität أو Schäden zu verhindern.
    -   Siehe den [Umschaltbare Ports Guide](/usb-switch) لـ Details و Logikdiagramme.
