# Software

Openterface provides open-source applications for every product line. Download the app that matches your hardware and host platform, or build from source on GitHub.

---

## KVM Series

Control your **Mini-KVM**, **KVM-Go**, or **uConsole KVM Extension** from your host device. All apps deliver keyboard, video, and mouse pass-through over USB, with additional features like screen capture, OCR, and serial console.
