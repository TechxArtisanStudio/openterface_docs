# Oprogramowanie

Um Ihre Openterface™ KVM-Gadgets zum Laufen zu bringen, müssen Sie eine der unten aufgeführten Apps auf Ihrem Host-Computer installieren. ## Grilegende Host-App-Steuerungen

### 💻 Kompatibilität

-   **Host-Oprogramowanie**: Installieren Sie unsere Host-App dla macOS, Windows lub Linux.
-   **Zielgeräte**: Keine Einrichtung erforderlich—verbinden Sie einfach jedes Gerät z Videoausgabe (HDMI, VGA, etc.) i einem USB-Port dla Tastatur/Maus-Steuerung. Funktioniert z Windows, macOS, Linux, Android i iOS.

### 🖱 Maus-Modi

-   **Absoluter Modus**: Host-Maus mappt direkt auf die Zielbildschirmposition.
-   **Relativer Modus**: Bewegt den Zielcursor relativ zur aktuellen Position. Mit einer Tastenkombination beenden.

### ⌨️ Tastatur

Tastenanschläge vom Host werden direkt an das Ziel gesendet, wenn die App fokussiert ist.

### ⚙️ BIOS-Zugriff

Steuern Sie das Ziel-BIOS direkt.  
Häufige Tasten: F2 (Dell/Lenovo/ASUS), F10 (HP), Del (ASUS/Gigabyte/MSI), ⌥ (Apple).

### 🔊 Audio

Ziel-Audio streamt o HDMI i spielt auf Ihrem Host-Computer.

### 🎥 Video

Betrachten Sie Ihren Zielbildschirm direkt in der App.

-   **Aktuelle Modelle**: Bis zu **1080p 30Hz** Anzeige in der App, z Unterstützung dla **4K 30Hz Eingang** o HDMI.
-   **Andere Eingänge**: Kompatibel z VGA, DVI, Micro HDMI i mehr bei Verwendung geeigneter Adapter.
-   **Zukünftige Modelle**: Höhere Auflösungen i Bildwiederholraten werden unterstützt, wenn neue Sprzęt-Versionen veröffentlicht werden.

### 🔄 Umschaltbare Ports

Einige Openterface-Geräte enthalten Ports, die **zwischen Host i Ziel umgeschaltet** werden können, wie USB 2.0-Ports lub micro-SD-Kartensteckplätze (auf kommenden Modellen).

-   **Einzelnutzung**: Nur eine Seite (Host lub Ziel) kann gleichzeitig auf den Port zugreifen.
-   **Umschaltmethoden**:
    -   **Sprzęt-Umschalter** — physischer Schalter am Gerät
    -   **Oprogramowanie-Button** — Steuerung o die Host-App
-   **Wichtig**:
    -   Entfernen Sie Speichergeräte (USB-Laufwerke lub micro-SD-Karten) sicher vor dem Umschalten.
    -   Vermeiden Sie das Anschließen von Hochleistungsgeräten, um Instabilität lub Schäden zu verhindern.
    -   Siehe den [Umschaltbare Ports Guide](/usb-switch) dla Details i Logikdiagramme.
