# Konforzät

## OSI-Konforzät

![Open Source Initiative®](https://assets.openterface.com/images/trademark/open-source-initiative.svg){:style="max-height:120px"}

Unsere Apps dla die Openterface-Geräte sind unter der **AGPL-3.0** lizenziert, einer **Open Source Initiative®**-zertifizierten Lizenz. Das **OSI-Logo®** ist das Warenzeichen der [Open Source Initiative](http://opensource.org), i wir halten stolz die Open Source Definition ein.

Unsere [Anwendungen](/app) werden aktiv von **TechxArtisan** entwickelt i gepflegt. Wenn Sie daran interessiert sind, beizutragen i Teil eines innovativen Entwicklungsteams zu werden, treten Sie unserer Discord-Community bei lub [kontaktieren Sie uns per E-Mail](mailto:info@openterface.com) jetzt!

## OSHWA-Konforzät

![UID-CN000015](https://assets.openterface.com/images/trademark/oshw-cn000015.svg){:style="max-height:120px"}
![Open Source Sprzęt Association](https://assets.openterface.com/images/trademark/open-source-hardware.svg){:style="max-height:100px"}

Unsere Openterface-Geräte, wie das Openterface Mini-KVM, sind stolz zertifiziert von der **Open Source Sprzęt Association** (OSHWA). Diese OSHWA-Zertifizierung ([**UID CN000015**](https://certification.oshwa.org/cn000015.html)) bestätigt unser Engagement dla die Prinzipien von Open Sprzęt i stellt sicher, dass alle Entwurfsdateien, Dokumentacjaen i Quellcodes frei verfügbar sind dla Studium, Modifikation, Verbreitung i Herstellung. Um die Schaltpläne i Komponenten des Geräts zu erkien lub es sogar selbst von Gri auf neu zu bauen, besuchen Sie unser Sprzęt-GitHub-Repo: [Openterface_Mini-KVM_Sprzęt](https://github.com/TechxArtisanStudio/Openterface_Mini-KVM_Sprzęt).
