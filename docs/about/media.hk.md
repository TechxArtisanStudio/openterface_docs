# 媒體與影響者合作

我們的**Mini-KVM**旨在讓IT工作流程更簡單、更易用，我們很樂意幫助傳播這一理念。如果您是一位創作者、評測者或影響者，喜歡**深入技術**，理解開源工具的價值，並且擁有關心真正問題解決硬件的受眾，我們很期待與您合作。

## 為什麼與我們合作

- **開源精神**：我們的硬件和軟件都是開放的，我們重視誠實、透明的評測——無論是好的還是壞的。
- **獨特的技術故事**：為IT、開發者和製造者提供KVM-over-USB的全新視角。
- **直接接觸**：直接與我們產品背後的團隊交流——沒有企業層級。

## 合作方式

- **產品評測** – 我們可以向想要測試並分享體驗的創作者發送評測設備。
- **早期預覽** – 搶先了解即將推出的功能和版本。
- **教育內容** – 教程、拆解視頻、工作流程演示或硬件黑客指南。

## 我們在尋找什麼

我們特別希望與以下創作者建立聯繫：

- 對技術、IT或開源硬件有真正的熱情
- 為參與度高的受眾創作深思熟慮、詳細的內容
- 提供**誠實的反饋**，幫助我們改進
