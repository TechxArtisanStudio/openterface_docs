# 公眾假期

作為一家總部位於香港的公司，我們主要遵循**中國內地**和**香港**的公眾假期。這些日期我們的辦公室將休息。有關我們的常規工作時間，請參閲[關於我們](about-us.md)。

!!! info "假期期間的響應時間"
    在公眾假期期間，我們的響應可能比平時較慢。我們的技術與客户支持團隊通常會在 **48 小時**內回覆。

    敬請理解。我們致力於為客户提供優質的產品和服務，同時也支持團隊保持健康的工作與生活平衡。感謝您的耐心。
