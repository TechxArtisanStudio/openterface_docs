# 批量訂購與合作

## 批發價格

### Crowd Supply 合作伙伴關係
Openterface 產品僅通過 **Crowd Supply** 銷售，併為批量採購與經銷商提供**批發價格**。

### 批量訂購優勢
- **批量折扣**：大數量訂單可享具有競爭力的價格
- **流程順暢**：通過 Crowd Supply 高效下單與履約
- **質量保證**：同等高品質產品與企業級可靠性
