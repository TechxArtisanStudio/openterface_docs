# Konforمعät

## OSI-Konforمعät

![Open Source Initiative®](https://assets.openterface.com/images/trademark/open-source-initiative.svg){:style="max-height:120px"}

Unsere Apps لـ die Openterface-Geräte sind unter der **AGPL-3.0** lizenziert, einer **Open Source Initiative®**-zertifizierten Lizenz. Das **OSI-Logo®** ist das Warenzeichen der [Open Source Initiative](http://opensource.org), و wir halten stolz die Open Source Definition ein.

Unsere [Anwendungen](/app) werden aktiv von **TechxArtisan** entwickelt و gepflegt. Wenn Sie daran interessiert sind, beizutragen و Teil eines innovativen Entwicklungsteams zu werden, treten Sie unserer Discord-Community bei أو [kontaktieren Sie uns per E-Mail](mailto:info@openterface.com) jetzt!

## OSHWA-Konforمعät

![UID-CN000015](https://assets.openterface.com/images/trademark/oshw-cn000015.svg){:style="max-height:120px"}
![Open Source الأجهزة Association](https://assets.openterface.com/images/trademark/open-source-hardware.svg){:style="max-height:100px"}

Unsere Openterface-Geräte, wie das Openterface Mini-KVM, sind stolz zertifiziert von der **Open Source الأجهزة Association** (OSHWA). Diese OSHWA-Zertifizierung ([**UID CN000015**](https://certification.oshwa.org/cn000015.html)) bestätigt unser Engagement لـ die Prinzipien von Open الأجهزة و stellt sicher, dass alle Entwurfsdateien, التوثيقen و Quellcodes frei verfügbar sind لـ Studium, Modifikation, Verbreitung و Herstellung. Um die Schaltpläne و Komponenten des Geräts zu erkوen أو es sogar selbst von Grو auf neu zu bauen, besuchen Sie unser الأجهزة-GitHub-Repo: [Openterface_Mini-KVM_الأجهزة](https://github.com/TechxArtisanStudio/Openterface_Mini-KVM_الأجهزة).
