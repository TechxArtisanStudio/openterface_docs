# 合規

## OSI 合規

![Open Source Initiative®](https://assets.openterface.com/images/trademark/open-source-initiative.svg){:style="max-height:120px"}

我們的Openterface設備應用程序採用**AGPL-3.0**許可證，這是**開源倡議®**批准的許可證。**OSI標誌®**是[開源倡議](http://opensource.org)的商標，我們自豪地遵守開源定義。

我們的[應用程序](/app)由**TechxArtisan**積極開發和維護。如果您有興趣貢獻並想成為創新開發團隊的一員，請加入我們的Discord社區或立即[發郵件給我們](mailto:info@openterface.com)！

## OSHWA 合規

![UID-CN000015](https://assets.openterface.com/images/trademark/oshw-cn000015.svg){:style="max-height:120px"}
![Open Source Hardware Association](https://assets.openterface.com/images/trademark/open-source-hardware.svg){:style="max-height:100px"}

我們的Openterface設備，如Openterface Mini-KVM，自豪地獲得了**開源硬件協會**（OSHWA）的認證。這個OSHWA認證（[**UID CN000015**](https://certification.oshwa.org/cn000015.html)）確認了我們對開源硬件原則的承諾，確保所有設計文件、文檔和源代碼都可以免費用於研究、修改、分發和製造。要探索設備的原理圖和組件，甚至從頭開始自己構建，請查看我們的硬件GitHub倉庫：[Openterface_Mini-KVM_Hardware](https://github.com/TechxArtisanStudio/Openterface_Mini-KVM_Hardware)。
