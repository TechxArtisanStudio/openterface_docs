# 貢獻與支持

開源硬件讓每個人都能掌控、定製並真正理解自己的技術。構建它——並保持其開放——需要一個投入的社區。在你的幫助下，我們可以挑戰封閉系統，創造一個技術真正屬於用户的未來。

使用本頁查找最適合你的參與方式——無論是貢獻你的時間與技能，還是通過資金與倡導來支持項目。

---

## 快速開始

!!! tip "加入社區"
    在我們的 [Discord](/discord) 或 [Subreddit](/reddit) 與大家交流。

如果你有問題，請通過[電子郵件](mailto:info@openterface.com)與我們聯繫。

---

## 參與方式

### 📢 傳播聲量
在我們的[社區](/community)或社交媒體分享你的 Openterface 使用故事、照片或視頻，激勵更多人加入。

### 🛠️ 報告並修復問題
在我們的[應用](/app)中發現了 bug？請在相應的代碼倉庫提交報告。如果你會編程，fork 倉庫、修復問題並提交 pull request。

### 🎨 改進 UI/UX
幫助設計與打磨界面，讓我們的應用直觀、好用、令人愉悦。

### 📝 改進與翻譯文檔
幫助保持文檔準確且易讀：報告錯別字或過時信息，提出改進建議，並在我們的 GitHub 倉庫創建 issue。

貢獻翻譯，讓 Openterface 面向全球用户。

### 🤝 社區協作與管理
通過管理討論與幫助用户，維護一個友好、包容的社區環境。

### 💬 提出反饋
告訴我們哪些地方有效、哪些需要改進、以及你希望接下來看到什麼——歡迎在我們的[反饋頁面](/feedback)留言。

---

## 支持項目

每一次購買、分享與貢獻，都直接推動下一波創新：更強的功能、更完善的文檔，以及蓬勃發展的全球社區。

- **💻 購買我們的硬件**：支持我們最直接的方式是[購買一台 Openterface 設備](/buy-mini-kvm)。
- **👕 入手周邊**：在 [TxA 商店](/shop) 購買限量周邊，用行動支持開發。
- **🛠️ 加入使命**：開發者、創客與文檔貢獻者——查看我們的[貢獻指南](/contributing)，加入開發團隊。
- **📢 傳播聲量**：把 Openterface 分享給你的朋友、技術團隊或社區。
- **💬 提出反饋**：在[反饋頁面](/feedback)幫助我們確定路線圖優先級。
