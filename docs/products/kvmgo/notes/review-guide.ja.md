# Openterface KVM-Go — レビューガイド（エンジニアリングプロトタイプ）

## 概要

近日発売予定の製品 **[Openterface KVM-Go](https://openterface.com/products/kvmgo/)** をテストしていただき、ありがとうございます。

本ユニットは**エンジニアリングプロトタイプ**であり、ファームウェアとソフトウェアは急速に進化しています。皆様のフィードバックは量産前の製品改善に直接役立ちます。

テスト中に問題が発生した場合は、直接お問い合わせください。**動画撮影前に問題を解決できるよう、即座にサポートを提供します。**

## 重要な注意事項

### プロトタイプ免責事項

本デバイスは**エンジニアリングプロトタイプ**です。ファームウェアとソフトウェアにはまだバグや未完成の機能が含まれる可能性があります。不安定さやワークフローを妨げる問題が発生した場合はお知らせください。量産版出荷前に修正します。

### 最新ソフトウェアの使用

最高のパフォーマンスと互換性のため、GitHub Releases ページの [Openterface ソフトウェア](https://openterface.com/app/kvm/) **最新版**をご使用ください。頻繁に更新しており、古いバージョンはプロトタイプのファームウェアと一致しない場合があります。

## 既知の問題と説明

> **注意：** 以下に記載されたすべての問題は、量産版リリース前に対処されます。

### 表面温度

使用中、デバイスが温かい、または熱く感じる場合があります。プロトタイプは高性能チップを使用しているため、これは想定内です。

ご注意：

* すべての温度は安全な動作範囲内です
* 内蔵**温度センサー**がソフトウェアでリアルタイムの熱状態を報告します
* 複数日のストレステストで安定性の問題はありません

量産前に熱性能の改善を続けます。

### ソフトウェア配布

現在、複数のプラットフォームをサポートしています：

* **macOS と Windows**
  最も安定したプラットフォームで、全機能テストに推奨されます。

* **Linux**
  **AppImage** 版をご使用ください。
  `.deb` と `.rpm` パッケージはディストリビューションによって依存関係の問題がある場合があります。インストーラーの改善に取り組んでいます。

* **Android**
  **Google Play** で基本制御とモニタリング用の動作版が利用可能です。
  モバイルワークフローを探索したい場合はお試しください。

* **iPadOS**
  **TestFlight** 経由で利用可能です。
  テストを希望される場合は **Apple ID** をお送りください。テスターリストに追加します。

### コピー＆ペースト機能

お使いのユニットのファームウェアには、最新のクリップボード修正が含まれていない場合があります。これらの問題は最新ファームウェアで既に解決済みです。最新版をテストしたい場合は、[ファームウェアアップグレードガイド](firmware-upgrade.md)で更新できます。

### 分解（任意）

分解がお好きであれば、ユニットを分解していただいて構いません。

プロトタイプには以下のコンポーネントが含まれます：

* **MS2130S** — ビデオキャプチャチップ
* **WCH CH32V208** — USB キーボード・マウスエミュレーション MCU
* **標準シリコンサーマルペースト** — 本プロトタイプに適用

現在、**アルミ部品**と**高性能サーマルグリース**を使用したアップグレード熱ソリューションをテスト中です。これらの改善は内部テストを通過しましたが、プロトタイプ在庫が限られているため、レビューユニットには**まだ含まれていません**。

お使いのユニットは引き続き**シリコンペースト**を使用していますが、熱性能は安全範囲内です。

### 高度な機能（Mini-KVM でサポート、KVM-Go 近日対応）

KVM-Go は Openterface Mini-KVM と同じ設計思想に従います。複数の高度な機能が積極的に開発中ですが、現在のプロトタイプでは**まだ利用できません**：

* **カスタム EDID**
  Mini-KVM は QT アプリケーションで EDID の読み込み・変更が可能で、互換性問題を解決できます。
  この機能も KVM-Go に導入予定です。

* **ソフトウェアベースの SD カード切り替え**
  Mini-KVM はソフトウェアで USB-A ポートをホストと PC 間で切り替え可能です。
  KVM-Go では micro-SD スロット向けの同様のソフトウェア切り替えを開発中ですが、お使いのファームウェアではまだ有効化されていません。

これらの今後の機能について、ユニットでまだ有効でなくてもご認識いただければ幸いです。

### オープンソースへのコミットメント

はい、KVM-Go は完全オープンソースのままです。量産向けハードウェア設計が確定次第、OSHWA 認証（Open Source Hardware Association）を申請します。すべてのハードウェア設計ファイルと STL モデルは GitHub リポジトリにアップロードされます：[https://github.com/TechxArtisanStudio/Openterface_KVM-GO_Hardware](https://github.com/TechxArtisanStudio/Openterface_KVM-GO_Hardware)。
