# **Openterface uConsole KVM Extension Module v2**

![kvmext-v2-hero-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-hero-1.webp){:style="max-height:360px"}
![kvmext-v2-use-case-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-use-case-1.webp){:style="max-height:360px"}

<div class="slogan-highlight">
  <h2 class="slogan-text">Zmień swoje uConsole w przenośną konsolę KVM</h2>
  <div class="slogan-subtitle">KVM. Sieć. Karta SD. Jeden slot rozszerzeń.</div>

**Openterface uConsole KVM Extension Module v2** wpina się w slot rozszerzeń uConsole, zamieniając go w przenośną **konsolę KVM**, **terminal debugowania sieci** oraz **moduł narzędziowy do obsługi kart SD**. Uzyskaj bezpośrednie **wejście HDMI**, **sterowanie klawiaturą i myszą USB HID**, **rozszerzenie Ethernet** (w zestawie karty 100M i 1000M), **odczyt/zapis karty SD** oraz **współdzielone przełączanie USB 2.0** — zasilane bezpośrednio ze slotu, bez zewnętrznego zasilacza.

Stworzony dla profesjonalistów IT, twórców homelabów, programistów systemów wbudowanych i techników terenowych, którzy potrzebują dostępu na poziomie BIOS-u, konserwacji sieci i tworzenia obrazów SD bez konieczności noszenia dodatkowych monitorów, klawiatur czy czytników kart.

!!! note "Pojedynczy SKU — obie karty sieciowe w zestawie"
    W zestawie Extension Module v2 znajdują się **obie** karty Ethernet 100M i 1000M. To jeden produkt, a nie dwie oddzielne wersje sieciowe. Zobacz [Opcje zakupu](/products/kvmext/purchase-options/) i [Przewodnik po Ethernet](/products/kvmext/ethernet/).
