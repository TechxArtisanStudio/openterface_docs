# **Co znajduje się w pudełku** | Moduł rozszerzeń v2

![kvmext-v2-box-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-1.webp){:style="max-width:480px"}
![kvmext-v2-box-2](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-2.webp){:style="max-width:480px"}

**Główne komponenty**

- Płyta Openterface uConsole KVM Extension Module v2 (77,3 × 34,7 mm)
- **Karta Ethernet 100M** — współpracuje ze wszystkimi płytami bazowymi uConsole
- **Karta Ethernet 1000M** — wymaga [HackerGadgets uConsole Upgrade Kit](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole) do obsługi gigabitu
- Zaślepka gniazda rozszerzeń

!!! note "Pojedynczy SKU"
    Obie karty sieciowe są dołączone do każdego pudełka. Nie musisz wybierać wersji sieciowej przy zakupie — zobacz [Przewodnik Ethernet](/products/kvmext/ethernet/), aby dowiedzieć się, którą kartę zainstalować.

!!! warning "Nie jest dołączone"
    Urządzenie ClockworkPi **uConsole** nie jest dołączone. Zdjęcia produktu służą wyłącznie celom poglądowym.

## Opcje zakupu

| Opcja | Zawartość |
|--------|----------|
| **Tylko Extension v2** | Moduł rozszerzeń v2 + obie karty Ethernet + zaślepka gniazda |
| **Extension v2 + pakiet Upgrade Kit** | Wszystko powyżej + **HackerGadgets uConsole Upgrade Kit** (gotowy do Ethernetu gigabitowego) |
