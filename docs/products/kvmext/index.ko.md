# **Openterface uConsole KVM 확장 모듈 v2**

**Openterface uConsole KVM 확장 모듈 v2**는 uConsole 확장 슬롯에 연결하여 휴대용 **KVM 콘솔**, **네트워크 디버그 터미널**, **SD 카드 유틸리티 모듈**로 변환해 줍니다. 외부 어댑터 없이 슬롯에서 직접 전원을 공급받아 직접 **HDMI 입력**, **USB HID 키보드 및 마우스 제어**, **이더넷 확장**(100M 및 1000M 카드 포함), **SD 카드 읽기/쓰기**, **USB 2.0 공유 스위칭**을 이용할 수 있습니다.

추가 모니터, 키보드 또는 카드 리더를 휴대할 필요 없이 BIOS 수준 액세스, 네트워크 유지보수 및 SD 이미징이 필요한 IT 전문가, 홈랩 빌더, 임베디드 개발자 및 현장 기술자를 위해 제작되었습니다.

!!! note "단일 SKU — 두 가지 네트워크 카드 모두 포함"
    Extension Module v2는 100M 및 1000M 이더넷 카드 **모두**가 박스에 포함되어 출고됩니다. 이는 두 개의 별도 네트워크 버전이 아닌 하나의 제품입니다. [구매 옵션](/products/kvmext/purchase-options/) 및 [이더넷 가이드](/products/kvmext/ethernet/)를 참조하세요.
