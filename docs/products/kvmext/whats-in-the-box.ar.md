# **محتويات العلبة** | وحدة الامتداد v2

![kvmext-v2-box-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-1.webp){:style="max-width:480px"}
![kvmext-v2-box-2](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-2.webp){:style="max-width:480px"}

**المكونات الأساسية**

- لوحة وحدة امتداد Openterface uConsole KVM الإصدار v2 (77.3 × 34.7 مم)
- **بطاقة Ethernet 100M** — تعمل مع جميع اللوحات الأساسية لـ uConsole
- **بطاقة Ethernet 1000M** — تتطلب [طرقية ترقية HackerGadgets uConsole](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole) للعمل بسرعة جيجابت
- غطاء فتحة التوسعة

!!! note "SKU واحد"
    كلتا بطاقتي الشبكة مشمولتان في كل علبة. لا تحتاج إلى اختيار إصدار الشبكة عند الشراء — راجع [دليل Ethernet](/products/kvmext/ethernet/) لمعرفة البطاقة التي يجب تركيبها.

!!! warning "غير مشمول"
    جهاز **uConsole من ClockworkPi** غير مشمول. صور المنتج هي لأغراض العرض فقط.
