# **Openterface uConsole KVM Extension Module v2**

![kvmext-v2-hero-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-hero-1.webp){:style="max-height:360px"}

<div class="slogan-highlight">
  <h2 class="slogan-text">Trasforma il tuo uConsole in una console KVM portatile</h2>
  <div class="slogan-subtitle">KVM. Rete. Scheda SD. Uno slot di espansione.</div>

L'**Openterface uConsole KVM Extension Module v2** si collega allo slot di espansione del tuo uConsole e lo trasforma in una **console KVM** portatile, un **terminale di debug di rete** e un **modulo utility per schede SD**. Ottieni **ingresso HDMI** diretto, **controllo tastiera e mouse USB HID**, **espansione Ethernet** (schede 100M e 1000M incluse), **lettura/scrittura di schede SD** e **commutazione condivisa USB 2.0** — alimentato direttamente dallo slot senza adattatore esterno.

Progettato per professionisti IT, appassionati di homelab, sviluppatori embedded e tecnici sul campo che necessitano di accesso a livello BIOS, manutenzione di rete e imaging di schede SD senza dover trasportare monitor, tastiere o lettori di schede aggiuntivi.

!!! note "SKU singolo — entrambe le schede di rete incluse"
    Extension Module v2 viene fornito con **entrambe** le schede Ethernet 100M e 1000M nella confezione. È un unico prodotto, non due versioni di rete separate. Vedi [Opzioni di acquisto](/products/kvmext/purchase-options/) e [Guida Ethernet](/products/kvmext/ethernet/).
