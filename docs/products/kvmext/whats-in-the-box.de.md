# **Lieferumfang** | Erweiterungsmodul v2

![kvmext-v2-box-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-1.webp){:style="max-width:480px"}
![kvmext-v2-box-2](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-2.webp){:style="max-width:480px"}

**Kernkomponenten**

- Openterface uConsole KVM-Erweiterungsmodul v2 Platine (77,3 × 34,7 mm)
- **100M-Ethernet-Karte** — funktioniert mit allen uConsole-Basisplatinen
- **1000M-Ethernet-Karte** — erfordert das [HackerGadgets uConsole Upgrade-Kit](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole) für Gigabit-Betrieb
- Erweiterungs-Slotabdeckung

!!! note "Einzelne SKU"
    Beide Netzwerkkarten sind in jeder Packung enthalten. Sie müssen beim Checkout keine Netzwerkversion auswählen — siehe [Ethernet-Anleitung](/products/kvmext/ethernet/) für die Auswahl der zu installierenden Karte.

!!! warning "Nicht enthalten"
    Das ClockworkPi **uConsole-Gerät** ist nicht enthalten. Produktfotos dienen nur zur Veranschaulichung.
