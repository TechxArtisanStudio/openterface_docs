# **Настройка программного обеспечения** | Модуль расширения v2

## Обзор установки

Главное приложение Openterface позволяет вашему uConsole работать в качестве интерфейса KVM с захватом HDMI, управлением USB HID, **переключением SD-карт** и **совместным использованием USB-порта** между хостом и целевым устройством.

!!! note "Требования"
    - **uConsole (хост)**: требуется приложение Openterface QT
    - **Целевое устройство**: приложение не требуется — поддерживаются Windows, macOS, Linux, Android, iOS для KVM
    - **Видео**: стандартный кабель HDMI; активные преобразователи поддерживают VGA, DP и другие форматы
    - **Рекомендуемый бэкенд**: **GStreamer** для наилучшей производительности GPU на arm64 (в Kali Linux поддержка GStreamer может быть ограничена)

## Способы установки

### **Вариант 1: Релизы на GitHub (рекомендуется для arm64)**

1. Посетите [релизы Openterface_QT](https://github.com/TechxArtisanStudio/Openterface_QT/releases).
2. Загрузите последний `.deb` для **arm64** (например, `openterfaceqt_*_arm64.deb`).
3. Установите:
    ```bash
    sudo apt install ./openterfaceqt_*_arm64.deb
    ```

### **Вариант 2: Flatpak**

Следуйте [руководству по установке Flatpak](https://github.com/TechxArtisanStudio/Openterface_QT/blob/main/docs/flatpak_installation.md).

### **Вариант 3: Сообщественный репозиторий (ClockworkPi Bookworm)**

Поддерживается Rex для образов ClockworkPi:

1. **Добавьте репозиторий**:
    ```bash
    wget -q -O- https://raw.githubusercontent.com/ak-rex/ClockworkPi-apt/main/bookworm/KEY.gpg | gpg --dearmor | sudo tee /etc/apt/trusted.gpg.d/ak-rex.gpg
    sudo add-apt-repository -y "deb [arch=arm64] https://raw.githubusercontent.com/ak-rex/ClockworkPi-apt/main/bookworm stable main"
    ```

2. **Установите**:
    ```bash
    sudo apt update
    sudo apt install openterfaceqt
    ```

!!! warning "Примечания к репозиторию"
    Команды требуют `sudo`. Репозиторий предназначен для пакетов arm64 Bookworm — перед установкой проверьте совместимость с вашей ОС uConsole.

## Важные напоминания

!!! tip "Питание и первоначальная настройка"
    - Держите uConsole заряженным или подключенным к стабильному источнику питания — низкий заряд батареи может вызвать проблемы с подключением.
    - Если управление с клавиатуры/мыши не работает с первой попытки:
        1. Полностью выключите uConsole.
        2. Подождите не менее 10 секунд.
        3. Включите и повторите попытку.

!!! tip "Скорость последовательной передачи данных"
    Установите скорость передачи данных **9600** для последовательного использования — uConsole может не стабильно поддерживать 115200.

## Использование

### **Запуск сеанса KVM**

1. Запустите Openterface QT на вашем uConsole.
2. Приложение автоматически обнаружит Модуль расширения v2.
3. Подключите целевое устройство через HDMI и USB.
4. Используйте клавиатуру и трекбол uConsole для управления целевым устройством.

### **Возможности управления**

- **Клавиатура**: полная эмуляция, включая мультимедийные клавиши
- **Мышь**: абсолютное и относительное позиционирование
- **Аудио**: передача аудио через HDMI на динамики uConsole
- **Передача текста**: вставка имен пользователей, паролей и фрагментов в виде симулированных нажатий клавиш
- **Переключение USB**: общий доступ к USB-накопителю между uConsole и целевым устройством через главное приложение — см. [Подключение к целевому устройству](/products/kvmext/connect-to-target/)
- **Переключение SD-карт**: монтирование SD-карты на хост или целевое устройство через главное приложение — см. [Руководство по SD-картам](/products/kvmext/sd-card/)

### **Устранение проблем с установкой**

Если приложение сложно установить или мышь/клавиатура не работают:

- Убедитесь, что вы установили сборку **arm64** на вашем uConsole CM4/модуле
- Присоединяйтесь к [Discord](https://openterface.com/discord) для получения помощи в реальном времени
- Сообщайте о проблемах на [GitHub — Openterface_QT](https://github.com/TechxArtisanStudio/Openterface_QT/issues)
