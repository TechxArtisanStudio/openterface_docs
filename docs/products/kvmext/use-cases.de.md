# Anwendungsfälle | Extension Module v2

Das Extension Module v2 verwandelt Ihre uConsole in eine **tragbare KVM-Konsole**, ein **Netzwerk-Terminal** und ein **SD-Dienstprogramm** – ideal, wenn Sie volle Kontrolle benötigen, ohne auf einen Crash Cart angewiesen zu sein.

![kvmext-v2-use-case-3](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-use-case-3.webp){:style="max-height:360px"}

## IT- und Netzwerk-Wartung

Greifen Sie direkt von Ihrer uConsole auf Server, Router und headless Appliances zu. Nutzen Sie **KVM** für BIOS- und Konsolen-Zugriff und **Ethernet** für SSH, Web-Management und Log-Erfassung – alles in einem taschentauglichen Gerät.

## Embedded-Entwicklung

Testen und debuggen Sie SBCs, Entwicklungsboards und Custom Hardware, ohne externe Monitore aufbauen zu müssen. Flashen Sie Images über die **SD-Karte**, steuern Sie Boot-Menüs über **KVM** und iterieren Sie im Labor oder auf der Werkbank.

## Außendienst und Diagnostik

Ein kompaktes KVM für unterwegs für Techniker, die an mehreren Standorten arbeiten. Betreten Sie eine Serverreihe im Rechenzentrum oder einen Kundenstandort mit nur einer einzigen uConsole, anstatt Monitor, Tastatur und Kartenleser mitzuführen.

## Netzwerk-Fehlerbehebung

Wenn eine IP-Konnektivität verfügbar ist, nutzen Sie die Ethernet-Karte für Wartungsaufgaben. Wenn nicht, bietet **HDMI + USB HID** dennoch die volle Headless-Steuerung.

## SD-Karten-Workflows

Schreiben Sie OS-Images, verschieben Sie Logs und übertragen Sie Dateien direkt von der uConsole – kein externer Kartenleser erforderlich. Wechseln Sie den SD-Zugriff in der Openterface App zwischen Host und Target.

## Homelab und Maker

Konfigurieren Sie Headless-NAS-Nodes, Proxmox-Hosts und Labor-Equipment von einem Gerät, das Sie ohnehin dabei haben. Das Extension Module v2 erweitert Ihre täglich genutzte uConsole um KVM und nützliche Dienstprogramme.
