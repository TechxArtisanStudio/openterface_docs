# Mises à jour produit | Module d'extension v2

Dernières actualités et notes de version pour le **module d'extension KVM Openterface uConsole v2**.

## 2026-06-22 — Le module d'extension v2 est désormais expédié

Le **module d'extension v2** est disponible sur la [boutique TechxArtisan](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole).

Nouveautés par rapport au module de première génération :

- **Double Ethernet** — Cartes 100M et 1000M incluses dans chaque boîte
- **Lecture/écriture de carte SD** — Création d'images et transfert de fichiers depuis votre uConsole
- Sortie **1080p @ 60 Hz** avec une latence **&lt; 70 ms**
- Carte **77,3 × 34,7 mm** avec commutation partagée USB 2.0

Lisez l'annonce complète sur [Openterface News](https://news.openterface.com/product/uconsole-kvm-extension/2026-06-22-extension-module-v2-launch/).
