# Produktupdates | Erweiterungsmodul v2

Neueste Nachrichten und Versionshinweise für das **Openterface uConsole KVM-Erweiterungsmodul v2**.

## 2026-06-22 — Erweiterungsmodul v2 wird jetzt ausgeliefert

Das **Erweiterungsmodul v2** ist im [TechxArtisan Shop](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole) erhältlich.

Neuerungen gegenüber der ersten Modulgeneration:

- **Duales Ethernet** — 100M- und 1000M-Karten in jeder Verpackung enthalten
- **SD-Karten-Lese-/Schreibzugriff** — Image-Erstellung und Dateiübertragung von Ihrer uConsole
- **1080p @ 60 Hz** Ausgabe mit **&lt; 70 ms** Latenz
- **77,3 × 34,7 mm** Platine mit gemeinsam genutztem USB 2.0-Switching

Lesen Sie die vollständige Ankündigung auf [Openterface News](https://news.openterface.com/products/kvmext/2026-06-22-extension-module-v2-launch/).
