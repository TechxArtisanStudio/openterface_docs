# 製品アップデート | Extension Module v2

**Openterface uConsole KVM Extension Module v2** の最新ニュースとリリースノート。

## 2026-06-22 — Extension Module v2 出荷開始

**Extension Module v2** は [TechxArtisan Shop](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole) で入手可能です。

初代モジュールからの新機能:

- **デュアルイーサネット** — 100M および 1000M カードを各ボックスに同梱
- **SDカードの読み書き** — uConsole からのイメージ作成およびファイル転送
- **1080p @ 60 Hz** 出力、**&lt; 70 ms** の低遅延
- **77.3 × 34.7 mm** のボード、USB 2.0 共有スイッチング搭載

詳細な発表は [Openterface News](https://news.openterface.com/product/uconsole-kvm-extension/2026-06-22-extension-module-v2-launch/) をご覧ください。
