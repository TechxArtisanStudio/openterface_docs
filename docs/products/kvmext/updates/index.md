# Product Updates | Extension Module v2

Latest news and release notes for **Openterface uConsole KVM Extension Module v2**.

## 2026-06-22 — Extension Module v2 now shipping

**Extension Module v2** is available from the [TechxArtisan Shop](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole).

What's new vs the first-generation module:

- **Dual Ethernet** — 100M and 1000M cards included in every box
- **SD card read/write** — imaging and file transfer from your uConsole
- **1080p @ 60 Hz** output with **&lt; 70 ms** latency
- **77.3 × 34.7 mm** board with USB 2.0 shared switching

Read the full announcement on [Openterface News](https://news.openterface.com/product/uconsole-kvm-extension/2026-06-22-extension-module-v2-launch/).
