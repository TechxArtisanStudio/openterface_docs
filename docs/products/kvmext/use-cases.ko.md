# 사용 사례 | 확장 모듈 v2

확장 모듈 v2는 uConsole을 **휴대용 KVM 콘솔**, **네트워크 터미널**, **SD 유틸리티**로 변환하여 — 크래시 카트 없이 완전한 제어가 필요할 때 이상적입니다.

![kvmext-v2-use-case-3](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-use-case-3.webp){:style="max-height:360px"}

## IT 및 네트워크 유지보수

서버, 라우터, 헤드리스 장비를 uConsole에서 직접 접속하세요. **KVM**으로 BIOS 및 콘솔 접속을, **Ethernet**으로 SSH, 웹 관리, 로그 캡처를 — 하나의 휴대 가능한 기기로 사용하세요.

## 임베디드 개발

외부 모니터를 설정하지 않고도 SBC, 개발 보드, 커스텀 하드웨어를 테스트하고 디버그하세요. **SD 카드**로 이미지를 플래시하고, **KVM**으로 부트 메뉴를 제어하며, 랩이나 작업대에서 반복 작업을 수행하세요.

## 현장 서비스 및 진단

여러 사이트를 오가며 작업하는 기술자를 위한 컴팩트한 이동형 KVM. 데이터센터 열이나 클라이언트 사이트에 모니터, 키보드, 카드 리더 대신 uConsole 하나만 가지고 들어가세요.

## 네트워크 문제 해결

IP 연결이 가능한 경우, 유지보수 작업에 Ethernet 카드를 사용하세요. 연결이 불가능한 경우에도 **HDMI + USB HID**로 완전한 헤드리스 제어가 가능합니다.

## SD 카드 워크플로우

OS 이미지를 쓰고, 로그를 이동하고, 파일을 외부 리더 없이 uConsole에서 직접 전송하세요. Openterface 앱에서 호스트와 타겟 간 SD 액세스를 전환하세요.

## 홈랩 및 메이커

이미 가지고 다니는 기기로 헤드리스 NAS 노드, Proxmox 호스트, 랩 장비를 구성하세요. 확장 모듈 v2는 일상적으로 사용하는 uConsole에 KVM과 유틸리티를 추가합니다.
