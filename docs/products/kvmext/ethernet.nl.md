# **Ethernet-gids** | Extension Module v2

Extension Module v2 bevat **zowel** een 100M- als een 1000M-Ethernetkaart in de doos. Installeer **één** kaart tijdens de hardware-installatie — u koopt geen afzonderlijke netwerkversies.

![kvmext-v2-pcb-detail](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-pcb-detail.webp){:style="max-height:320px"}

## Welke kaart moet ik gebruiken?

| Kaart | Compatibiliteit | Het beste voor |
|------|---------------|----------|
| **100M Ethernet** | Alle uConsole-basisborden | Universeel gebruik, SSH, webinterface, logregistratie |
| **1000M Ethernet** | Vereist **HackerGadgets uConsole Upgrade Kit** | Gigabit-netwerken, snellere overdrachten |

!!! tip "Niet zeker?"
    Begin met de **100M**-kaart, tenzij u de Upgrade Kit al hebt geïnstalleerd en bevestigd dat deze werkt.

## Aankoopopties & Upgrade Kit

| Optie | Ethernet-mogelijkheden |
|--------|---------------------|
| **Alleen Extension v2** | 100M direct klaar voor gebruik; 1000M-kaart inbegrepen, maar Upgrade Kit nodig voor gigabit |
| **Extension v2 + Upgrade Kit bundel** | Gigabit-klaar met meegeleverde Upgrade Kit |

Volledige vergelijking: [Aankoopopties](/products/kvmext/purchase-options/)

Meer informatie over de Upgrade Kit van **HackerGadgets** (gelinkt vanaf onze [TechxArtisan Shop-vermelding](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole)).

## Installatie

1. Voltooi de stappen 1–2 van [Hardware-installatie](/products/kvmext/hardware-installation/) (uitschakelen, bestaande module verwijderen).
2. Plaats uw gekozen Ethernetkaart op Extension Module v2 volgens het module-ontwerp.
3. Installeer het hoofdbord in de uitbreidingssleuf en zet de schroeven vast.
4. Sluit een Ethernetkabel aan op uw doelapparaat of netwerk.

## Gebruiksscenario's

- **SSH** naar headless servers terwijl u ze via KVM bekijkt
- **Webbeheer** voor routers, switches en apparaten
- **Logregistratie** en netwerkonderhoud in het veld
- Gecombineerde **KVM + netwerk**-workflow zonder extra adapters
