## Optionen vergleichen

| | **Option 1: Extension v2 Only** | **Option 2: Extension v2 + Upgrade Kit Bundle** |
|---|--------------------------------|--------------------------------------------------|
| **Hauptprodukt** | Openterface uConsole KVM Extension Module v2 | Extension Module v2 + **HackerGadgets uConsole Upgrade Kit** |
| **Netzwerkkarten** | Sowohl 100M als auch 1000M im Lieferumfang enthalten | Sowohl 100M als auch 1000M im Lieferumfang enthalten |
| **100M Ethernet** | Funktioniert mit allen uConsole Base Boards | Funktioniert mit allen uConsole Base Boards |
| **1000M Ethernet** | Enthalten, benötigt Upgrade Kit für Gigabit | Gigabit-fähig mit enthaltenem Upgrade Kit |
| **Am besten geeignet für** | Nutzer, die das Upgrade Kit bereits besitzen oder nur 100M benötigen | Nutzer, die Gigabit benötigen und das Upgrade Kit nicht besitzen |

!!! note "Einzelne SKU — beide Netzwerkkarten immer enthalten"
    Jede Box enthält **beide** Ethernet-Karten. Das Bundle fügt das für den 1000M-Gigabit-Betrieb benötigte **Upgrade Kit** hinzu — keine andere Netzwerk-SKU.
