# **하드웨어 설치** | 확장 모듈 v2

## 개요

확장 모듈 v2는 uConsole **확장 슬롯**에 장착됩니다 (4G/LTE 모듈이 사용하는 동일한 슬롯). 4G 또는 LTE 모듈과 동시에 사용할 수 없습니다 — 셀룰러 **또는** KVM 기능 중 하나를 선택하세요.

## 필요한 항목

- 설치 전 [패키지 내용물](/products/kvmext/whats-in-the-box/) 확인 완료
- Openterface 확장 모듈 v2 보드
- **이더넷 카드 1개** (100M 또는 1000M — [이더넷 가이드](/products/kvmext/ethernet/) 참조)
- 확장 슬롯 커버 (포함됨)
- 장착 나사용 육각 스크루드라이버
- ESD 보호 장비 (손목 스트랩 또는 접지된 표면) — 권장

## 설치 단계

### **1. 전원 끄기**

uConsole을 종료하고 모든 전원과 케이블을 분리하세요.

### **2. 기존 모듈 제거**

4G/LTE 또는 다른 확장 모듈이 설치되어 있는 경우:

- 육각 스크루드라이버를 사용하여 두 개의 장착 나사를 제거하세요.
- 스프링 접점을 구부리지 않도록 보드를 **위로 똑바로** 들어올리세요.
- 나중에 재설치할 계획이라면 원래 모듈과 나사를 안전하게 보관하세요.

### **3. 이더넷 카드 선택**

메인 보드를 장착하기 전에 설치할 카드를 결정하세요:

| 카드 | 사용 시점 |
|------|-------------|
| **100M** | 모든 uConsole 베이스 보드 — 범용 호환성 |
| **1000M** | **HackerGadgets uConsole 업그레이드 키트**가 있고 기가비트가 필요한 경우에만 |

자세한 내용은 [이더넷 가이드](/products/kvmext/ethernet/)를 참조하세요.

### **4. 확장 모듈 v2 설치**

![kvmext-v2-pcb-detail](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-pcb-detail.webp){:style="max-height:240px"}

- 확장 모듈 v2를 확장 슬롯에 단단히 장착하세요.
- 스프링 접점이 모든 패드에 고르게 정렬되었는지 확인하세요.
- 장착 나사를 다시 삽입하고 **살짝** 조이세요 — 너무 세게 조이지 마세요.

### **5. 설치 확인**

보드는 눈에 띄는 흔들림 없이 **평평하고 안정적으로** 자리 잡아야 합니다. 모든 스프링 접점이 고르게 눌려야 합니다.

### **6. 확장 슬롯 커버 설치**

모듈을 보호하고 uConsole의 외관을 유지하기 위해 확장 슬롯 커버를 다시 설치하세요.

??? note "확장 슬롯 커버의 텍스트 방향"
    커버의 텍스트는 특정 각도에서 보았을 때 거꾸로 보일 수 있습니다. 이 텍스트는 uConsole을 들고 위에서 포트를 바라보는 자연스러운 사용 자세에서 읽을 수 있도록 방향이 맞춰져 있습니다.
