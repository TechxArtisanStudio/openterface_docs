# **Что в коробке** | Модуль расширения v2

![kvmext-v2-box-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-1.webp){:style="max-width:480px"}
![kvmext-v2-box-2](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-2.webp){:style="max-width:480px"}

**Основные компоненты**

- Плата Openterface uConsole KVM Extension Module v2 (77.3 × 34.7 мм)
- **Ethernet-карта 100M** — работает со всеми базовыми платами uConsole
- **Ethernet-карта 1000M** — требует [HackerGadgets uConsole Upgrade Kit](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole) для работы в гигабитном режиме
- Заглушка слота расширения

!!! note "Единый артикул"
    Обе сетевые карты включены в каждую коробку. Вам не нужно выбирать версию сети при оформлении заказа — см. [Руководство по Ethernet](/products/kvmext/ethernet/), чтобы узнать, какую карту установить.

!!! warning "Не входит в комплект"
    Устройство **uConsole от ClockworkPi** не входит в комплект. Фотографии продукта приведены исключительно в демонстрационных целях.
