# **Cosa c'è nella scatola** | Modulo di Estensione v2

![kvmext-v2-box-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-1.webp){:style="max-width:480px"}
![kvmext-v2-box-2](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-2.webp){:style="max-width:480px"}

**Componenti principali**

- Scheda Openterface uConsole KVM Extension Module v2 (77.3 × 34.7 mm)
- **Scheda Ethernet 100M** — funziona con tutte le schede base uConsole
- **Scheda Ethernet 1000M** — richiede l'[HackerGadgets uConsole Upgrade Kit](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole) per il funzionamento in gigabit
- Coperchio dello slot di espansione

!!! note "SKU unico"
    Entrambe le schede di rete sono incluse in ogni confezione. Non è necessario scegliere una versione di rete al momento dell'acquisto — consulta la [Guida Ethernet](/products/kvmext/ethernet/) per sapere quale scheda installare.

!!! warning "Non incluso"
    Il dispositivo **uConsole** di ClockworkPi non è incluso. Le foto del prodotto sono solo a scopo dimostrativo.

## Opzioni di acquisto

| Opzione | Contenuto |
|---------|-----------|
| **Solo Extension v2** | Modulo di Estensione v2 + entrambe le schede Ethernet + coperchio dello slot |
| **Bundle Extension v2 + Upgrade Kit** | Tutto quanto sopra + **HackerGadgets uConsole Upgrade Kit** (pronto per Ethernet gigabit) |
