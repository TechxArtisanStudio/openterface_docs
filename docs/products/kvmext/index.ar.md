# **وحدة توسيع KVM لـ Openterface uConsole الإصدار الثاني**

![kvmext-v2-hero-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-hero-1.webp){:style="max-height:360px"}

  <h2 class="slogan-text">حوّل جهاز uConsole الخاص بك إلى وحدة تحكم KVM محمولة</h2>
  <div class="slogan-subtitle">KVM. شبكة. بطاقة SD. فتحة توسيع واحدة.</div>

تُركّب **وحدة توسيع KVM لـ Openterface uConsole الإصدار الثاني** في فتحة التوسيع بجهاز uConsole الخاص بك، وتحوّله إلى **وحدة تحكم KVM محمولة**، و**محطة طرفية لتصحيح أخطاء الشبكة**، و**وحدة أداة لبطاقات SD**. احصل على **إدخال HDMI** مباشر، و**تحكم لوحة المفاتيح والفأرة عبر USB HID**، و**توسيع إيثرنت** (بطاقتا 100M و1000M مرفقتان)، و**قراءة/كتابة بطاقات SD**، و**مشاركة تبديل USB 2.0** — كل ذلك يعمل مباشرة من الفتحة دون الحاجة إلى محول خارجي.

مصممة لمحترفي تكنولوجيا المعلومات، ومُنشئي المختبرات المنزلية، ومطوري الأنظمة المدمجة، وفنيي الميدان الذين يحتاجون إلى وصول على مستوى BIOS، وصيانة الشبكة، ونسخ صور بطاقات SD دون حمل شاشات أو لوحات مفاتيح أو قارئات بطاقات إضافية.

!!! note "كود منتج واحد — كلتا بطاقتا الشبكة مرفقتان"
    تأتي وحدة التوسيع الإصدار الثاني مع **كلتا** بطاقتي إيثرنت 100M و1000M في العلبة. إنه منتج واحد، وليس نسختين منفصلتين من الشبكة. راجع [خيارات الشراء](/products/kvmext/purchase-options/) و[دليل الإيثرنت](/products/kvmext/ethernet/).
