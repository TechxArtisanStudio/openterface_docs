# **包装清单** | 扩展模块 v2

![kvmext-v2-box-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-1.webp){:style="max-width:480px"}
![kvmext-v2-box-2](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-2.webp){:style="max-width:480px"}

**核心组件**

- Openterface uConsole KVM 扩展模块 v2 主板 (77.3 × 34.7 mm)
- **100M 网卡** — 兼容所有 uConsole 底板
- **1000M 网卡** — 需要 [HackerGadgets uConsole 升级套件](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole) 才能实现千兆运行
- 扩展槽挡板

!!! note "单一 SKU"
    每个包装内均包含两张网卡。您在结账时无需选择网络版本 — 请参阅 [以太网指南](/products/kvmext/ethernet/) 了解应安装哪张网卡。

!!! warning "未包含"
    ClockworkPi **uConsole 设备** 不包含在内。产品图片仅供演示。
