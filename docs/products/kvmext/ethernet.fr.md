# **Guide Ethernet** | Module d'Extension v2

Le Module d'Extension v2 inclut **à la fois** une carte Ethernet 100M et une carte Ethernet 1000M dans la boîte. Installez **une** carte lors de la configuration matérielle — vous n'achetez pas de versions réseau séparées.

![kvmext-v2-pcb-detail](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-pcb-detail.webp){:style="max-height:320px"}

## Quelle carte dois-je utiliser ?

| Carte | Compatibilité | Idéal pour |
|------|---------------|----------|
| **Ethernet 100M** | Toutes les cartes de base uConsole | Usage universel, SSH, interface web, capture de logs |
| **Ethernet 1000M** | Nécessite le **Kit de Mise à Niveau uConsole de HackerGadgets** | Réseaux gigabit, transferts plus rapides |

!!! tip "Pas sûr ?"
    Commencez par la carte **100M** sauf si vous avez déjà le Kit de Mise à Niveau installé et confirmé fonctionnel.

## Options d'achat & Kit de Mise à Niveau

| Option | Capacité Ethernet |
|--------|---------------------|
| **Extension v2 uniquement** | 100M prêt à l'emploi ; carte 1000M incluse mais nécessite le Kit de Mise à Niveau pour le gigabit |
| **Bundle Extension v2 + Kit de Mise à Niveau** | Prêt pour le gigabit avec le Kit de Mise à Niveau inclus |

## Installation

1. Complétez les étapes 1–2 de l'[Installation Matérielle](/products/kvmext/hardware-installation/) (éteindre, retirer le module existant).
2. Insérez la carte Ethernet choisie sur le Module d'Extension v2 selon la conception du module.
3. Installez la carte principale dans le slot d'extension et fixez les vis.
4. Connectez un câble Ethernet à votre appareil cible ou réseau.

## Scénarios d'utilisation

- **SSH** vers des serveurs sans écran tout en les visualisant via KVM
- **Gestion web** pour routeurs, switches et appliances
- **Capture de logs** et maintenance réseau sur le terrain
- Flux de travail combiné **KVM + réseau** sans adaptateurs supplémentaires
