# **同梱物** | Extension Module v2

![kvmext-v2-box-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-1.webp){:style="max-width:480px"}
![kvmext-v2-box-2](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-2.webp){:style="max-width:480px"}

**主要コンポーネント**

- Openterface uConsole KVM Extension Module v2ボード (77.3 × 34.7 mm)
- **100M Ethernetカード** — すべてのuConsoleベースボードで動作します
- **1000M Ethernetカード** — ギガビット動作には[HackerGadgets uConsole Upgrade Kit](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole)が必要です
- 拡張スロットカバー

!!! note "単一SKU"
    すべてのパッケージに両方のネットワークカードが含まれています。チェックアウト時にネットワークバージョンを選択する必要はありません。どのカードを取り付けるかについては、[Ethernetガイド](/products/kvmext/ethernet/)を参照してください。

!!! warning "非同梱"
    ClockworkPi **uConsoleデバイス**は含まれていません。製品写真はデモンストレーション用のものです。
