## Сравнение вариантов

| | **Вариант 1: Только Extension v2** | **Вариант 2: Extension v2 + Upgrade Kit Bundle** |
|---|--------------------------------|--------------------------------------------------|
| **Основной продукт** | Openterface uConsole KVM Extension Module v2 | Extension Module v2 + **HackerGadgets uConsole Upgrade Kit** |
| **Сетевые карты** | В комплекте обе: 100M и 1000M | В комплекте обе: 100M и 1000M |
