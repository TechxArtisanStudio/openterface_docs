# **Openterface uConsole KVM Extension Module v2**

**Openterface uConsole KVM Extension Module v2** устанавливается в слот расширения вашего uConsole и превращает его в портативную **KVM-консоль**, **сетевой отладочный терминал** и **модуль утилит для SD-карт**. Получите прямой **HDMI-вход**, **управление клавиатурой и мышью через USB HID**, **расширение Ethernet** (карты 100M и 1000M в комплекте), **чтение/запись SD-карт** и **общее переключение USB 2.0** — питание подаётся напрямую через слот, без внешнего адаптера.

Создано для IT-специалистов, энтузиастов домашних лабораторий, разработчиков встраиваемых систем и полевых техников, которым необходим доступ на уровне BIOS, сетевое обслуживание и работа с образами SD-карт без необходимости носить с собой дополнительные мониторы, клавиатуры или кардридеры.

!!! note "Один артикул — обе сетевые карты в комплекте"
    Extension Module v2 поставляется с **обеими** сетевыми картами — 100M и 1000M — в коробке. Это один продукт, а не две отдельные сетевые версии. См. [Варианты покупки](/products/kvmext/purchase-options/) и [Руководство по Ethernet](/products/kvmext/ethernet/).
