# ユースケース | Extension Module v2

Extension Module v2は、uConsoleを**ポータブルKVMコンソール**、**ネットワークターミナル**、および**SDユーティリティ**に変えます。クラッシュカートなしで完全な制御が必要な場合に最適です。

![kvmext-v2-use-case-3](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-use-case-3.webp){:style="max-height:360px"}

## ITおよびネットワークメンテナンス

uConsoleからサーバー、ルーター、およびヘッドレスアプライアンスに直接アクセスします。**KVM**を使用してBIOSおよびコンソールにアクセスし、**Ethernet**を使用してSSH、Web管理、およびログキャプチャを、ポケットに入る1つのデバイスで実行できます。

## 組み込み開発

外部モニターを設置することなく、SBC、開発ボード、カスタムハードウェアのテストとデバッグを行います。**SDカード**経由でイメージをフラッシュし、**KVM**経由でブートメニューを制御して、ラボや作業台で反復開発を行います。

## フィールドサービスと診断

複数のサイトを巡回する技術者のための、コンパクトなモバイルKVMです。モニター、キーボード、カードリーダーの代わりに、uConsole1台を持ってデータセンターの列やクライアントサイトに乗り込みましょう。

## ネットワークトラブルシューティング

IP接続が利用可能な場合は、イーサネットカードを使用してメンテナンスタスクを行います。利用できない場合でも、**HDMI + USB HID**により、完全なヘッドレス制御が引き続き可能です。

## SDカードワークフロー

OSイメージの書き込み、ログの移動、ファイルの転送をuConsoleから直接行います。外部リーダーは不要です。Openterfaceアプリで、ホストとターゲット間のSDアクセスを切り替えます。

## ホームラボとメイカー

すでに持ち歩いているデバイスから、ヘッドレスNASノード、Proxmoxホスト、ラボ機器を構成します。Extension Module v2は、日常的に使用するuConsoleにKVMとユーティリティを追加します。
