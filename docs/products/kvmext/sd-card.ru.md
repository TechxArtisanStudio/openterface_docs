# **Руководство по SD-карте** | Модуль расширения v2

Модуль расширения v2 включает **чтение/запись SD-карты**, чтобы вы могли прошивать образы, экспортировать журналы и передавать файлы с вашего uConsole без необходимости носить с собой внешний кардридер.

## Обзор

Модуль предоставляет слот microSD, общий для **uConsole (хоста)** и **целевого устройства** — аналогично по концепции рабочему процессу переключения MicroSD в KVM-GO, но интегрированный в модуль расширения uConsole.

!!! note "Только одна сторона за раз"
    SD-карта монтируется либо к uConsole, **либо** к целевому устройству, но никогда одновременно к обоим. Переключайте доступ с помощью хост-приложения Openterface.

## Установка SD-карты

Вставьте карту microSD плотно, пока она надежно не зафиксируется в слоте модуля.

## Управление через хост-приложение

Используйте **Openterface QT** на вашем uConsole для:

- Переключения доступа к SD между **хостом** (uConsole) и **целевым устройством**
- Записи образов ОС на карту с uConsole
- Экспорта журналов или передачи файлов без извлечения карты

Убедитесь, что вы завершили [Настройку программного обеспечения](/products/kvmext/software-setup/) перед использованием функций SD.

## Типичные рабочие процессы

| Рабочий процесс | Описание |
|----------|-------------|
| **Создание образов ОС** | Прошивка образов Raspberry Pi, встраиваемых плат или устройств с uConsole |
| **Экспорт журналов** | Извлечение журналов с целевого устройства на карту, затем чтение на uConsole |
| **Передача файлов** | Перемещение конфигураций или скриптов между uConsole и целевым устройством при отсутствии сети |

## Советы по безопасности

- **Извлеките/размонтируйте** карту в хост-приложении перед физическим извлечением
- Переключитесь на правильную сторону (хост или целевое устройство) перед операциями чтения/записи
- Используйте качественные карты microSD для задач создания образов
