# Use Cases | Extension Module v2

Extension Module v2 turns your uConsole into a **portable KVM console**, **network terminal**, and **SD utility** — ideal when you need full control without a crash cart.

![kvmext-v2-use-case-3](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-use-case-3.webp){:style="max-height:360px"}

## IT and network maintenance

Access servers, routers, and headless appliances directly from your uConsole. Use **KVM** for BIOS and console access and **Ethernet** for SSH, web management, and log capture — in one pocketable device.

## Embedded development

Test and debug SBCs, development boards, and custom hardware without setting up external monitors. Flash images via **SD card**, control boot menus over **KVM**, and iterate in the lab or on the bench.

## Field service and diagnostics

A compact on-the-go KVM for technicians working across multiple sites. Walk into a datacenter row or client site with a single uConsole instead of a monitor, keyboard, and card reader.

## Network troubleshooting

When IP connectivity is available, use the Ethernet card for maintenance tasks. When it is not, **HDMI + USB HID** still provides full headless control.

## SD card workflows

Write OS images, move logs, and transfer files directly from the uConsole — no external reader required. Switch SD access between host and target in the Openterface app.

## Homelab and makers

Configure headless NAS nodes, Proxmox hosts, and lab gear from a device you already carry. Extension Module v2 adds KVM and utilities to the uConsole you use daily.
