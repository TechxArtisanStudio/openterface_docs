# Casos de uso | Módulo de extensión v2

El Módulo de extensión v2 convierte tu uConsole en una **consola KVM portátil**, **terminal de red** y **utilidad SD**, ideal cuando necesitas control total sin necesidad de un crash cart.

![kvmext-v2-use-case-3](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-use-case-3.webp){:style="max-height:360px"}

## Mantenimiento de TI y redes

Accede a servidores, routers y dispositivos headless directamente desde tu uConsole. Usa **KVM** para acceso a BIOS y consola, y **Ethernet** para SSH, gestión web y captura de registros, todo en un dispositivo que cabe en el bolsillo.

## Desarrollo de sistemas embebidos

Prueba y depura SBC, placas de desarrollo y hardware personalizado sin necesidad de configurar monitores externos. Graba imágenes a través de **tarjetas SD**, controla los menús de arranque mediante **KVM** e itera en el laboratorio o en el banco de trabajo.

## Servicio de campo y diagnóstico

Un KVM compacto y portátil para técnicos que trabajan en múltiples sitios. Entra en una fila de centro de datos o en las instalaciones de un cliente con un solo uConsole en lugar de llevar un monitor, teclado y lector de tarjetas.

## Resolución de problemas de red

Cuando hay conectividad IP disponible, utiliza la tarjeta Ethernet para tareas de mantenimiento. Cuando no la hay, **HDMI + USB HID** sigue proporcionando control total sobre dispositivos headless.

## Flujos de trabajo con tarjetas SD

Escribe imágenes de sistemas operativos, mueve registros y transfiere archivos directamente desde el uConsole, sin necesidad de un lector externo. Cambia el acceso a la SD entre el host y el objetivo en la aplicación de Openterface.

## Homelab y makers

Configura nodos NAS headless, hosts Proxmox y equipos de laboratorio desde un dispositivo que ya llevas contigo. El Módulo de extensión v2 añade KVM y utilidades al uConsole que usas a diario.
