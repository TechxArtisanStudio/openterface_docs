# 应用场景 | 扩展模块 v2

扩展模块 v2 将您的 uConsole 转变为**便携式 KVM 控制台**、**网络终端**和 **SD 实用工具**——在您需要完全控制而又无需笨重推车时，它是理想之选。

![kvmext-v2-use-case-3](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-use-case-3.webp){:style="max-height:360px"}

## IT 与网络维护

直接从您的 uConsole 访问服务器、路由器和无头设备。使用 **KVM** 进行 BIOS 和控制台访问，使用 **以太网** 进行 SSH、Web 管理和日志采集——全部集成在一个口袋大小的设备中。

## 嵌入式开发

无需连接外部显示器，即可测试和调试 SBC、开发板以及定制硬件。通过 **SD 卡**烧录镜像，通过 **KVM** 控制启动菜单，在实验室或工作台上高效迭代。

## 现场服务与诊断

为奔波于多个现场的工程师提供紧凑的便携式 KVM。走进数据中心机柜或客户现场时，只需携带一台 uConsole，而无需显示器、键盘和读卡器。

## 网络故障排除

当 IP 连通可用时，使用以太网网卡执行维护任务。当 IP 连通不可用时，**HDMI + USB HID** 仍可提供完整的无头控制能力。

## SD 卡工作流

直接从 uConsole 烧录系统镜像、移动日志和传输文件——无需外部读卡器。在 Openterface 应用中可在主机与目标机之间切换 SD 卡访问。

## 家庭实验室与创客

使用您日常随身携带的设备，配置无头 NAS 节点、Proxmox 主机和实验室设备。扩展模块 v2 为您常用的 uConsole 增添了 KVM 和实用工具功能。
