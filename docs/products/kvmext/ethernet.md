# **Ethernet Guide** | Extension Module v2

Extension Module v2 includes **both** a 100M and a 1000M Ethernet card in the box. Install **one** card during hardware setup — you do not buy separate network versions.

![kvmext-v2-pcb-detail](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-pcb-detail.webp){:style="max-height:320px"}

## Which card should I use?

| Card | Compatibility | Best for |
|------|---------------|----------|
| **100M Ethernet** | All uConsole base boards | Universal use, SSH, web UI, log capture |
| **1000M Ethernet** | Requires **HackerGadgets uConsole Upgrade Kit** | Gigabit networking, faster transfers |

!!! tip "Not sure?"
    Start with the **100M** card unless you already have the Upgrade Kit installed and confirmed working.

## Installation

1. Complete [Hardware Installation](/products/kvmext/hardware-installation/) steps 1–2 (power off, remove existing module).
2. Seat your chosen Ethernet card on Extension Module v2 per the module design.
3. Install the main board in the expansion slot and secure screws.
4. Connect an Ethernet cable to your target device or network.

## Usage scenarios

- **SSH** into headless servers while viewing them over KVM
- **Web management** for routers, switches, and appliances
- **Log capture** and network maintenance in the field
- Combined **KVM + network** workflow without extra adapters
