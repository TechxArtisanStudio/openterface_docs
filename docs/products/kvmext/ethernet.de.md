# **Ethernet-Anleitung** | Erweiterungsmodul v2

Das Erweiterungsmodul v2 enthält **sowohl** eine 100M- als auch eine 1000M-Ethernet-Karte in der Verpackung. Installieren Sie **eine** Karte während der Hardware-Einrichtung — Sie kaufen keine separaten Netzwerkversionen.

![kvmext-v2-pcb-detail](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-pcb-detail.webp){:style="max-height:320px"}

## Welche Karte sollte ich verwenden?

| Karte | Kompatibilität | Am besten geeignet für |
|------|---------------|----------|
| **100M Ethernet** | Alle uConsole-Basisplatinen | Universeller Einsatz, SSH, Web-UI, Log-Erfassung |
| **1000M Ethernet** | Erfordert **HackerGadgets uConsole Upgrade-Kit** | Gigabit-Netzwerke, schnellere Übertragungen |

!!! tip "Nicht sicher?"
    Beginnen Sie mit der **100M**-Karte, es sei denn, Sie haben das Upgrade-Kit bereits installiert und bestätigt funktionsfähig.

## Kaufoptionen & Upgrade-Kit

| Option | Ethernet-Fähigkeit |
|--------|---------------------|
| **Nur Erweiterung v2** | 100M sofort einsatzbereit; 1000M-Karte enthalten, benötigt jedoch Upgrade-Kit für Gigabit |
| **Erweiterung v2 + Upgrade-Kit-Bundle** | Gigabit-bereit mit enthaltenem Upgrade-Kit |

Vollständiger Vergleich: [Kaufoptionen](/products/kvmext/purchase-options/)

Erfahren Sie mehr über das Upgrade-Kit von **HackerGadgets** (verlinkt von unserem [TechxArtisan-Shop-Eintrag](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole)).

## Installation

1. Schließen Sie die Schritte 1–2 der [Hardware-Installation](/products/kvmext/hardware-installation/) ab (ausschalten, vorhandenes Modul entfernen).
2. Setzen Sie Ihre gewählte Ethernet-Karte gemäß dem Moduldesign auf das Erweiterungsmodul v2.
3. Installieren Sie die Hauptplatine im Erweiterungssteckplatz und sichern Sie die Schrauben.
4. Verbinden Sie ein Ethernet-Kabel mit Ihrem Zielgerät oder Netzwerk.

## Nutzungsszenarien

- **SSH** in kopflose Server, während Sie diese über KVM anzeigen
- **Web-Verwaltung** für Router, Switches und Geräte
- **Log-Erfassung** und Netzwerkwartung im Feld
- Kombinierter **KVM + Netzwerk**-Arbeitsablauf ohne zusätzliche Adapter
