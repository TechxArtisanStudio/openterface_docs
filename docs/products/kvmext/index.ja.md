# **Openterface uConsole KVM Extension Module v2**

![kvmext-v2-hero-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-hero-1.webp){:style="max-height:360px"}
![kvmext-v2-use-case-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-use-case-1.webp){:style="max-height:360px"}

<div class="slogan-highlight">
  <h2 class="slogan-text">uConsoleをポータブルKVMコンソールに変換</h2>
  <div class="slogan-subtitle">KVM。ネットワーク。SDカード。1つの拡張スロットで。</div>
</div>

**Openterface uConsole KVM Extension Module v2** はuConsoleの拡張スロットに接続し、ポータブル**KVMコンソール**、**ネットワークデバッグターミナル**、および**SDカードユーティリティモジュール**へと変換します。外部アダプター不要でスロットから直接給電され、直接**HDMI入力**、**USB HIDキーボードおよびマウス制御**、**Ethernet拡張**（100Mおよび1000Mカード同梱）、**SDカードの読み書き**、**USB 2.0共有切り替え**を利用できます。

追加のモニター、キーボード、カードリーダーを持ち運ぶことなく、BIOSレベルのアクセス、ネットワークメンテナンス、SDイメージ作成を必要とするITプロフェッショナル、ホームラボ構築者、組み込み開発者、フィールド技術者のために設計されました。

!!! note "単一SKU — 両方のネットワークカードを同梱"
    Extension Module v2には、100Mおよび1000M Ethernetカードの**両方**がボックスに同梱されています。これは別々のネットワークバージョンがある2つの製品ではなく、1つの製品です。[購入オプション](/products/kvmext/purchase-options/)および[Ethernetガイド](/products/kvmext/ethernet/)を参照してください。
