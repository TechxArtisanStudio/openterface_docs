## Comparer les options

| | **Option 1 : Extension v2 seule** | **Option 2 : Extension v2 + Bundle Kit de mise à niveau** |
|---|--------------------------------|--------------------------------------------------|
| **Produit principal** | Module d'Extension KVM Openterface uConsole v2 | Module d'Extension v2 + **Kit de mise à niveau uConsole HackerGadgets** |
| **Cartes réseau** | Cartes 100M et 1000M incluses dans la boîte | Cartes 100M et 1000M incluses dans la boîte |
| **Ethernet 100M** | Fonctionne avec toutes les cartes de base uConsole | Fonctionne avec toutes les cartes de base uConsole |
| **Ethernet 1000M** | Incluse, nécessite le Kit de mise à niveau pour le gigabit | Prêt pour le gigabit avec le Kit de mise à niveau inclus |
| **Idéal pour** | Utilisateurs qui possèdent déjà le Kit de mise à niveau, ou qui n'ont besoin que du 100M | Utilisateurs qui ont besoin du gigabit et n'ont pas le Kit de mise à niveau |

!!! note "SKU unique — les deux cartes réseau toujours incluses"
    Chaque boîte contient **les deux** cartes Ethernet. Le bundle ajoute le **Kit de mise à niveau** nécessaire au fonctionnement en gigabit 1000M — il ne s'agit pas d'une référence réseau différente.
