# **Ce conține pachetul** | Modul de extensie v2

![kvmext-v2-box-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-1.webp){:style="max-width:480px"}
![kvmext-v2-box-2](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-2.webp){:style="max-width:480px"}

**Componente principale**

- Placă Openterface uConsole KVM Extension Module v2 (77.3 × 34.7 mm)
- **Placă Ethernet 100M** — funcționează cu toate plăcile de bază uConsole
- **Placă Ethernet 1000M** — necesită [HackerGadgets uConsole Upgrade Kit](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole) pentru funcționare gigabit
- Capac pentru slotul de expansiune

!!! note "SKU unic"
    Ambele plăci de rețea sunt incluse în fiecare cutie. Nu trebuie să alegi o versiune de rețea la comandă — vezi [Ghid Ethernet](/products/kvmext/ethernet/) pentru a afla ce placă să instalezi.

!!! warning "Nu este inclus"
    Dispozitivul ClockworkPi **uConsole** nu este inclus. Fotografiile produsului sunt doar pentru demonstrație.
