# **Openterface uConsole KVM Extension Module v2**

![kvmext-v2-hero-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-hero-1.webp){:style="max-height:360px"}
![kvmext-v2-use-case-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-use-case-1.webp){:style="max-height:360px"}

<div class="slogan-highlight">
  <h2 class="slogan-text">Transforma tu uConsole en una Consola KVM Portátil</h2>
  <div class="slogan-subtitle">KVM. Red. Tarjeta SD. Una sola ranura de expansión.</div>
</div>

El **Openterface uConsole KVM Extension Module v2** se conecta a la ranura de expansión de tu uConsole y lo convierte en una **consola KVM** portátil, un **terminal de depuración de red** y un **módulo de utilidad para tarjetas SD**. Obtén **entrada HDMI** directa, **control de teclado y mouse USB HID**, **expansión Ethernet** (tarjetas de 100M y 1000M incluidas), **lectura/escritura de tarjetas SD** y **conmutación compartida USB 2.0**, todo alimentado directamente desde la ranura sin necesidad de un adaptador externo.

Diseñado para profesionales de TI, creadores de homelabs, desarrolladores de sistemas embebidos y técnicos de campo que necesitan acceso a nivel de BIOS, mantenimiento de red y creación de imágenes SD sin tener que llevar monitores, teclados o lectores de tarjetas adicionales.

!!! note "SKU único — ambas tarjetas de red incluidas"
    El Extension Module v2 se envía con **ambas** tarjetas Ethernet de 100M y 1000M en la caja. Es un solo producto, no dos versiones de red separadas. Consulta las [Opciones de compra](/products/kvmext/purchase-options/) y la [Guía de Ethernet](/products/kvmext/ethernet/).
