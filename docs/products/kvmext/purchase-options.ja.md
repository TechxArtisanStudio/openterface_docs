## オプションの比較

| | **オプション 1: 拡張モジュール v2 のみ** | **オプション 2: 拡張モジュール v2 + アップグレードキット バンドル** |
|---|--------------------------------|--------------------------------------------------|
| **主な製品** | Openterface uConsole KVM 拡張モジュール v2 | 拡張モジュール v2 + **HackerGadgets uConsole アップグレードキット** |
| **ネットワークカード** | 100M と 1000M の両方が箱に同梱 | 100M と 1000M の両方が箱に同梱 |
| **100M イーサネット** | すべての uConsole ベースボードで動作 | すべての uConsole ベースボードで動作 |
| **1000M イーサネット** | 同梱、ギガビット利用にはアップグレードキットが必要 | 同梱のアップグレードキットでギガビット対応 |
| **最適な用途** | すでにアップグレードキットをお持ちの場合、または 100M のみで十分な場合 | ギガビットが必要でアップグレードキットをお持ちでない場合 |

!!! note "単一 SKU — 両方のネットワークカードが常に同梱されます"
    すべての箱に **両方の** イーサネットカードが入っています。バンドルには 1000M ギガビット動作に必要な **アップグレードキット** が付属します。ネットワーク SKU が異なるわけではありません。
