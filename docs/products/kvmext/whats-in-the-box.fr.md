# **Contenu de la boîte** | Module d'extension v2

![kvmext-v2-box-1](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-1.webp){:style="max-width:480px"}
![kvmext-v2-box-2](https://assets.openterface.com/images/product/kvmext-v2/kvmext-v2-box-2.webp){:style="max-width:480px"}

**Composants principaux**

- Carte Openterface uConsole KVM Extension Module v2 (77.3 × 34.7 mm)
- **Carte Ethernet 100M** — compatible avec toutes les cartes de base uConsole
- **Carte Ethernet 1000M** — nécessite le [kit de mise à niveau uConsole HackerGadgets](https://shop.techxartisan.com/products/openterface-kvm-ext-for-uconsole) pour fonctionner en gigabit
- Cache pour slot d'extension

!!! note "SKU unique"
    Les deux cartes réseau sont incluses dans chaque boîte. Vous n'avez pas besoin de choisir une version réseau lors de la commande — consultez le [guide Ethernet](/products/kvmext/ethernet/) pour savoir quelle carte installer.

!!! warning "Non inclus"
    L'appareil **uConsole ClockworkPi** n'est pas inclus. Les photos du produit sont fournies à titre de démonstration uniquement.

## Options d'achat

| Option | Contenu |
|--------|----------|
| **Extension v2 uniquement** | Module d'extension v2 + les deux cartes Ethernet + cache pour slot |
| **Extension v2 + kit de mise à niveau** | Tout ce qui précède + **kit de mise à niveau uConsole HackerGadgets** (prêt pour l'Ethernet gigabit) |
