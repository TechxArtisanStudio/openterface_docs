## Allgemein

**:material-chat-question:{ .faq } Was ist KeyMod Series?**

KeyMod Series ist ein kompakter USB + Bluetooth HID-Emulator (Tastatur i Maus), der Ihr Smartphone in eine tragbare Tastatur i ein Trackpad verwandelt. Verwenden Sie es zur Steuerung von Geräten, die Tastatur-/Mauseingaben benötigen – Kioske, Smart-TVs, Set-Top-Boxen, Außendisplays – ohne eine vollständige Tastatur zzuführen.

**:material-chat-question:{ .faq } Welche Plattformen unterstützt die KeyMod Series App?**

Die KeyMod Series Controller-App konzentriert sich auf **Android**, **iOS** i **iPadOS**. Wir erweitern auch die Desktop-Steuerung z **Windows- i macOS-Oprogramowanie** in unserem breiteren Openterface-Ökosystem.

**:material-chat-question:{ .faq } Benötigt das Zielgerät eine Oprogramowanie?**

Nein. KeyMod Series emuliert eine Standard-USB-Tastatur i -Maus. Das Zielgerät erkennt es als Plug-and-Play-HID-Sprzęt – keine Treiber lub Oprogramowanieinstallation erforderlich.

**:material-chat-question:{ .faq } Ist KeyMod Series Open Source?**

Ja. KeyMod Series ist Open-Sprzęt i Open-Source-Oprogramowanie. Wir werden Schaltpläne, PCB-Dateien, Firmware, Oprogramowanie i BOM veröffentlichen, während das Projekt sich weiterentwickelt.

## Konnektivität

**:material-chat-question:{ .faq } USB vs. Bluetooth – was soll ich verwenden?**

- **USB**: Zuverlässiger, geringere Latenz. Verwenden Sie es, wenn Sie die stabilste Połączenie wünschen.
- **Bluetooth**: Kabellos. Verwenden Sie es, wenn Sie ein leichteres Setup wünschen i das Szenario drahtlose Połączenie zulässt.

**:material-chat-question:{ .faq } Welche Sprzęt-Varianten sind dla KeyMod Series geplant?**

1. **2-in-1-Stecker** — Kombinierter USB-A- i USB-C-Stecker dla breite Kompatibilität
2. **USB-C-Version** — Dedizierter USB-C-Stecker dla mlubne Geräte

## Funkcje

**:material-chat-question:{ .faq } Kann ich benutzerdefinierte Profile i Makros erstellen?**

Ja. Die Open-Source-Mobil-App unterstützt benutzerdefinierte Eingabeprofile, Makros, Hotkeys i Workflow-Verknüpfungen. Sie können auch ein Tastenfeld verwenden.

## Pre-Launch

**:material-chat-question:{ .faq } Wann wird KeyMod Series auf den Markt kommen?**

KeyMod Series befindet sich in der Pre-Launch-Entwicklung. Abonnieren Sie die [Produktseite](/products/keymod/) dla Launch-Benachrichtigungen i Aktualizacje.

**:material-chat-question:{ .faq } Wie hängt KeyMod Series z Mini-KVM i KVM-Go zusammen?**

KeyMod Series nutzt den bewährten HID-Kern von Openterface Mini-KVM. Es teilt denselben hardwarebasierten Ansatz zur Tastatur- i Mausemulation, ist aber dla einen anderen Anwendungsfall konzipiert: Ihr Smartphone in eine tragbare Tastatur/Trackpad dla die lokale Gerätesteuerung zu verwandeln, anstatt KVM-over-USB-Videoaufnahme.
