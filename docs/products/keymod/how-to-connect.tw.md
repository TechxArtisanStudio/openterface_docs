# **如何連接** | 設置指南 | Openterface KeyMod

## **概述**

KeyMod 將您的手機（運行 KeyCmd 應用）連接到目標設備。您的手機充當鍵盤和觸控板；KeyMod 向目標設備模擬 HID 輸入。

![KeyMod Right Side](https://assets2.openterface.com/images/keymod/right-side.webp){:style="max-height:360px"}

**連接流程：** 手機（KeyCmd 應用）→ KeyMod（USB 或藍牙）→ 目標設備

- **手機/平板**：需要 KeyCmd 應用（Android 或 iPadOS）
- **KeyMod**：通過 USB 或藍牙連接手機；通過 USB 連接目標設備
- **目標設備**：無需安裝軟件

## **所需物品**

- **KeyMod** — USB + 藍牙 HID 模擬器
- **手機或平板** — 已安裝 KeyCmd 應用的 Android 或 iPadOS 設備
- **USB 線纜** — 用於 KeyMod 到目標的連接（KeyMod 隨附）
- **可選**：用於手機與 KeyMod 無線連接的藍牙

## **分步設置**

### **步驟 1 — 安裝 KeyCmd 應用**

從[應用](/app)部分在您的 Android 設備或 iPad 上下載並安裝 KeyCmd 應用。

### **步驟 2 — 將 KeyMod 連接到手機**

**選項 A：USB 連接**

通過 USB 線纜將 KeyMod 連接到手機。2 合 1 版本適用於 USB-A 和 USB-C 端口；USB C 版本使用 USB-C 線纜。

![KeyMod Feature](https://assets2.openterface.com/images/keymod/feature.webp){:style="max-height:360px"}

**選項 B：藍牙連接**

通過藍牙將 KeyMod 與手機配對，實現無線設置。在手機上啟用藍牙，然後從應用中與 KeyMod 配對。

![iPad Connect](https://assets2.openterface.com/images/keymod/ipad-connect.webp){:style="max-height:360px"}

### **步驟 3 — 將 KeyMod 連接到目標設備**

將 KeyMod 的 USB 連接器插入目標設備（計算機、信息亭、智能電視、機頂盒等）。目標設備會將 KeyMod 識別為標準 USB 鍵盤和鼠標——無需驅動程序或軟件。

![Windows Connect](https://assets2.openterface.com/images/keymod/windows-connect.webp){:style="max-height:360px"}

### **步驟 4 — 開始控制**

在手機上打開 KeyCmd 應用。使用屏幕鍵盤和觸控板控制目標設備。根據需要配置配置文件、宏和快捷鍵。
