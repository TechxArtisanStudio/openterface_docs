# **الاتصال herstellen** | Einrichtungsanleitung | Openterface KeyMod

## **نظرة عامة**

KeyMod verbindet Ihr Smartphone (مع der KeyMod-App) مع einem Zielgerät. Ihr Smartphone fungiert als Tastatur و Trackpad; KeyMod emuliert die HID-Eingabe لـ das Zielgerät.

![KeyMod Right Side](https://assets2.openterface.com/images/keymod/right-side.webp){:style="max-height:360px"}

**الاتصالsablauf:** Smartphone (KeyMod-App) → KeyMod (USB أو Bluetooth) → Zielgerät

- **Smartphone/Tablet**: Erfordert die KeyMod-Controller-App (Android أو iPadOS)
- **KeyMod**: الاتصال zum Smartphone per USB أو Bluetooth; الاتصال zum Zielgerät per USB
- **Zielgerät**: Keine البرمجياتinstallation erforderlich

## **Was Sie benötigen**

- **KeyMod** — USB + Bluetooth HID-Emulator
- **Smartphone أو Tablet** — Android أو iPadOS مع installierter KeyMod-App
- **USB-Kabel** — Für die KeyMod-zu-Ziel-الاتصال (im KeyMod-Lieferumfang enthalten)
- **Optional**: Bluetooth لـ kabellose Smartphone-zu-KeyMod-الاتصال

## **Schritt-لـ-Schritt-Einrichtung**

### **Schritt 1 — KeyMod-App installieren**

Laden Sie die KeyMod-Controller-App herunter و installieren Sie sie auf Ihrem Android-Gerät أو iPad im [App](/app)-Bereich.

### **Schritt 2 — KeyMod مع Ihrem Smartphone verbinden**

**Option A: USB-الاتصال**

Verbinden Sie KeyMod per USB-Kabel مع Ihrem Smartphone. Die 2-in-1-Variante passt in USB-A- و USB-C-Anschlüsse; die USB-C-Variante verwendet ein USB-C-Kabel.

![KeyMod Feature](https://assets2.openterface.com/images/keymod/feature.webp){:style="max-height:360px"}

**Option B: Bluetooth-الاتصال**

Koppeln Sie KeyMod per Bluetooth مع Ihrem Smartphone لـ eine kabellose Einrichtung. Aktivieren Sie Bluetooth auf Ihrem Smartphone و koppeln Sie dann حول die App مع KeyMod.

![iPad Connect](https://assets2.openterface.com/images/keymod/ipad-connect.webp){:style="max-height:360px"}

### **Schritt 3 — KeyMod مع Zielgerät verbinden**

Stecken Sie den USB-Stecker von KeyMod in das Zielgerät (Computer, Kiosk, Smart-TV, Set-Top-Box usw.). Das Zielgerät erkennt KeyMod als Standard-USB-Tastatur و -Maus—keine Treiber أو البرمجيات erforderlich.

![Windows Connect](https://assets2.openterface.com/images/keymod/windows-connect.webp){:style="max-height:360px"}

### **Schritt 4 — Steuerung starten**

Öffnen Sie die KeyMod-App auf Ihrem Smartphone. Verwenden Sie die Bildschirmtastatur و das Trackpad, um das Zielgerät zu steuern. Konfigurieren Sie bei Bedarf Profile, Makros و Hotkeys.
