- **Plus 版** — Type A 公头接口和 Type C 母头接口

## 核心功能

### **手机变键盘和触控板**

KeyMod 将您的手机变成便携式键盘和触控板控制台。在无法使用完整键盘和鼠标时使用，或当您需要比切换设备更快的操作流程时使用。适用于户外显示屏电脑、LED 广告机播放器、信息亭、智能电视和机顶盒。

### **双连接：USB + 蓝牙**

- **USB** — 即插即用有线连接，实现可靠、低延迟的输入
- **蓝牙** — 在场景允许时实现无线设置；保持配置轻便便携

KeyMod 专为实用的日常本地设备控制而设计，而非替代远程桌面。

### **开源移动应用**

通过我们的开源移动应用，您可以：

- **键盘与鼠标（基础版）** — 全屏键盘，支持长按重复、按键预览和数字键盘
- **键盘与鼠标专业版** — 带快捷方式中心条、分体键盘和输入法的组合布局
- **演示模式** — 适用于 Google Slides 和其他应用的幻灯片遥控与计时器
- **手柄** — 虚拟控制器，支持可自定义的预设布局和多触控板支持
- **快捷方式中心** — 为创意和开发工具（Blender、KiCAD、Photoshop、VS Code）提供基于配置文件的键盘快捷键，支持创建、导入和导出
- **宏** — 带延迟的可编程按键序列
- **语音输入** — 通过 AI（Whisper API）实现语音转键盘
- **终端** — 通过蓝牙进行 SSH，实现远程命令访问
- **Agent** — 通过 HID 或 SSH 指令与 AI 直接交互，控制另一台电脑

**KeyCmd** 应用专注于 **Android** 和 **iOS**（包括 iPadOS）。它还可通过 USB 或蓝牙与 **KVM-GO** 配合使用。我们还在更广泛的 Openterface 生态系统中通过 **Windows 和 macOS** 软件扩展桌面控制。


### **真正的硬件 HID**

基于 Openterface Mini-KVM 的成熟 HID 核心。基于硬件的键盘和鼠标模拟——目标设备无需安装软件。

### **开源**

KeyMod 是开源硬件和开源软件。随着项目的发展，我们将发布电路图、PCB 文件、固件、软件和 BOM。[加入我们的社区](/discord)参与贡献并获取最新信息。

## 技术规格

### **连接**

- **USB**：Mini 版使用 Type C 公头接口；Plus 版使用 Type A 公头接口和 Type C 母头接口
- **蓝牙**：HID 键盘和鼠标
- **目标**：无需安装软件

### **关键硬件**

- CH32V208 芯片（兼容 CH9329 协议）
- USB 接口：Mini 版使用 Type C 公头；Plus 版使用 Type A 公头和 Type C 母头
- MCU
- 可编程按钮

### **输入功能**

- 完整键盘和鼠标模拟（HID）
- 自定义输入配置文件（基础和高级两个层级）
- 宏和快捷键
- 带应用专用配置文件的快捷方式中心
- 带预设布局的手柄（schema v7）
- 带幻灯片计时器的演示控制
- 通过 AI 实现语音转键盘
