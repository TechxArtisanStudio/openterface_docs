## Allgemein

**:material-chat-question:{ .faq } Was ist KeyMod Series?**

KeyMod Series ist ein kompakter USB + Bluetooth HID-Emulator (Tastatur и Maus), der Ihr Smartphone in eine tragbare Tastatur и ein Trackpad verwandelt. Verwenden Sie es zur Steuerung von Geräten, die Tastatur-/Mauseingaben benötigen – Kioske, Smart-TVs, Set-Top-Boxen, Außendisplays – ohne eine vollständige Tastatur сzuführen.

**:material-chat-question:{ .faq } Welche Plattformen unterstützt die KeyMod Series App?**

Die KeyMod Series Controller-App konzentriert sich auf **Android**, **iOS** и **iPadOS**. Wir erweitern auch die Desktop-Steuerung с **Windows- и macOS-Программное обеспечение** in unserem breiteren Openterface-Ökosystem.

**:material-chat-question:{ .faq } Benötigt das Zielgerät eine Программное обеспечение?**

Nein. KeyMod Series emuliert eine Standard-USB-Tastatur и -Maus. Das Zielgerät erkennt es als Plug-and-Play-HID-Оборудование – keine Treiber или Программное обеспечениеinstallation erforderlich.

**:material-chat-question:{ .faq } Ist KeyMod Series Open Source?**

Ja. KeyMod Series ist Open-Оборудование и Open-Source-Программное обеспечение. Wir werden Schaltpläne, PCB-Dateien, Firmware, Программное обеспечение и BOM veröffentlichen, während das Projekt sich weiterentwickelt.

## Konnektivität

**:material-chat-question:{ .faq } USB vs. Bluetooth – was soll ich verwenden?**

- **USB**: Zuverlässiger, geringere Latenz. Verwenden Sie es, wenn Sie die stabilste Подключение wünschen.
- **Bluetooth**: Kabellos. Verwenden Sie es, wenn Sie ein leichteres Setup wünschen и das Szenario drahtlose Подключение zulässt.

**:material-chat-question:{ .faq } Welche Оборудование-Varianten sind для KeyMod Series geplant?**

1. **2-in-1-Stecker** — Kombinierter USB-A- и USB-C-Stecker для breite Kompatibilität
2. **USB-C-Version** — Dedizierter USB-C-Stecker для mилиne Geräte

## Pre-Launch

**:material-chat-question:{ .faq } Wann wird KeyMod Series auf den Markt kommen?**

KeyMod Series befindet sich in der Pre-Launch-Entwicklung. Abonnieren Sie die [Продуктseite](/products/keymod/) для Launch-Benachrichtigungen и Обновления.

**:material-chat-question:{ .faq } Wie hängt KeyMod Series с Mini-KVM и KVM-Go zusammen?**

KeyMod Series nutzt den bewährten HID-Kern von Openterface Mini-KVM. Es teilt denselben hardwarebasierten Ansatz zur Tastatur- и Mausemulation, ist aber для einen anderen Anwendungsfall konzipiert: Ihr Smartphone in eine tragbare Tastatur/Trackpad для die lokale Gerätesteuerung zu verwandeln, anstatt KVM-over-USB-Videoaufnahme.
