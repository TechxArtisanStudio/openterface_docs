# **기능 및 사양** | Openterface KeyMod 시리즈

## 현재 상태

KeyMod 는 활발히 개발 중이며, Android 용 [공개 베타](/tutorial/keymod/)가 제공됩니다. 최신 출시 알림을 받으려면 [제품 페이지](/products/keymod/)에서 구독하세요.

> **참고:** 기능, 사양 및 디자인은 개발이 진행됨에 따라 변경될 수 있습니다.

## 제품 버전

- **Mini 버전** — Type C 수 커넥터만
- **Plus 버전** — Type A 수 커넥터 및 Type C 암 커넥터

## 핵심 기능

### **휴대폰을 키보드와 트랙패드로**

KeyMod 는 휴대폰을 휴대용 키보드 및 트랙패드 콘솔로 바꿉니다. 전체 키보드와 마우스를 사용할 수 없거나, 기기를 전환하는 것보다 빠른 워크플로우가 필요할 때 사용하세요. 야외 디스플레이 컴퓨터, LED 간판 플레이어, 키오스크, 스마트 TV, 셋톱박스에 이상적입니다.

### **듀얼 연결: USB + 블루투스**

- **USB** — 안정적이고 낮은 지연 시간의 입력을 위한 플러그 앤 플레이 유선 연결
- **블루투스** — 시나리오가 허용할 때 케이블 없는 설정; 설정을 가볍고 휴대 가능하게 유지

KeyMod 는 원격 데스크톱 대체가 아닌 실용적인 일상의 로컬 기기 제어를 위해 설계되었습니다.

### **오픈소스 모바일 앱**

오픈소스 모바일 앱으로 다음이 가능합니다:

- **키보드 & 마우스 (기본)** — 길게 눌러 반복, 키 미리보기, 숫자 키패드가 있는 전체 화면 키보드
- **키보드 & 마우스 Pro** — 단축키 허브 스트립, 분할 키보드, IME 가 있는 복합 레이아웃
- **프레젠테이션 모드** — Google Slides 및 기타 앱을 위한 슬라이드 원격 제어 및 타이머
- **게임패드** — 사용자 정의 가능한 프리셋 레이아웃, 멀티 터치패드 지원을 갖춘 가상 컨트롤러
- **단축키 허브** — 창의적 및 개발 도구(Blender, KiCAD, Photoshop, VS Code)를 위한 프로필 기반 키보드 단축키. 생성, 가져오기, 내보내기 지원
- **매크로** — 지연이 있는 프로그래밍 가능한 키 시퀀스
- **음성 입력** — AI(Whisper API)를 통한 음성-키보드 변환
- **터미널** — 원격 명령 접근을 위한 블루투스 기반 SSH
- **Agent** — HID 또는 SSH 명령으로 다른 컴퓨터를 제어하는 AI 기반 직접 상호작용

**KeyCmd** 앱은 **Android** 및 **iOS**(iPadOS 포함)에 중점을 둡니다. USB 또는 블루투스를 통해 **KVM-GO**와도 작동합니다. 더 넓은 Openterface 생태계에서 **Windows 및 macOS** 소프트웨어로 데스크톱 제어도 확장하고 있습니다.


### **진정한 하드웨어 HID**

Openterface Mini-KVM 의 검증된 HID 코어를 기반으로 합니다. 하드웨어 기반 키보드 및 마우스 에뮬레이션—대상 기기에 소프트웨어 설치가 필요하지 않습니다.

### **오픈소스**

KeyMod 는 오픈 하드웨어 및 오픈 소프트웨어입니다. 프로젝트가 발전함에 따라 회로도, PCB 파일, 펌웨어, 소프트웨어 및 BOM 을 게시할 예정입니다. [커뮤니티에 참여](/discord)하여 기여하고 최신 정보를 받아보세요.

## 기술 사양

### **연결**

- **USB**: Mini 버전은 Type C 수 커넥터 사용; Plus 버전은 Type A 수 커넥터 및 Type C 암 커넥터 사용
- **블루투스**: HID 키보드 및 마우스
- **대상**: 소프트웨어 설치 불필요

### **주요 하드웨어**

- CH32V208 칩 (CH9329 호환 프로토콜)
- USB 커넥터: Mini 버전은 Type C 수; Plus 버전은 Type A 수 및 Type C 암
- MCU
- 프로그래밍 가능 버튼

### **입력 기능**

- 전체 키보드 및 마우스 에뮬레이션 (HID)
- 사용자 정의 입력 프로필 (기본 및 Pro 두 단계)
- 매크로 및 단축키
- 앱별 프로필이 있는 단축키 허브
- 프리셋 기반 레이아웃의 게임패드 (schema v7)
- 슬라이드 타이머가 있는 프레젠테이션 컨트롤
- AI 를 통한 음성-키보드 변환
