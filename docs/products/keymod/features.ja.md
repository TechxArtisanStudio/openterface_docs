# **機能と仕様** | Openterface KeyMod シリーズ

## 現在の状況

KeyMod は活発に開発中であり、Android 向けに[公開ベータ版](/tutorial/keymod/)が提供されています。最新のお知らせを受け取るには、[製品ページ](/products/keymod/)で購読してください。

> **注意：** 機能、仕様、デザインは開発中に引き続き変更される場合があります。

## 製品バリエーション

- **Mini バージョン** — Type C オスコネクタのみ
- **Plus バージョン** — Type A オスコネクタと Type C メスコネクタ

## コア機能

### **スマートフォンをキーボードとタッチパッドに**

KeyMod は、お使いのスマートフォンをポータブルなキーボード＆タッチパッドコンソールに変えます。フルサイズのキーボードとマウスが使用できない場面や、デバイスを切り替えるよりも迅速に作業したい場合に最適です。屋外ディスプレイ用コンピュータ、LED サイネージプレーヤー、キオスク、スマートテレビ、セットトップボックスに最適です。

### **デュアル接続：USB + Bluetooth**

- **USB** — 信頼性の高い低遅延入力のためのプラグアンドプレイ有線接続
- **Bluetooth** — シナリオが許す場合にケーブルフリーのセットアップ；軽量でポータブルな構成を維持

KeyMod は、リモートデスクトップの代替ではなく、実用的な日常的なローカルデバイス制御のために設計されています。

### **オープンソースモバイルアプリ**

オープンソースモバイルアプリで、以下のことができます：

- **キーボード＆マウス（基本）** — 長押しリピート、キープレビュー、テンキー付きフルスクリーンキーボード
- **キーボード＆マウス Pro** — ショートカットハブストリップ、分割キーボード、IME を備えたコンポジットレイアウト
- **プレゼンテーションモード** — Google スライドやその他のアプリ向けのスライドリモコンとタイマー
- **ゲームパッド** — カスタマイズ可能なプリセットレイアウト、マルチタッチパッドサポートを備えた仮想コントローラー
- **ショートカットハブ** — クリエイティブツール・開発ツール（Blender、KiCAD、Photoshop、VS Code）向けのプロファイルベースキーボードショートカット。作成、インポート、エクスポートに対応
- **マクロ** — ディレイ付きのプログラム可能なキーシーケンス
- **音声入力** — AI（Whisper API）による音声からキーボードへの変換
- **ターミナル** — Bluetooth 経由の SSH によるリモートコマンドアクセス
- **Agent** — HID または SSH コマンドを通じて AI と直接対話し、別のコンピュータを制御

**KeyCmd** アプリは **Android** と **iOS**（iPadOS を含む）に焦点を当てています。USB または Bluetooth 経由で **KVM-GO** とも動作します。より広範な Openterface エコシステムで、**Windows と macOS** ソフトウェアによるデスクトップ制御も展開しています。


### **真のハードウェア HID**

Openterface Mini-KVM で実証済みの HID コアを搭載。ハードウェアベースのキーボードおよびマウスエミュレーション—ターゲットデバイスにソフトウェアをインストールする必要はありません。

### **オープンソース**

KeyMod はオープンハードウェアであり、オープンソースソフトウェアです。プロジェクトの進展に伴い、回路図、PCB ファイル、ファームウェア、ソフトウェア、BOM を公開していく予定です。[コミュニティに参加](/discord)して、貢献と最新情報の入手をお願いします。

## 技術仕様

### **接続**

- **USB**：Mini バージョンは Type C オスコネクタを使用；Plus バージョンは Type A オスコネクタと Type C メスコネクタを使用
- **Bluetooth**：HID キーボードとマウス
- **ターゲット**：ソフトウェアのインストール不要

### **主要ハードウェア**

- CH32V208 チップ（CH9329 互換プロトコル）
- USB コネクタ：Mini バージョンは Type C オス；Plus バージョンは Type A オスと Type C メス
- MCU
- プログラマブルボタン

### **入力機能**

- フルキーボードとマウスエミュレーション（HID）
- カスタム入力プロファイル（基本と Pro の 2 tier）
- マクロとホットキー
- アプリ固有のプロファイルを備えたショートカットハブ
- プリセットベースレイアウトのゲームパッド（schema v7）
- スライドタイマー付きプレゼンテーションコントロール
- AI による音声からキーボードへの変換
