## Allgemein

**:material-chat-question:{ .faq } Was ist KeyMod Series?**

KeyMod Series ist ein kompakter USB + Bluetooth HID-Emulator (Tastatur و Maus), der Ihr Smartphone in eine tragbare Tastatur و ein Trackpad verwandelt. Verwenden Sie es zur Steuerung von Geräten, die Tastatur-/Mauseingaben benötigen – Kioske, Smart-TVs, Set-Top-Boxen, Außendisplays – ohne eine vollständige Tastatur معzuführen.

**:material-chat-question:{ .faq } Welche Plattformen unterstützt die KeyMod Series App?**

Die KeyMod Series Controller-App konzentriert sich auf **Android**, **iOS** و **iPadOS**. Wir erweitern auch die Desktop-Steuerung مع **Windows- و macOS-البرمجيات** in unserem breiteren Openterface-Ökosystem.

**:material-chat-question:{ .faq } Benötigt das Zielgerät eine البرمجيات?**

Nein. KeyMod Series emuliert eine Standard-USB-Tastatur و -Maus. Das Zielgerät erkennt es als Plug-and-Play-HID-الأجهزة – keine Treiber أو البرمجياتinstallation erforderlich.

**:material-chat-question:{ .faq } Ist KeyMod Series Open Source?**

Ja. KeyMod Series ist Open-الأجهزة و Open-Source-البرمجيات. Wir werden Schaltpläne, PCB-Dateien, Firmware, البرمجيات و BOM veröffentlichen, während das Projekt sich weiterentwickelt.

## Konnektivität

**:material-chat-question:{ .faq } USB vs. Bluetooth – was soll ich verwenden?**

- **USB**: Zuverlässiger, geringere Latenz. Verwenden Sie es, wenn Sie die stabilste الاتصال wünschen.
- **Bluetooth**: Kabellos. Verwenden Sie es, wenn Sie ein leichteres Setup wünschen و das Szenario drahtlose الاتصال zulässt.

**:material-chat-question:{ .faq } Welche الأجهزة-Varianten sind لـ KeyMod Series geplant?**

1. **2-in-1-Stecker** — Kombinierter USB-A- و USB-C-Stecker لـ breite Kompatibilität
2. **USB-C-Version** — Dedizierter USB-C-Stecker لـ mأوne Geräte

## Pre-Launch

**:material-chat-question:{ .faq } Wann wird KeyMod Series auf den Markt kommen?**

KeyMod Series befindet sich in der Pre-Launch-Entwicklung. Abonnieren Sie die [منتجseite](/products/keymod/) لـ Launch-Benachrichtigungen و التحديثات.

**:material-chat-question:{ .faq } Wie hängt KeyMod Series مع Mini-KVM و KVM-Go zusammen?**

KeyMod Series nutzt den bewährten HID-Kern von Openterface Mini-KVM. Es teilt denselben hardwarebasierten Ansatz zur Tastatur- و Mausemulation, ist aber لـ einen anderen Anwendungsfall konzipiert: Ihr Smartphone in eine tragbare Tastatur/Trackpad لـ die lokale Gerätesteuerung zu verwandeln, anstatt KVM-over-USB-Videoaufnahme.
