# **功能與規格** | Openterface KeyMod 系列

## 產品版本

- **Mini 版** — 僅 Type C 公頭介面
- **Plus 版** — Type A 公頭介面和 Type C 母頭介面

## 核心功能

### **手機變鍵盤和觸控板**

KeyMod 將您的手機變成便攜式鍵盤和觸控板控制台。在無法使用完整鍵盤和滑鼠時使用，或當您需要比切換裝置更快的操作流程時使用。適用於戶外顯示屏電腦、LED 廣告機播放器、資訊亭、智慧型電視和機上盒。

### **雙連接：USB + 藍牙**

- **USB** — 隨插即用有線連接，實現可靠、低延遲的輸入
- **藍牙** — 在場景允許時實現無線設定；保持設定輕便便攜

KeyMod 專為實用的日常本地裝置控制而設計，而非替代遠端桌面。

### **開源行動應用**

透過我們的開源行動應用，您可以：

- **鍵盤與滑鼠（基礎版）** — 全螢幕鍵盤，支援長按重複、按鍵預覽和數字鍵盤
- **鍵盤與滑鼠專業版** — 帶快速鍵中心條、分割鍵盤和輸入法的組合佈局
- **簡報模式** — 適用於 Google Slides 和其他應用的投影片遙控與計時器
- **手把** — 虛擬控制器，支援可自訂的預設佈局和多觸控板支援
- **快速鍵中心** — 為創意和開發工具（Blender、KiCAD、Photoshop、VS Code）提供基於設定檔的鍵盤快速鍵，支援建立、匯入和匯出
- **巨集** — 帶延遲的可程式化按鍵序列
- **語音輸入** — 透過 AI（Whisper API）實現語音轉鍵盤
- **終端機** — 透過藍牙進行 SSH，實現遠端命令存取
- **Agent** — 透過 HID 或 SSH 指令與 AI 直接互動，控制另一台電腦

**KeyCmd** 應用專注於 **Android** 和 **iOS**（包含 iPadOS）。它亦可透過 USB 或藍牙與 **KVM-GO** 配合使用。我們還在更廣泛的 Openterface 生態系統中透過 **Windows 和 macOS** 軟體擴展桌面控制。


### **真正的硬體 HID**

基於 Openterface Mini-KVM 的成熟 HID 核心。基於硬體的鍵盤和滑鼠模擬——目標裝置無需安裝軟體。

### **開源**

KeyMod 是開源硬體和開源軟體。隨著專案的發展，我們將發佈電路圖、PCB 檔案、韌體、軟體和 BOM。[加入我們的社群](/discord)參與貢獻並獲取最新資訊。

## 技術規格

### **連接**

- **USB**：Mini 版使用 Type C 公頭介面；Plus 版使用 Type A 公頭介面和 Type C 母頭介面
- **藍牙**：HID 鍵盤和滑鼠
- **目標**：無需安裝軟體

### **關鍵硬體**

- CH32V208 晶片（相容 CH9329 協定）
- USB 介面：Mini 版使用 Type C 公頭；Plus 版使用 Type A 公頭和 Type C 母頭
- MCU
- 可程式化按鈕

### **輸入功能**

- 完整鍵盤和滑鼠模擬（HID）
- 自訂輸入設定檔（基礎和進階兩個層級）
- 巨集和快速鍵
- 帶應用專用設定檔的快速鍵中心
- 帶預設佈局的手把（schema v7）
- 帶投影片計時器的簡報控制
- 透過 AI 實現語音轉鍵盤
