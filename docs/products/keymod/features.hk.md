# **功能與規格** | Openterface KeyMod

## 產品版本

- **2 合 1 連接器版本** — 組合 USB A + USB C 插頭設計，廣泛兼容筆記本電腦、平板電腦和手機
- **USB C 版本** — 專用於現代設備的 USB C 插頭，便於整潔的線纜管理

## 核心功能

### **手機變鍵盤和觸控板**

KeyMod 將您的手機變成便攜式鍵盤和觸控板控制台。在無法使用完整鍵盤和鼠標時使用，或當您需要比切換設備更快的操作流程時使用。適用於户外顯示屏電腦、LED signage 播放器、信息亭、智能電視和機頂盒。

### **雙連接：USB + 藍牙**

- **USB** — 即插即用有線連接，實現可靠、低延遲的輸入
- **藍牙** — 在場景允許時實現無線設置；保持輕便便攜的配置

KeyMod 專為實用的日常本地設備控制而設計，而非替代遠程桌面。

### **開源移動應用**

通過我們的開源移動應用，您可以：

- 創建自定義輸入配置
- 啓動宏並配置快捷鍵
- 創建工作流快捷方式

KeyCmd 應用主要支持 **Android、IOS 和 iPadOS**。我們也在更廣泛的 Openterface 生態系統中通過 **Windows 和 macOS** 軟件擴展桌面控制。

### **真正的硬件 HID**

基於 Openterface Mini-KVM 的成熟 HID 核心。基於硬件的鍵盤和鼠標模擬——目標設備無需安裝軟件。

### **開源**

KeyMod 是開源硬件和開源軟件。隨着項目的發展，我們將發佈電路圖、PCB 文件、固件、軟件和 BOM。[加入我們的社區](/discord)參與貢獻並獲取最新信息。

## 技術規格

### **連接**

- **USB**：USB C 端口（2 合 1 版本：USB A + USB C 組合插頭）
- **藍牙**：HID 鍵盤和鼠標
- **目標**：無需安裝軟件

### **關鍵硬件**

- CH9329 HID 模擬器芯片
- 藍牙模塊
- USB C 端口
- MCU
- 可編程按鈕

### **輸入功能**

- 完整鍵盤和鼠標模擬（HID）
- 自定義輸入配置
- 宏和快捷鍵
