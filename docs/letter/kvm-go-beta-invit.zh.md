# **欢迎加入 Openterface KVM-GO Beta 测试计划！**

**亲爱的 Beta 测试员：**

感谢您加入 **Openterface KVM-GO** beta 测试计划！您的参与对于在正式发布前完善这款新一代超紧凑 KVM-over-USB 设备至关重要。

## **关于 KVM-GO**

**KVM-GO** 系列（HDMI/DP/VGA 版本）可挂在**钥匙扣**上，无需显示器或网络配置即可即时访问无头设备。它是 Mini-KVM 的进化版——**更小、更快、更灵活**——关键时刻真正**随拿随用**的技术工具。

## **如何测试**

### **1. 设置**

- 请按照我们的快速入门指南：**openterface.com/products/kvmgo/how-to-connect**
- 在不同平台（Windows、macOS、Linux、Android）和目标设备（服务器、迷你 PC、BIOS 级访问）上进行测试

### **2. 真实场景测试**

- 在日常工作或爱好项目中使用 KVM-GO
- 测试视频极限：不同分辨率/刷新率、HD/4K 性能
- 测试键盘/鼠标响应速度和 USB 供电稳定性

### **3. 清晰报告 Bug**
请包含：应用版本、主机操作系统/规格、目标设备、复现步骤、预期与实际结果、截图/视频
