# **歡迎加入 Openterface KVM-GO Beta 測試計劃！**

**親愛的 Beta 測試員：**

感謝您加入 **Openterface KVM-GO** beta 測試計劃！您的參與對於在正式發佈前完善這款新一代超緊湊 KVM-over-USB 設備至關重要。

## **關於 KVM-GO**

**KVM-GO** 系列（HDMI/DP/VGA 版本）可掛在**鑰匙扣**上，無需顯示器或網絡配置即可即時訪問無頭設備。它是 Mini-KVM 的進化版——**更小、更快、更靈活**——關鍵時刻真正**隨拿隨用**的技術工具。

## **如何測試**

### **1. 設置**

- 請按照我們的快速入門指南：**docs.openterface.com/products/kvmgo/how-to-connect/**
- 在不同平台（Windows、macOS、Linux、Android）和目標設備（服務器、迷你 PC、BIOS 級訪問）上進行測試

### **2. 真實場景測試**

- 在日常工作或愛好項目中使用 KVM-GO
- 測試視頻極限：不同分辨率/刷新率、HD/4K 性能
- 測試鍵盤/鼠標響應速度和 USB 供電穩定性

### **3. 清晰報告 Bug**
請包含：應用版本、主機操作系統/規格、目標設備、復現步驟、預期與實際結果、截圖/視頻
