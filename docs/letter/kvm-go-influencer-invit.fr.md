# **Openterface KVM-GO : Guide de test bêta**

Salut !

Merci encore d'avoir rejoint notre programme bêta. Nous sommes vraiment ravis de vous voir essayer le **KVM-GO** avec notre groupe d'accès anticipé. Ce petit appareil est essentiellement un KVM de la taille d'un porte-clés qui vous permet de vous connecter à des appareils headless sans les tracas habituels.

## **Ce qui rend KVM-GO génial**

Le **KVM-GO** (versions HDMI, DP et VGA) est assez petit pour tenir sur un porte-clés, mais bien plus capable que notre Mini-KVM précédent. Pas besoin de moniteurs, de réseau ou d'étapes de configuration compliquées. Branchez-le et ça fonctionne. Très pratique pour les informaticiens, administrateurs de serveurs et toute personne travaillant avec des appareils headless.

**Votre audience appréciera probablement :**

* Qu'il est *vraiment* minuscule et super portable
* Qu'il fonctionne dès que vous le branchez avec juste l'USB
* Qu'il tourne sur Windows, macOS, Linux, Android, même iPadOS
* L'accès BIOS complet pour le travail serveur et le dépannage
* La prise en charge vidéo 4K, ce qui est assez fou pour la taille
