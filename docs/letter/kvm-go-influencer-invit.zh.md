您好！

再次感谢您加入我们的 beta 计划。我们非常期待您与早期访问小组一起试用 **KVM-GO**。这个小东西基本上就是一个钥匙扣大小的 KVM，让您无需任何常见麻烦即可连接无头设备。

## **KVM-GO 的亮点**

**KVM-GO**（HDMI、DP 和 VGA 版本）小到可以挂在钥匙扣上，但比之前的 Mini-KVM 功能强大得多。您不需要显示器、网络或复杂的设置步骤。只需插入即可工作。对 IT 人员、服务器管理员以及任何处理无头设备的人来说都非常方便。

**您的受众可能会欣赏它：**

* 真的*非常*小巧且超级便携
* 只需 USB 插入即可立即工作
* 支持 Windows、macOS、Linux、Android，甚至 iPadOS
* 为服务器和故障排除工作提供完整 BIOS 访问
* 支持 4K 视频，对于这个尺寸来说相当惊人
