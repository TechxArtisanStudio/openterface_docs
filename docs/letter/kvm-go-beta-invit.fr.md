# **Bienvenue dans le programme de test bêta Openterface KVM-GO !**

**Chers testeurs bêta,**

Merci de rejoindre le programme de test bêta **Openterface KVM-GO** ! Votre participation est essentielle pour peaufiner cet appareil KVM-over-USB ultra-compact de nouvelle génération avant son lancement.

## **À propos de KVM-GO**

La série **KVM-GO** (versions HDMI/DP/VGA) tient sur votre **porte-clés** et offre un accès instantané aux appareils headless sans moniteur ni configuration réseau. C'est l'évolution de notre Mini-KVM — **plus petit, plus rapide et plus polyvalent** — un véritable outil **prêt à l'emploi** pour les moments techniques critiques.

## **Comment tester**

### **1. Configuration**

- Suivez notre guide de démarrage rapide : **docs.openterface.com/products/kvmgo/how-to-connect/**
- Testez sur différentes plateformes (Windows, macOS, Linux, Android) et appareils cibles (serveurs, mini-PC, accès au niveau du BIOS)

### **2. Tests en conditions réelles**

- Utilisez KVM-GO dans votre travail quotidien ou vos projets personnels
- Poussez les limites vidéo : différentes résolutions/fréquences de rafraîchissement, performances HD/4K
- Testez la réactivité clavier/souris et la stabilité de l'alimentation USB

### **3. Signalez les bugs clairement**
Incluez : version de l'application, OS/specs de l'hôte, appareil cible, étapes de reproduction, résultats attendus vs réels, captures d'écran/vidéos
