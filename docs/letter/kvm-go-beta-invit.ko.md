# **Openterface KVM-GO 베타 테스트 프로그램에 오신 것을 환영합니다!**

**베타 테스터 여러분,**

**Openterface KVM-GO** 베타 테스트 프로그램에 참여해 주셔서 감사합니다! 여러분의 참여는 출시 전 이 차세대 초소형 KVM-over-USB 기기를 다듬는 데 매우 중요합니다.

## **KVM-GO 소개**

**KVM-GO** 시리즈(HDMI/DP/VGA 버전)는 **열쇠고리**에 달 수 있으며, 모니터나 네트워크 설정 없이 헤드리스 장치에 즉시 접근할 수 있습니다. Mini-KVM의 진화형——**더 작고, 더 빠르며, 더 다재다능**——중요한 기술 순간에 진정한 **휴대용 도구**입니다.

## **테스트 방법**

### **1. 설정**

- 빠른 시작 가이드를 따르세요: **openterface.com/product/kvm-go/how-to-connect**
- 다양한 플랫폼(Windows, macOS, Linux, Android)과 대상 장치(서버, 미니 PC, BIOS 수준 접근)에서 테스트

### **2. 실제 환경 테스트**

- 일상 업무나 취미 프로젝트에서 KVM-GO 사용
- 영상 한계 테스트: 다양한 해상도/주사율, HD/4K 성능
- 키보드/마우스 반응성 및 USB 전원 안정성 테스트

### **3. 버그를 명확하게 보고**
포함 사항: 앱 버전, 호스트 OS/사양, 대상 장치, 재현 단계, 예상 결과 vs 실제 결과, 스크린샷/동영상
