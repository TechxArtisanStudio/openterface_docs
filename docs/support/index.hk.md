# 技術支持

我們理解當事情不如預期工作時會令人沮喪，**我們在這裏幫助您**。我們的故障排除表單將**逐步**指導您分享有關您的設置和您面臨的問題的詳細信息。有了這些信息，我們可以更好地理解問題並更有效地支持您。

請耐心等待，我們一起努力找出原因並找到最佳解決方案。

以下是您可以獲得支持的一些方式：

- [查看我們的常見問題](/faq)：您可能會在那裏找到答案。
- [故障排除表單](/support)：請填寫並幫助我們更好地瞭解您的設置。
- [加入我們的社區](/community)：如果您更喜歡即時聊天，這裏是我們的開發團隊和其他優秀用户聚集的地方。
- [GitHub Issues](/app)：查看並在我們應用的 GitHub 倉庫中創建問題
- 發送郵件給我們：[support@openterface.com](mailto:support@openterface.com)
